# 不接定位的 SDCP 多径检测实验

日期：2026-09-16。保留原双 RF、双 DFE、双独立跟踪环路；不调用定位。实验入口 `audit_sdcp_multipath_no_positioning.py`；逐项参数和源码快照以输出目录的 `plan.json`、`config.json`、`code/` 为准。

## 主实验：绝对几何残差

单 GPS L1 C/A PRN 1，RF 33 MHz，中频 4.092 MHz，DFE 降采样 5 倍，跟踪 6.6 MHz、1 ms 积分、Costas。每条记录 1.5 s。真实/假设视线均为方位 30°、仰角 60°，TL/TR 基线 75.9 mm。无干扰、无定位，通道额外时延为零。

以共同接收时刻插值两路累积 NCO 相位，换算载波距离单差，再减已知几何单差。不做波长取余、不去本记录均值、不使用真值修正整周或半周分支。硬件已知零偏置与可比相位分支是绝对判据的前提，必须通过正常组检查，不能因其不成立而隐藏实验结果。

预定统计：舍弃前 200 ms；200 个 1 ms 采样作因果算术平均，每 10 ms 判定；连续 3 次绝对值超过固定门限才报警。首个窗口结束于 399 ms，最早确认在 419 ms。门限为三条独立正常标定记录的最大绝对窗口均值乘 1.25。固定裕量为工程试验选择，不宣称对应特定误报概率。

标定 A/B 噪声种子为 11900/11901、11902/11903、11904/11905；测试为 12000/12001、12002/12003、12004/12005。先冻结门限再执行测试，不根据多径结果重选种子、门限或场景。16 类测试包含正常、固定硬件偏差、慢漂移、启动即有/中途出现回波、强弱回波、短/中/长时延、不同反射相位/到达方向及双路共同污染。每类 3 条记录；配对场景复用正常 A 记录与噪声实现。

多径用现有 `_multipath_scene` 生成：对包含合成 50 bps 数据符号的完整源波形执行分数时延、射频载波相位恢复和方向响应，再叠加在直达波上。中途回波在 600 ms 开始，10 ms 升余弦包络进入；启动回波在记录开始就存在。不是直接给跟踪相位加偏差。反射相位参数不等于接收点回波相对相位，后者还包含传播时延、空间几何和 Doppler。

报告记录级是否检出、首次报警延迟、报警判定数/总判定数、事件前误报、原始残差统计及跟踪质量。质量只作诊断，不筛掉异常数据。3 个种子和重叠窗口不足以估计通用检测概率。无多径硬件/漂移报警必须记为多径归因的假阳性。

## 标定后补充实验：只检测时间变化

在完成上述标定、尚未读取多径测试结果时发现：三条正常标定中两条残差约为 −95 mm，符合 L1 半周分支差；主实验门限达到 119.835 mm。主实验仍按原计划完整保留，不校正分支、不重标定。

增加独立标记的探索性补充判据：比较相邻两个、不重叠的 200 ms 算术平均，`change(t)=mean[t−199ms,t]−mean[t−399ms,t−200ms]`。仍每 10 ms 判定、连续 3 次超限确认。只用同三条正常标定数据决定 `1.25×max(abs(change))` 门限；不利用测试多径标签/结果调参。采用同一批已保存 NCO 数据，无须重跑或改动 RF、DFE、跟踪链。

该判据没有波长取余和分支修正，但会消去持续不变的相位偏差；因此仅可研究连续跟踪弧中的变化，不能证明启动静态多径可检出。固定硬件偏差、静态多径、固定模糊度都会被消去；慢漂移和跳周仍可能误报。首个可用判定为 599 ms，最早确认 619 ms。结果必须与主实验分开，不把补充试验包装成预先冻结的主验收。

## 证据与验收

保留源码哈希、配置、种子、全部跟踪数组、标定值、每次判定和统计。独立脚本从 NCO 重建相位，再用逐窗求均值和显式连续判定核对结果。给出数据图、逐场景结果及失败原因。不得据此宣称商用可靠、已解决初始模糊度、能区分多径与硬件异常，或改善了定位精度。
