# W2：时延、频差与星间双差回放

这是首阶段 W2 的窄带误差模型子项，承接旧 RF 记录适配；不是同步故障检测器，也没有完成 W2 全部工作。旧阶段计划中“输入检查器、缺字段拒收”的实现要求已按用户后续指示取消，本入口直接使用明确参数。未增加通用输入验证层。

## 方法与约定

每个 PRN 用确定性复正弦表示，频率为中频加 Doppler。各通道共享同一组 PRN，误差在通道采样时间上注入，因此不同基线之间共享参考通道误差，不能视作独立噪声。默认 GPS L1 载频 1575.42 MHz、中频 1 MHz；八颗星的 Doppler 为 −4000 至 +4500 Hz。这里不模拟空间方向、码相关器、PLL、噪声或 IMU。

设名义时刻为 t，通道 a 的 RF 传播延迟为 τₐ，ADC 固定偏斜为 sₐ，采样频率相对误差为 εₐ，公共中频 NCO 时标偏差为 ηₐ，标签偏差为 ℓₐ。正偏斜表示采得更晚，正传播延迟表示波形到达更晚。实际采样时刻与输出标签分别为：

```text
t_actual,a = t/(1+εₐ) + sₐ
t_label,a  = t + ℓₐ
δtₐ       = t_actual,a − t
φₐp       = 2π[(f_IF + dₚ)t_actual,a − (f_c + dₚ)τₐ − f_IF(t+ηₐ)]
φ_clean,p = 2π dₚ t
eₐp       = −λ(φₐp−φ_clean,p)/(2π)
          = λ[(f_c+dₚ)τₐ − (f_IF+dₚ)δtₐ + f_IF ηₐ]
```

距离符号遵循现有接收机载波约定。单差是 eₐp−e₀p；以 PRN 列 0 为代数参考再做星间差：

```text
DDₐ,p0 = λ(dₚ−d₀)[(τₐ−τ₀) − (δtₐ−δt₀)]
```

因此公共载频/中频项消失，Doppler 差项保留。若逐星 NCO 各用不同频率，NCO 时标偏差也会留下频率差项；本实验只覆盖公共中频 NCO，不能推广为任意 NCO 误差都可消除。

单纯标签错误不改变任何复样本。消费者按错误标签与几何/其他传感器对齐时，距离误差多出 λdₚℓₐ，对应双差额外为 λ(dₚ−d₀)(ℓₐ−ℓ₀)。`label_aligned_error_m` 由仿真真值评价得到，未作为检测器输入。

实际复相位只能给出模 λ 的单差/双差。本入口同时输出复相位推得的包裹误差，以及仅供评价的未包裹误差；后者不代表真实接收机已解整周模糊度。

## 分析及开发边界

双差确实能去掉满足共模条件的固定偏差，但无法证明同步正确，更无法认证信号。共模故障可能完全不可见；标签错误甚至可以在原始空间判据上完全不显现，却严重污染后续对齐。时钟频差的残差随时间积累，固定短窗的良好表现不能外推到长时运行。

本轮没有给误差加检测阈值，没有把已知注入事件当成自动检出，也没有宣称具备攻击下导航能力。下一子项仍包括丢样/重样、NCO 重置与真实跟踪弧关联、消费者状态传播、标定生命周期和 IMU 延迟；W5/W6 的实测与可信误差边界仍需设备证据。

## W2 后续：丢重样、重置事件与相位弧消费

`stream_replay.py` 新增有限 IF 样本回放，复用既有 `SDCPArc`，没有修改默认接收机。100 kHz 采样率、每块 100 点、20 块（20 ms）；3 个 PRN 分量的 Doppler 为 −3000、0、4000 Hz，中频 10 kHz。第 8 块边界注入丢 1 样、重 1 样、重 100 样、NCO 半周重置或整周重置。这里只使用每块首样本的已知基带分量作为相位观测，没有执行码相关、PLL 或真实重捕。

令第 k 块的名义起点为 kB，故障导致的累计样本偏移为 Jₐ(k)，NCO 重置相位为 θₐ(k)，则：

```text
n_actual,a(k,j) = kB + j + Jₐ(k),  j=0,...,B−1
Δφₐp = 2π(f_IF+dₚ)Jₐ(k)/f_s − θₐ(k)
```

正 J 表示丢样后的源索引前移，负 J 表示重样。消费者只接收上报的源计数、tracking_id、质量和复相位；故障真值独立返回给评价模块。源计数必须来自采样源，而非主机给收到的数据重新编号。

相邻块源起点之差不等于 B 时，现有相位弧进入 unavailable；随后计数连续只会得到 await_reference。上报的 NCO 重置改变 tracking_id，即使质量全程良好也进入新弧的 await_reference。消费者在这些状态下实际输出 `residual_m=null`，不是只写告警日志。第 0、12 块设置外部参考准入事件，第 12 块重新建立参考后才能输出新残差；这是假设的外部准入输入，不代表软件已经证明信号可信。

## W2 后续：已保存 RF 跟踪输出的数值消费

```text
φ_A(t_B) = φ_A(t_A) + 2π f_NCO,A(t_A) (t_B−t_A)
SD(t_B)  = −λ[φ_B(t_B)−φ_A(t_B)]/(2π)
```

只在 A 的对应历元内使用此传播，质量和时间覆盖决定观测是否可用。tracking 起点只是观测时刻，不能当作采集端原始连续计数。初始 0.20–0.29 s 内首次合格观测在显式可信起点假设下建立参考，之后不给任何新准入。可用状态才输出 `SD−reference`，其余状态输出 null；`raw_sd_m` 保留为未认证诊断量。
