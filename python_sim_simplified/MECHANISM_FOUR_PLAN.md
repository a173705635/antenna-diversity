# 四轮机制研究：观测筛选间隙与绝对位置接续

范围：先真实初始化，单物理欺骗源，手机原固定布局，24星三/四天线主线；不研究冷启动、多源或IMU。只改精简版，不添加异常兜底。上一批所有样本（包括原留出）现在均为开发/回归样本。

1. 定位已知0.34s四天线33.87m错误：分别检查实际跟踪弧、方向筛选、平滑重置、跨历元载波约束；单独检验跨一个筛选间隙保留同跟踪弧平滑历史。
2. 根据第1轮结果检验测量支持的跨历元位置接续，与平滑修改消融比较。不得直接冻结旧位置，也不得仅遮蔽输出而污染后续状态。
3. 选择代码并统一回归正常弱信号、持续攻击、噪声冲击、真实消失，以及旧强信号正常/近源/撤除；报告误差与缺失，三天线失败保留。
4. 冻结候选和依赖后生成新种子117901，24星30dB-Hz持续攻击4秒、真实消失2秒，三/四天线检验；不根据这些结果调参。完成全部导航重演、输入/源码核验、测试、方法与结果。

20m目标、30/50m错误统计、原质量/方向证据/码解分离与恢复确认条件保持；新时间历史只用实际同弧的已接收测量。需要同时报告所有机会的20m内比例、最大误差、30/50m发布、最长缺失及攻击前实际发布。只几秒仿真不代表商用或长期导航。
