# 更新需求后的100轮：结果与未解决问题

本批完成001–100共100个机制候选实验：阵列采样码、空间来源、相关器恢复、连续观测导航各25轮。有改善，但三天线最低目标仍未通过；四天线也未证明稳定优于三天线。全套来源认证、连续RF跟踪/PVT尚未贯通，未替换原默认接收机。

## 1. 三、四天线的直接配对结果

下面是冻结025、新种子、同四路采样码记录的64快照验证。每配置1098个初始化后历元，包含正常对照和五类攻击；P95只在有输出样本上计算。初始化18/18条记录均通过本层观测稳定性规则。

三天线和四天线在普通单源、近一颗真星方向、弱信号三类攻击中均无≥30m位置；但三天线通道漂移出现3次≥30m，四天线漂移出现6次≥50m。四天线漂移只输出132/183个历元，三天线为182/183，因此不能只展示P95。

真实信号消失时各配置均无位置输出：这是本数据下拒绝残余码峰的效果，不是攻击下持续导航成功。最长连续拒绝61个快照，覆盖整个消失阶段。

## 2. 二天线性能差的原因

同数据子集排除了重新抽噪声与重新选卫星造成的差异。两个二天线几何都明显落后三天线，但长边反而更差，说明不能简化为“间距越大越好”。理想零陷保留量取决于各星与攻击源在基线上的相位投影，投影接近时噪声被放大；二天线抑制一维后只剩一维。

弱信号与通道漂移进一步扩大这种损失。四天线漂移反而比三天线差，也说明校准模型和权重处理不能忽略。当前证据支持“阵列几何、剩余维数与算法共同影响”，尚不能把每次失败唯一归因于某一个误差。空间检测层的二天线则没有普遍劣势，不能把恢复/导航的差距泛化为检测一定差。二天线不要求继续强修达标。

## 3. 另外75轮的结果

**来源026–050：**精确手机尺寸补验、冻结049与原门限下，每配置21/21攻击被检测、普通良性0/18误报，但共同良性反射3/3误报。6/48空间初始化失败全部保留。仅3独立种子；扩展旧几何审计已出现更高误报，不能将这组0/18解释成低风险认证。

**恢复051–075：**原研究初始化失败仍可能accepted的问题已通过独立发布接口纠正。以全部162次卫星判定/配置为分母，二/三/四天线发布40/76/80次，即24.69%/46.91%/49.38%，错误发布5/0/0。通过初始化的子集码误差P95分别31.59/18.01/16.25m，但这是相关器码误差，不是位置误差。另有四天线早期累计窗口1次错误，末端0次不能代表全过程安全。

**导航076–100：**冻结留出8640历元，5968次输出（69.07%），5839次≤20m，输出水平条件P95=14.42m，≥30/50m为0；2672次无输出，最长中断90s。48条场景组合仅来自3独立种子。它证明当前观测模型内的错误抑制与可用性代价，不证明三四天线性能，也未达到持续定位目标。

## 4. 本批改了什么

- 001–025：复增益标定、联合码拟合、空间零陷、广义特征源估计、LCMV/MVDR、几何准入、相关功率连续性、创新筛选、信息码平滑和初始化资格。
- 026–050：相位不变特征、跨星通道漂移消除、空间谱/协方差、时间外推、天空与共同源残差竞争；保留6个候选，其余拒绝。
- 051–075：启动模板、亚栅格码延迟、空间与时延白化、投影拟合、信号存在性与精度/连续性判定；保留9个机制。机制库事先实现后逐轮评估，不将其包装成25项全新独立系统。
- 076–100：稳健PVT、码载波差、相位步进、速度约束、重捕与丢失观测处理；12保留、13拒绝。

每轮假设、源码、同输入前后数字和决策见[逐轮台账](RESEARCH_WARM_HUNDRED_LEDGER.md)。实现纠错与审查补验不另计轮。

## 5. 验证与下一步

各线25轮均逐源复演；根任务与子任务完成交叉审查。完整测试及归档哈希最终状态见 `results/research-warm-hundred/status.json`，日志见同目录 `tests_final.log`。

下一步优先把三天线方案接入真实连续RF初始化、跟踪和重捕闭环，并处理漂移；四天线需要证明增加一路在相同漂移下确有收益。真实信号消失时，长期定位只能依赖额外独立约束；当前拒绝输出不能替代该能力。继续优化之前应先扩大独立场景和时间验证，不能只在这三个留出种子上补门限。
