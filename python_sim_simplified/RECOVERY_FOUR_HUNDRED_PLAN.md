# 第 201–400 轮计划与预注册

目标是降低上一轮出现的选星加权偏差和攻击下位置漂移，保持所有不可用历元在分母内。仅在精简版研究；不改变商用默认配置。遵循 ponytail 的现有代码复用原则。

- 201–240：40 个新种子、每个正常/攻击配对，生成原始协方差零陷与短时解扩启动相位校准两种接收方法。增加因果载波观测和原始多天线空间证据。每条 0.8 秒。
- 241–300：60 个预定义观测准入/码载波平滑规则，各自比较两个接收方法。复用上述 80 条记录，不计作新 RF 试验。
- 301–320：20 个观测域反例，检查一致伪位置、慢拖曳、时钟共模、失锁、载波周跳、动态接收机等；不是 RF 记录，不参与选型。
- 321–360：冻结所选算法后，40 个新种子正常/攻击配对，每条 1 秒，与上一轮主策略、备选策略在同一输入比较。
- 361–400：40 个新种子边界配对，包括 2–8 秒、受骗启动、无真实信号、2–4 天线、12/16 颗卫星、运动及渐变攻击。

开发选择规则：正常输出率至少 95%、攻击输出率至少 50%，在满足者中优先最小化所有 ≥30m 输出，再最小化 ≥50m，随后最大化攻击/正常 ≤20m 全历元数量。95% 只是研究选型约束；用户 99% 正常可用性目标保持不变。若无可行配置，记录选型失败，不伪称达标。

所有新种子由编号派生，各编号使用不同天空几何。重复规则、历元、同种子正常/攻击不解释成独立总体样本。冻结后不根据留出结果调整算法。

数学：Hatch 递推用观测载波增量传播伪距，连续弧内以有限窗口码观测校正；相位常偏消除，但共同伪造的码与载波及初始错误不会因此消除。空间证据使用当前输出前 20ms 原始多天线数据的短时相关，投影到测得公共源的正交空间，判断是否存在真实方向可观测分量。附近假码与真码相关，故该分量不等于真码锁定证明。

新增场景用同一几何距离同时驱动码和载波：接收机东向匀速，假位置为接收机位置加初始东向偏移和攻击后线性拖曳。姿态、阵列相位固定，依然不是手持转动模型。

验收包含：前缀因果性、失锁/时间缺口弧重置、常数相位模糊度不影响结果、运动保持、一致伪造反例；完整既有测试；按保存数组重新统计与重放准入；归档源码与 SHA256。输出完整方法、结果、失败分析和图。
