# GNSS双接收通道在线校准研究需求

日期：2026-10-29。本文用于高校合作方案讨论，指标为拟定研究目标，需评估可达条件后确定验收要求。

## 研究目标与范围

研究GNSS双接收通道幅度、相位及差分时延的在线校准，解决两条接收链路不一致对信号合成和抗干扰处理的影响。

以两条接收通道为对象，估计并补偿RF及后续采样、数字处理引入的相对增益、相位和时延误差，补偿位置放在DFE输出之后、空间合成之前。

优先研究不依赖卫星解扩和跟踪的校准方案，例如注入已知宽带校准信号。明确注入点及校准覆盖范围，并扣除校准信号分配网络自身的幅相和时延影响；天线方向图、空间几何相位等不应误认为接收通道误差而被消除。

## 拟定性能目标

以下均指相对于参考通道、补偿后的残余误差，请结合硬件条件评估能否同时达到。

| 项目 | 初步目标 | 评价口径 |
| --- | --- | --- |
| 相对增益误差 | RMS ≤ 0.1 dB | 在约定工作带宽内评估，并报告最差频点 |
| 相对相位误差 | RMS ≤ 1° | 中心频点残余相位，并提供带内残余相位曲线 |
| 差分时延误差 | RMS ≤ 0.1 ns | 根据带内相位斜率估计，并报告非线性相位残差 |
| 在线更新能力 | 请提出可实现指标 | 给出首次收敛时间、更新周期、处理延迟及计算量 |

这些是建议目标，并非现有文献已经证明的通用保证。作为参考，MIR接收机研究的一个RF链路估计示例报告了相位标准差0.88°、群时延标准差0.11 ns、增益估计几何标准差（以dB表示）0.1 dB；这些反映估计波动，不能直接等同于补偿后的准确度或实时更新精度。该示例采用10 Msps、I/Q各16 bit采样及500个子区间，校准分配器和线缆另行表征。[参考论文，§3.2、图14](https://pmc.ncbi.nlm.nih.gov/articles/PMC6427221/)

## 验证要求

先完成算法仿真，再进行双通道硬件验证，重点覆盖：

- 固定幅相和时延偏差，以及温度变化引起的缓慢漂移。
- 两通道不同AGC/ILNA档位，以及档位切换后的重新收敛。
- 无干扰、窄带干扰和宽带干扰条件。
- 校准信号对正常GNSS捕获、跟踪和载噪比的影响。

采用独立测量或已知注入误差作为参考，分别报告偏差、标准差和RMS误差；RMS应包含偏差，不能先去均值再作为准确度指标。各工况单独统计，并说明参考测量本身的不确定度，避免仅用重复估计的一致性证明校准准确度。

工作频段、有效带宽、采样率、初始误差范围、温度范围、AGC档位及校准信号功率，在方案阶段共同明确，作为指标成立的条件。

## 期望交付

- 校准模型与算法说明。
- 可运行源码、仿真及硬件验证结果。
- 接入现有DFE后处理链路的接口方案。

请重点评估三个精度目标能否同时达到、所需硬件条件、精度与更新时间的取舍，以及主要误差来源；若目标暂时不可达，给出有实测依据的可达指标和改进路径。
