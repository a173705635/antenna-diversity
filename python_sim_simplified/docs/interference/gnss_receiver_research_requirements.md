# GNSS双通道校准、抗干扰与抗欺骗研究需求

日期：2026-10-29。本文用于高校合作方案讨论，数值分为基础建议和进阶目标；它们是参考公开研究提出的工程目标，不是统一行业标准，也不代表当前系统已达到。正式验收前应结合硬件和应用确认。

## 研究目标与范围

研究GNSS双接收通道在线校准及抗干扰、抗欺骗处理，在约定信号功率和场景下保持可信定位。抗欺骗为拟新增合作研究范围，本文不表示当前维护版代码已实现该能力。

以两条接收通道为对象，估计并补偿RF及后续采样、数字处理引入的相对增益、相位和时延误差，补偿位置放在DFE输出之后、空间合成之前。

优先研究不依赖卫星解扩和跟踪的校准方案，例如注入已知宽带校准信号。明确注入点及校准覆盖范围，并扣除校准信号分配网络自身的幅相和时延影响；天线方向图、空间几何相位等不应误认为接收通道误差而被消除。

## 通道校准目标

以下均指相对于参考通道、补偿后的残余误差，请结合硬件条件评估能否同时达到。

| 项目 | 初步目标 | 评价口径 |
| --- | --- | --- |
| 相对增益误差 | RMS ≤ 0.1 dB | 在约定工作带宽内评估，并报告最差频点 |
| 相对相位误差 | RMS ≤ 1° | 中心频点残余相位，并提供带内残余相位曲线 |
| 差分时延误差 | RMS ≤ 0.1 ns | 根据带内相位斜率估计，并报告非线性相位残差 |
| 在线更新能力 | 请提出可实现指标 | 给出首次收敛时间、更新周期、处理延迟及计算量 |

这些是建议目标，并非现有文献已经证明的通用保证。作为参考，MIR接收机研究的一个RF链路估计示例报告了相位标准差0.88°、群时延标准差0.11 ns、增益估计几何标准差（以dB表示）0.1 dB；这些反映估计波动，不能直接等同于补偿后的准确度或实时更新精度。该示例采用10 Msps、I/Q各16 bit采样及500个子区间，校准分配器和线缆另行表征。[参考论文，§3.2、图14](https://pmc.ncbi.nlm.nih.gov/articles/PMC6427221/)

## 系统级指标的统一口径

- **首轮条件**：GPS L1 C/A、双接收通道、单点定位，不使用RTK或惯导辅助；参考RF端口每颗真实卫星功率先取−130 dBm，配置至少8颗可见卫星、无攻击时HDOP ≤ 2，先测静态，再测约定运动轨迹。−130 dBm是建议测试电平，不是GNSS最低接收功率标准；其他频点、弱信号和复杂多径另行验证。
- **空间条件**：基础目标针对一个空间干扰源或一个空间欺骗源，预先固定阵列布局、卫星及攻击源方向，避免主要卫星响应与攻击源响应近乎共线；近共线和多个独立源单独测能力边界，不能以“方向不同”代替可分离性检查。双通道常规空间处理不能保证同时压制任意多个独立同频源。
- **功率参考面**：以被测接收机各路RF输入连接器为准，记录并扣除测试线缆、合路器损耗。dBm表示该端口收到的功率，不能用发射机输出功率代替。宽带干扰注明功率积分带宽，脉冲干扰同时给出峰值和平均功率。
- **相对功率**：干信比 `J/S = P_jam − P_auth`（dB）中的干扰为指定带宽内总功率，真实信号为指定卫星、指定信号分量的功率；欺骗功率优势 `ΔP_spoof = P_spoof − P_auth`（dB）比较同一PRN、同一信号分量，在同一端口测量。注明参考通道，并记录各端口、各PRN功率；多星总功率与单星功率不混用。
- **定位误差**：以独立位置真值计算所有新鲜有效解的水平误差，分别给出95%分位值和最大值，不能先剔除超限解、只统计相对于无干扰结果的变化，或把RMSE当成95%误差。以下只约定水平定位，高程和授时另定。
- **连续性与可信性**：可信定位可用率按“新鲜、标记有效且误差不超过最大误差限值的历元数／按输出周期应有历元数”统计。缺报、无效、过期及超限解均计为不可用，不能用冻结坐标或复制旧历元结果冒充新解；误差统计与可用率必须同时报告。

| 定位与连续性指标 | 基础建议 | 进阶目标 |
| --- | --- | --- |
| 无攻击水平误差95%分位值／最大值 | ≤ 5 m／10 m | 同基础，作为对照 |
| 约定干扰或欺骗下水平误差95%分位值／最大值 | ≤ 10 m／20 m | ≤ 5 m／10 m |
| 可信定位可用率 | ≥ 99% | ≥ 99.9% |
| 最长连续不可用时间 | ≤ 5 s | ≤ 1 s |
| 干扰下冷启动至首次可信定位 | ≤ 120 s | ≤ 60 s |
| 干扰撤除后恢复可信定位 | ≤ 10 s | ≤ 5 s |

功率、定位误差和可用率应在同一组试验中同时满足，不能拼接不同试验的最优值。稳定定位后加入攻击的试验，从加入时刻起统计，不能删去失锁或过渡段；冷启动另计首次定位时间，并统计此后连续600 s的结果。无法维持可信定位时应及时标为无效，基础要求不晚于下一输出历元；超限解仍标为有效即失败，不能把后述告警时限当作允许错误输出的宽限。告警停报不等同于通过连续定位要求。

## 抗干扰需求

可直接使用的需求表述：

> 在上述首轮条件下，接收机RF输入端存在−80 dBm的单源CW或2 MHz带限噪声干扰，持续600 s时，应达到水平95%误差≤10 m、最大误差≤20 m、可信定位可用率≥99%、最长中断≤5 s。干扰已存在时，先以−85 dBm验证冷启动，首次可信定位时间≤120 s。

各类干扰分别约定门限，不用一个“抗干扰XX dBm”覆盖所有波形：

| 干扰类型 | 首轮条件 | 保持定位：基础／进阶 | 冷启动：基础 |
| --- | --- | --- | --- |
| 单音CW | 扫描L1中心及带内频偏 | −80／−70 dBm | −85 dBm |
| 多音 | 同一空间源的3音，等功率、频点固定；数值为总功率 | −80／−70 dBm | −85 dBm |
| 带限噪声 | L1中心、2 MHz带宽，带内近似平坦 | −80／−75 dBm | −85 dBm |
| 扫频 | 覆盖L1中心±1 MHz，预先约定并扫描周期 | −80／−75 dBm | −85 dBm |
| 脉冲 | 2 MHz带限噪声门控、10%占空比，另定脉宽和周期 | 峰值／平均：基础−70／−80 dBm，进阶−65／−75 dBm | 峰值−75、平均−85 dBm |

按每星−130 dBm计，连续干扰−85、−80、−75、−70 dBm分别对应本文口径的J/S为45、50、55、60 dB。冷启动先比保持定位降低5 dB，是考虑捕获难度的工程余量，不是所有接收机都存在固定5 dB差距。脉冲平均功率按 `P_avg = P_peak + 10log10(占空比)` 换算，峰值还需通过前端压缩和ADC限幅检查。

指定通信制式需先固定制式版本、信道、带宽和业务占用：若为进入GNSS通带的约2 MHz连续调制干扰，可先用−80 dBm做预研测试点；邻频LTE/5G/Wi-Fi等阻塞能力主要取决于频偏、滤波和前端线性度，不能沿用该数值作为验收门限。方案阶段应提交对应“频偏—可承受输入功率”曲线后定值。

各功率点分别测试稳定定位后加入干扰、冷启动时已有干扰，以及干扰撤除后的恢复；记录两路输入、前端压缩、ADC限幅和AGC状态。多音同源不等于多个独立空间源，单源结果不代替多源结果。

## 抗欺骗需求

可直接使用的需求表述：

> 在上述首轮条件及约定单源欺骗场景下，同PRN欺骗信号功率优势为0～+10 dB、持续600 s并施加约定虚假位置变化时，应达到水平95%误差≤10 m、最大误差≤20 m、可信定位可用率≥99%、最长中断≤5 s；不得将超限位置标记为有效。+20 dB作为进阶研究目标，不能只凭检测告警或停报宣称定位未被拉偏。

| 场景 | 必须约定的条件 | 功率优势：基础／进阶 |
| --- | --- | --- |
| 非同步欺骗或虚假位置突变 | 初始码／载波／时间偏差、虚假位置偏移、加入时刻 | 0～+10 dB／扩展至+20 dB |
| 初始对齐后逐步牵引 | 初始对齐误差、功率变化过程、位置／时间牵引速率和最终偏移 | 0～+10 dB／扩展至+20 dB |
| 转发式欺骗 | 转发时延及变化率、覆盖的PRN、转发源空间位置 | 0～+10 dB／扩展至+20 dB |

建议至少测0、+3、+6、+10 dB，进阶增加+15、+20 dB，不能只测最大功率；高功率更易检测，不代表接近等功率时也能可靠处理。每星真实信号−130 dBm时，+10 dB对应每个欺骗PRN为−120 dBm，不能把它当作多个欺骗PRN的总功率。

基础验收先覆盖真实信号已锁定后加入欺骗；启动时欺骗已存在、失锁后重捕获列为独立进阶场景，不能默认继承已锁定时的指标。各场景记录受影响的星座／频点／PRN、未受影响卫星和静止／运动轨迹；需包含所有参与定位的PRN都受到欺骗的情况，避免只靠未受影响星座掩盖能力不足。功率、时间同步和位置变化分别控制，参见[公开测试方法](https://safran-navigation-timing.com/testing-gnss-receivers-to-harden-against-spoofing-attacks/)。

告警延迟建议≤5 s，进阶≤1 s；计时起点为预先约定的攻击差异开始显现时刻，另记从信号加入到告警的总时间，不能事后移动起点。与真实信号在观测上不可区分的阶段不能保证检出，但超限位置不得有效输出的要求始终成立。建议试验检出率≥95%、无攻击误报≤0.1次/h；至少累计60次独立攻击试验、10 h无攻击数据，并报告次数及置信区间，不能把有限样本的通过率当作普适概率。“超限位置仍被标记有效”的次数必须为0。

## 建议值的依据与限制

- **双天线抗干扰及定位量级**：[Pallarés-Rodríguez等，ICL-GNSS 2025，§IV、表I](https://spcomnav.uab.cat/docs/conferences/Lucia_ICL-GNSS_2025.pdf)采用Skydel与软件接收机、半波长阵元间距，单CW条件下双天线PI/Capon水平RMSE分别为4.06/4.38 m，跟踪7/9颗卫星，展示的水平误差低于10 m。这支持把米级定位作为研究方向，但属于限定几何的仿真，RMSE不能直接换成95%分位值，也不能证明600 s可用率；其合成信号功率口径不能未经核对直接换算为本文每星参考的dBm门限。
- **宽带功率预算**：[NovAtel RoDAR公开规格](https://novatel.com/products/receivers/aerospace-defence-critical-infrastructure/robust-dual-antenna-receiver-rodar)给出30 dB干扰抑制，说明双天线工程实现具备该量级的参考，但产品天线、硬件和处理与本项目不同。作为本文预算假设：若有效J/S改善30 dB，−80 dBm、2 MHz平坦干扰的等效残余密度约−173 dBm/Hz；再假设输出折算的噪声密度为−172 dBm/Hz、目标功率−130 dBm，则有效载噪比约39.5 dB-Hz。因此把−80 dBm作为基础、宽带−75 dBm作为进阶有研究价值；真实空间处理的目标损失、噪声增益及前端非线性必须实测，不能用30 dB抑制直接宣称某个绝对抗扰功率。多音、扫频、脉冲的表中值是据此提出的待验证扩展，不是文献已逐项验证的成绩。
- **欺骗功率范围**：[Givhan，Auburn大学博士论文，2025](https://auetd.auburn.edu/handle/10415/9971)在双天线矢量跟踪、波束形成及逐次干扰消除的组合方案中，报告仿真对最高+20 dB欺骗功率优势改善了定位。该结果不能证明简单Blind Null或静止双通道也能达到本文指标，更未证明上述三种攻击都通过；建议+10 dB先作为联合研究目标，+20 dB作为进阶，仍须从检测做到正确定位。
- **告警与等功率难点**：[Psiaki等，ION GNSS+ 2014](https://gps.mae.cornell.edu/Paper_E6b_1_ION_GNSS_2014b.pdf)的双天线载波相位检测经过实船试验，算法检测可低于1 s，但系统处理使总延迟最长约6 s，接近等功率时存在跟踪和分类困难。本文5 s／1 s是需要验证的系统延迟目标，后者要求优化全链路；该研究证明的是检测能力，不是持续正确定位。

基础定位10 m（95%）／20 m（最大值）是在上述双天线米级仿真结果之外，为硬件、动态和过渡过程预留空间的工程建议；无攻击5 m、进阶5 m及99%可用率等也不是从论文直接推导的保证。可用率、最长中断、冷启动、恢复和误报门限主要是项目使用需求，暂按上表作为讨论起点。首轮不把厘米级定位、任意方向、多源攻击及邻频强阻塞纳入同一保证。

## 验证与交付要求

先完成算法仿真，再进行双通道硬件验证；通过传导注入或屏蔽环境完成可重复的系统级测试。除上述干扰与欺骗场景外，通道校准重点覆盖：

- 固定幅相和时延偏差，以及温度变化引起的缓慢漂移。
- 两通道不同AGC/ILNA档位，以及档位切换后的重新收敛。
- 无干扰、窄带干扰和宽带干扰条件。
- 校准信号对正常GNSS捕获、跟踪和载噪比的影响。

校准采用独立测量或已知注入误差作为参考，分别报告偏差、标准差和RMS误差；RMS应包含偏差，不能先去均值再作为准确度指标。各工况单独统计，并说明参考测量本身的不确定度，避免仅用重复估计的一致性证明校准准确度。

方案阶段共同明确工作频段、有效带宽、采样率、初始误差范围、温度范围、AGC档位及校准信号功率，并固化全部场景参数。建议定位至少1 Hz输出，新鲜度限值不超过一个输出周期；每个功率／几何条件持续600 s、至少重复10次，各次分别报告误差、可用率和中断，另给汇总值。1 Hz、600 s下99%允许最多6个不可用历元，99.9%则要求该次没有不可用历元，不能通过四舍五入放宽。启动试验另加首次定位阶段，不与稳定定位试验混算。

交付内容：

- 校准、抗干扰及抗欺骗的模型、算法说明与可运行源码，注明所需硬件和外部信息。
- 可复现的仿真及硬件测试配置、输入功率校准记录、位置真值和逐历元位置／有效标志／告警日志。
- 每种场景的可达功率范围、定位误差、可用率、最长中断及恢复时间；报告失败条件，不仅给出成功示例或平均载噪比。
- 接入现有DFE后处理链路及定位结果／告警接口的方案，给出计算量、收敛时间和更新延迟。

请评估三个校准精度目标能否同时达到，以及在相应校准误差下系统可承受的干扰／欺骗水平；给出精度与更新时间的取舍、主要限制和改进路径。基础值用于首轮方案评审，进阶值另列研究里程碑；所有验收门限和适用条件在测试前确定，不能在看到结果后改写为通过。
