# GNSS双通道校准、抗干扰与抗欺骗研究需求

日期：2026-10-29。本文用于高校合作方案讨论，校准数值为拟定研究目标；其余标为“待定”的门限由双方结合应用和硬件条件确定，不代表当前系统已具备相应能力。

## 研究目标与范围

研究GNSS双接收通道在线校准及抗干扰、抗欺骗处理，在约定信号功率和场景下保持可信定位。抗欺骗为拟新增合作研究范围，本文不表示当前维护版代码已实现该能力。

以两条接收通道为对象，估计并补偿RF及后续采样、数字处理引入的相对增益、相位和时延误差，补偿位置放在DFE输出之后、空间合成之前。

优先研究不依赖卫星解扩和跟踪的校准方案，例如注入已知宽带校准信号。明确注入点及校准覆盖范围，并扣除校准信号分配网络自身的幅相和时延影响；天线方向图、空间几何相位等不应误认为接收通道误差而被消除。

## 通道校准目标

以下均指相对于参考通道、补偿后的残余误差，请结合硬件条件评估能否同时达到。

| 项目 | 初步目标 | 评价口径 |
| --- | --- | --- |
| 相对增益误差 | RMS ≤ 0.1 dB | 在约定工作带宽内评估，并报告最差频点 |
| 相对相位误差 | RMS ≤ 1° | 中心频点残余相位，并提供带内残余相位曲线 |
| 差分时延误差 | RMS ≤ 0.1 ns | 根据带内相位斜率估计，并报告非线性相位残差 |
| 在线更新能力 | 请提出可实现指标 | 给出首次收敛时间、更新周期、处理延迟及计算量 |

这些是建议目标，并非现有文献已经证明的通用保证。作为参考，MIR接收机研究的一个RF链路估计示例报告了相位标准差0.88°、群时延标准差0.11 ns、增益估计几何标准差（以dB表示）0.1 dB；这些反映估计波动，不能直接等同于补偿后的准确度或实时更新精度。该示例采用10 Msps、I/Q各16 bit采样及500个子区间，校准分配器和线缆另行表征。[参考论文，§3.2、图14](https://pmc.ncbi.nlm.nih.gov/articles/PMC6427221/)

## 系统级指标的统一口径

- **功率参考面**：以被测接收机各路RF输入连接器为准，记录并扣除测试线缆、合路器损耗。dBm表示该端口收到的功率，不能用发射机输出功率代替。宽带干扰注明功率积分带宽，脉冲干扰同时给出峰值和平均功率。
- **相对功率**：干信比 `J/S = P_jam − P_auth`（dB）中的干扰为指定带宽内总功率，真实信号为指定卫星、指定信号分量的功率；欺骗功率优势 `ΔP_spoof = P_spoof − P_auth`（dB）比较同一PRN、同一信号分量，在同一端口测量。注明参考通道，并记录各端口、各PRN功率；多星总功率与单星功率不混用。
- **定位误差**：以独立位置真值计算水平误差，分别给出95%分位值和最大值，不能只统计相对于无干扰结果的变化。水平95%误差限值、最大误差限值均为[待定] m；若要求高程或授时性能，另定对应指标。
- **连续性与可信性**：可信定位可用率目标为[待定]%，按“新鲜、标记有效且误差不超过约定限值的历元数／按输出周期应有历元数”统计。缺报、无效、过期及超限解均计为不可用，不能用冻结坐标或复制旧历元结果冒充新解；同时限制最长连续不可用时间为[待定] s。

无法维持可信定位时，应在[待定] s内告警并将结果标为无效。告警停报属于异常输出保护，不等同于通过“连续可信定位”要求；两项分别验收。

## 抗干扰需求

可直接使用的需求表述：

> 在约定GNSS制式、单星输入功率、阵列几何及动态条件下，接收机RF输入端存在功率达到[待定] dBm的[指定制式或波形]干扰，持续[待定] s时，应满足约定的定位误差、可信定位可用率和最长中断时间要求。另行验证干扰已存在时的启动定位能力，首次可信定位时间不超过[待定] s。

各类干扰分别约定门限，不用一个“抗干扰XX dBm”覆盖所有波形：

| 干扰类型 | 必须固定或扫描的条件 | 保持定位的功率目标 | 干扰下启动的功率目标 |
| --- | --- | --- | --- |
| 单音CW | 中心频率、相对GNSS中心频偏 | [待定] dBm | [待定] dBm |
| 多音 | 音数、频点及功率分配；表中功率为总功率 | [待定] dBm | [待定] dBm |
| 带限噪声 | 中心频率、占用带宽和频谱形状 | [待定] dBm | [待定] dBm |
| 扫频 | 扫频范围、周期和扫频规律 | [待定] dBm | [待定] dBm |
| 脉冲 | 脉宽、重复周期及脉内波形；分别填写峰值／平均值 | [待定]／[待定] dBm | [待定]／[待定] dBm |
| 指定通信制式 | 制式版本、信道、带宽、调制及业务占用；区分同频与邻频阻塞 | [待定] dBm | [待定] dBm |

每个场景注明独立干扰源数量、来波方向、与真实卫星的空间关系和两路输入功率，单源结果不代替多源结果。分别测试已稳定定位后加入干扰、冷启动时已有干扰，以及干扰撤除后的恢复；恢复时间目标为[待定] s。记录前端压缩、ADC限幅和AGC状态，区分硬件动态范围限制与算法失效。

## 抗欺骗需求

可直接使用的需求表述：

> 在约定单星真实信号功率、卫星几何及欺骗场景下，同PRN欺骗信号在参考RF输入端比真实信号高[待定] dB，持续[待定] s并施加约定的虚假位置变化时，系统应保持定位误差不超过约定限值，同时满足可信定位可用率和最长中断时间要求；不得把超限位置标记为有效输出。不能维持可信定位时按异常输出保护要求处理，不能据此宣称连续定位通过。

| 场景 | 必须约定的条件 | 欺骗功率优势目标 |
| --- | --- | --- |
| 非同步欺骗或虚假位置突变 | 初始码／载波／时间偏差、虚假位置偏移、加入时刻 | [待定] dB |
| 初始对齐后逐步牵引 | 初始对齐误差、功率变化过程、位置／时间牵引速率和最终偏移 | [待定] dB |
| 转发式欺骗 | 转发时延及变化率、覆盖的PRN、转发源空间位置 | [待定] dB |

不能只测最大功率优势；应扫描从接近真实功率到约定上限的范围，并分别测试真实信号已锁定、启动时欺骗已存在、失锁后的重捕获。每项记录受影响的星座／频点／PRN、是否保留未受影响的卫星、欺骗源数量与方向，以及静止／运动轨迹。功率优势、时间同步关系和位置变化是不同测试维度，[公开测试方法](https://safran-navigation-timing.com/testing-gnss-receivers-to-harden-against-spoofing-attacks/)也分别控制这些条件。

除定位指标外，报告欺骗告警延迟、漏检次数／总攻击次数及无攻击条件下的误报次数／小时，目标分别为[待定] s、[待定]、[待定]次／小时。约定测试中“超限位置仍被标记有效”的次数要求为0，并同时报告试验总次数；有限试验未出现失败，不等于证明失败概率为零。

## 验证与交付要求

先完成算法仿真，再进行双通道硬件验证；通过传导注入或屏蔽环境完成可重复的系统级测试。除上述干扰与欺骗场景外，通道校准重点覆盖：

- 固定幅相和时延偏差，以及温度变化引起的缓慢漂移。
- 两通道不同AGC/ILNA档位，以及档位切换后的重新收敛。
- 无干扰、窄带干扰和宽带干扰条件。
- 校准信号对正常GNSS捕获、跟踪和载噪比的影响。

校准采用独立测量或已知注入误差作为参考，分别报告偏差、标准差和RMS误差；RMS应包含偏差，不能先去均值再作为准确度指标。各工况单独统计，并说明参考测量本身的不确定度，避免仅用重复估计的一致性证明校准准确度。

方案阶段共同明确工作频段、有效带宽、采样率、初始误差范围、温度范围、AGC档位及校准信号功率；同时固定GNSS制式、真实单星功率、卫星数量／几何、轨迹、输出周期与新鲜度限值、测试时长和重复次数。定位采用单点还是RTK、是否使用惯导／辅助信息也须明确，不能混用不同条件的结果。

交付内容：

- 校准、抗干扰及抗欺骗的模型、算法说明与可运行源码，注明所需硬件和外部信息。
- 可复现的仿真及硬件测试配置、输入功率校准记录、位置真值和逐历元位置／有效标志／告警日志。
- 每种场景的可达功率范围、定位误差、可用率、最长中断及恢复时间；报告失败条件，不仅给出成功示例或平均载噪比。
- 接入现有DFE后处理链路及定位结果／告警接口的方案，给出计算量、收敛时间和更新延迟。

请评估三个校准精度目标能否同时达到，以及在相应校准误差下系统可承受的干扰／欺骗水平；给出精度与更新时间的取舍、主要限制和改进路径。待定门限应在正式验收前确定，不能在看到结果后改写为通过。
