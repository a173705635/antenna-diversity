# 无干扰场景：天线方向图增益验证用例

状态：用例设计，尚未按本清单执行；本文没有新增已验证结论。

目标：逐条回答“方向图怎样改变每根天线的接收质量、怎样影响合并收益、接收机不知道增益时损失多少”。先确定用例，再设计代码。沿用通用验证入口，不为每条用例创建新脚本。

## 1. 所有用例的公共条件 C0

## 2. 方法、指标与通过判据

### 2.1 方法身份先固定

- SINGLE-TL：固定参考，不随卫星方向自动换天线。
- BEST-SINGLE：从各通道的理论/独立评分 SNR 中选最大者，仅作评价基准，不代表已经实现选择算法。
- EGC-strict：仅补相位、各通道等幅权值。当前工程尚无独立的此方法入口，需要后续实现或作为独立复算对照。
- MATCHED：按准确复响应幅度加权。当前代码名为 `egc`，实际 `w=a/(aᴴa)`，本清单称 MATCHED，不能写成严格等增益。
- MVDR：当前实现；方向图错误时保留真实样本，只改接收机名义响应。

### 2.2 每条用例的标准输出 O0

1. 每根天线的有效接收增益 dB、目标/热噪声功率及 SNR dB。
2. 各合并方法输出 SNR dB、相对固定 SINGLE-TL 的收益 dB、相对 BEST-SINGLE 的收益 dB。
3. 捕获峰值比（不转 dB）、捕获成功次数/总次数、跟踪成功次数、C/N₀ dB-Hz 和有限样本数。
4. 每个 seed 原始结果；配对差异的均值、标准差及 95% 均值置信区间；成功率附二项 Wilson 95% 区间。
5. 实际配置、源码哈希、理论复算、失败原因。C/N₀ 缺测不能填 0，也不能只保留成功样本后声称整体改善。

### 2.3 统一判据

- A（公式/实现）：用独立公式计算响应幅度和合并 SNR，不能只再调用被测方向图函数。常规有限数值点增益误差 ≤1e-8 dB；深衰减和边界额外核查线性响应，避免把浮点底噪当物理现象。
- B（线性采样）：30 seed 的配对 SNR 差异均值相对理论误差 ≤0.2 dB；记录置信区间。未通过需定位窗口、噪声、相位或数值原因，不能事后放宽门限。
- C（完整链路）：捕获、跟踪、C/N₀ 为接收表现统计，不要求每个 seed 单调，也不要求弱信号全部捕获。不能将未捕获直接判为方向图实现错误。
- D（MVDR）：与解析 MATCHED 上界比较，逐点报告损失；本轮先不预设“必须与 MATCHED 相等”的硬门限。有限样本协方差、加载和信号污染均可能导致差异。
- 图示：每指标、每方法单独窗口；对照场景最多横排两幅。差异类用 dB，捕获比保留比值；重合曲线标注，不能人为错开数值。

独立白噪声、相位准确时，令 gᵢ 为有效功率增益的线性值：

- MATCHED 相对第 r 根收益 = `10log10(Σgᵢ/gᵣ)`。
- EGC-strict 相对第 r 根收益 = `10log10((Σ√gᵢ)²/(N·gᵣ))`。
- MATCHED 相对最强单天线收益 = `10log10(Σgᵢ/max(gᵢ))`。

以上是评价公式，不要求输出信号功率一定增大；权值归一化会改变输出信号和噪声的绝对数值。

## 3. 逐条验证用例

### PAT-01 单通道有效增益传递

- 条件：C0；天线阵列仍保留 TL/BR，但只评价 TL；`pattern_kind="ideal"`。
- 参数：真实和名义 `amplitude_error_db["TL"]` 同设为 0、−3、−6、−10、−20 dB；BR 固定 0 dB。
- 唯一变化：TL 的方向无关幅度响应。该用例是校验基准，不是方向图扫描。
- 对照：同 seed、TL=0 dB。
- 检查：O0 中 TL 的目标功率、热噪声功率和 SNR，另看捕获/跟踪。
- 通过判据：目标功率和 SNR 分别变化 0、−3、−6、−10、−20 dB，热噪声不随此参数变化；按 A/B 验收，接收表现按 C。

### PAT-02 理想等增益双天线基准

- 条件：C0；理想方向图，TL=BR=0 dB。
- 参数：准确名义响应；比较 SINGLE-TL、EGC-strict、MATCHED、MVDR。
- 唯一变化：合并方法，物理 IQ 完全相同。
- 对照：SINGLE-TL。
- 检查：O0，重点为合并热噪声 SNR 收益。
- 通过判据：EGC-strict 与 MATCHED 理论收益均为 3.0103 dB，按 A/B；MVDR 按 D。不能以输出电压大小判断收益。

### PAT-03 双通道共同衰减

- 条件：PAT-02，其余不变。
- 参数：TL/BR 同时取 (−3,−3)、(−6,−6)、(−10,−10)、(−20,−20) dB。
- 唯一变化：共同增益损失。
- 对照：PAT-02 的 (0,0) dB；同时对照每个条件内的 SINGLE-TL。
- 检查：绝对 SNR 变化、同条件合并收益、捕获/跟踪退化。
- 通过判据：相对 PAT-02 的合并 SNR 分别降低 3/6/10/20 dB；相对同条件 TL 的理想收益仍为 3.0103 dB，按 A/B/C。

### PAT-04 一强一弱通道

- 条件：PAT-02；TL 固定 0 dB。
- 参数：BR=0、−3、−6、−10、−20、−40 dB。
- 唯一变化：BR 增益，不改信号源功率或 RF 增益。
- 对照：同条件 SINGLE-TL；PAT-02。
- 检查：EGC-strict、MATCHED 和 MVDR 相对强通道的收益。
- 通过判据：MATCHED 符合 `10log10(1+10^(G_BR/10))`；EGC-strict 符合上述等幅公式，BR 趋于消失时接近 −3.0103 dB。弱通道不能凭“增加天线数”被认定总能改善，按 A/B/D。

### PAT-05 强弱天线互换

- 条件：PAT-04；选增益差 6 和 20 dB。
- 参数：比较 (TL,BR)=(0,−6) 与 (−6,0)，再比较 (0,−20) 与 (−20,0) dB。
- 唯一变化：物理增益对应的天线名字；固定参考仍为 TL。
- 对照：每组交换前后；BEST-SINGLE。
- 检查：理论合并绝对 SNR、相对两种参考的收益。
- 通过判据：解析 MATCHED 绝对 SNR 不因交换改变；有限样本用配对统计比较，不强求逐采样相等。相对固定 TL 的增益允许变化，相对 BEST-SINGLE 的理论收益不变。

### PAT-06 理想模型到参数化模型的衔接

- 条件：C0；卫星方向改为 (0°,90°)，阵元姿态保持 0；两根相同。
- 参数：A=ideal；B=parametric P0；两组真实/名义状态分别一致。
- 唯一变化：方向图模型类型。
- 对照：理想模型。
- 检查：方向图标量幅度与极化投影分别输出；有效增益和 SNR。
- 通过判据：顶点标量增益为 0 dB，但有效增益还包含 Jones 极化投影；用固定 XPD=30 dB 的独立投影复算，不能强行要求参数化与理想有效增益精确相同。按 A/B。

### PAT-07 相同方向图的仰角扫描

- 条件：C0，TL/BR 均使用 P0；方位固定 0°。
- 参数：真实/名义仰角同步取 5、10、20、30、45、60、75、90°。
- 唯一变化：卫星仰角；几何相位及名义导向必须随角度同步更新。
- 对照：同模型仰角 90°；同角度 SINGLE-TL。
- 检查：两根有效增益、SNR 相对顶点变化、同角度合并收益。
- 通过判据：标量增益符合 `max(10log10(sin(el)),−20)`；另计极化投影。两根等幅时 MATCHED/EGC-strict 对单通道理想收益为 3.0103 dB，按 A/B/C。

### PAT-08 轴对称方向图的方位不变性

- 条件：P0，仰角 30°，`azimuth_attenuation_db=0`。
- 参数：真实/名义方位同步为 0、45、90、135、180、225、270、315、360°。
- 唯一变化：卫星方位；保持极化投影控制条件一致。
- 对照：0°，并专门比较 0°与360°。
- 检查：标量增益不变性、有效增益、正确相位对齐后的 SNR。
- 通过判据：标量方向图不随方位变；几何相位可以变，但不应被解释为增益变化。0°/360°响应周期一致；有效响应如有差异须通过独立极化投影解释，按 A/B。

### PAT-09 方位衰减深度

- 条件：P0，方位主瓣 0°，仰角 30°。
- 参数：`azimuth_attenuation_db` 取 0、6、12 dB；每个深度扫描方位 0、90、180、270、360°。
- 唯一设计变量：方位衰减深度；方位作为统一测量网格，这是显式二维试验，不是隐式全参数组合。
- 对照：相同角度深度 0 dB；同深度主瓣 0°。
- 检查：前后向标量增益差及有效 SNR 差。
- 通过判据：背向附加损失为 `A·cos²(30°)=0.75A`，即 0/4.5/9 dB，而不是直接等于参数 A；侧向为 0.375A。按 A/B。

### PAT-10 方位主瓣旋转

- 条件：PAT-09，固定方位衰减深度 12 dB，仰角 30°。
- 参数：`azimuth_peak_deg` 分别为 0、90、180、270°；测量方位 0～330°，步长 30°。
- 唯一变化：主瓣方位参数；不修改阵元姿态或信号强度。
- 对照：主瓣为 0°的曲线。
- 检查：标量增益曲线峰值角及平移关系。
- 通过判据：曲线随主瓣参数按相同角度周期平移；峰值和前后向差不变，按 A/B。仅旋转轴对称方向图的 yaw 不能用来验证方位互补。

### PAT-11 仰角方向图宽度

- 条件：P0，方位衰减为 0；两根相同。
- 参数：`cosine_exponent` 为 1、2、4；每组扫描仰角 5、15、30、45、60、75、90°。
- 唯一设计变量：指数，其他峰值/背瓣不变。
- 对照：相同角度指数 1；每组顶点。
- 检查：偏离顶点时增益及 SNR，进入下限区域的位置。
- 通过判据：标量增益为 `max(10p·log10(sin(el)),−20)`；顶点不变，指数越大离轴衰减越大，达到下限后不继续按余弦衰减。按 A/B。

### PAT-12 背向下限与作用范围

- 条件：P0，方位衰减为 0；两根相同。
- 参数：`back_lobe_gain_db` 为 −10、−20、−30 dB；测量局部仰角 −30、0、1、30、90°。
- 唯一设计变量：背向下限；角度网格含背面、地平线、正面和顶点。
- 对照：相同角度下限 −20 dB。
- 检查：标量增益、有效增益和 SNR。
- 通过判据：局部仰角≤0°时标量增益等于设置下限；30°/90°若未触及下限则不受影响。负仰角仅用于数学模型边界验证，不声称可见 GNSS 卫星从地下入射。

### PAT-13 峰值增益与固定背瓣的区别

- 条件：P0，背瓣固定 −20 dB、方位衰减为 0。
- 参数：`peak_gain_db` 为 −6、0、6 dB；测量局部仰角 0、30、90°。
- 唯一变化：峰值参数，不同步平移背瓣。
- 对照：同角度峰值 0 dB。
- 检查：顶点、正面、背向下限各处增益。
- 通过判据：未触底区域随峰值平移；局部仰角 0°仍为 −20 dB。该用例必须区别于 PAT-03 的“全部方向共同衰减”。

### PAT-14 地平线、周期和顶点边界

- 条件：P0；额外设方位衰减 12 dB。
- 参数：局部仰角 −0.001、0、0.001°；方位 −0.001、0、0.001、359.999、360°；另在仰角90°比较方位0/90/180/270°。
- 唯一目的：边界一致性，使用上述指定配对，不运行全部角度的无意义组合。
- 对照：跨地平线相邻点、等价方位点、顶点不同方位。
- 检查：标量幅度连续性、有效响应和解析公式。
- 通过判据：下限区域无非物理幅度跳变，方位周期一致；顶点方位衰减项为0。不要直接用相位角的±180°跳变判错，应比较复响应或幅度。

### PAT-15 双天线方位互补

- 条件：两根使用 P0，但方位衰减均为12 dB、仰角30°；姿态不旋转。
- 参数：TL 主瓣0°、BR 主瓣180°；方位0～330°步长30°。
- 唯一变化：相对 PAT-09 的同向主瓣，改为两根主瓣相反。
- 对照：相同角度两根主瓣均为0°；固定TL和BEST-SINGLE。
- 检查：逐角度SNR、最差角度SNR、合并相对BEST-SINGLE收益；不把均匀角度网格当真实卫星概率分布。
- 通过判据：各角度MATCHED符合Σg公式，且解析结果不劣于BEST-SINGLE；是否改善最差方向由数据回答，不要求所有角度都优于同向阵列。

### PAT-16 相同真实方向图，接收机幅度假设不同

- 条件：PAT-15，同一seed和角度复用完全相同的物理IQ。
- 参数：A=名义复响应准确；B=名义响应幅度全部设为1，但保留A的准确相位。
- 唯一变化：名义幅度。不能通过整套切换ideal状态顺带改变极化/相位。
- 对照：A/B的MATCHED、MVDR；EGC-strict作独立参照。
- 检查：每点假设误差导致的SNR损失，确认场景/ADC/DFE数据一致。
- 通过判据：等幅点A/B一致；不等幅点按独立权值公式复算。B不允许改变物理信号。只改名义幅度的入口若现有代码不支持，列为后续实现项，不能用混合失配替代。

### PAT-17 阵元数与任意组合

- 条件：第一轮各阵元ideal、0 dB；第二轮P0且方位衰减12 dB，TL/TR/BL/BR主瓣分别0/90/180/270°，仰角30°。
- 参数：双天线6组：TL-TR、TL-BL、TL-BR、TR-BL、TR-BR、BL-BR；三天线4组：TL-TR-BL、TL-TR-BR、TL-BL-BR、TR-BL-BR；四天线1组：TL-TR-BL-BR。
- 测量角度：理想轮固定方位30°；方向图轮方位0～330°步长30°。
- 唯一变化：启用组合；按物理天线名保持噪声实现一致。
- 对照：各组合内BEST-SINGLE；跨组合使用同一可比的绝对SNR，不混用各自首通道基准。
- 通过判据：理想2/3/4天线MATCHED收益分别3.0103/4.7712/6.0206 dB；方向图轮用各组合实际Σg复算，不要求恒定10log10(N)。

### PAT-18 通道排列不变性

- 条件：PAT-15选方位0/90/180°；另取四天线互补场景。
- 参数：TL-BR与BR-TL；TL-TR-BL-BR与BR-BL-TR-TL；参数、噪声和导向按物理名字同步排列。
- 唯一变化：矩阵行顺序，不改变物理通道。
- 对照：排列前后MATCHED、MVDR的绝对SNR和合并输出；SINGLE单独注明参考变化。
- 通过判据：合并结果在浮点容差内一致。SINGLE随第一根变化不是算法错误；不允许把数组行号错当物理天线名。

### PAT-19 增益效应与极化效应分离

- 条件：P0顶点(0°,90°)，两根相同；标量方向图参数固定。
- 参数：信号RHCP不变；阵元nominal polarization分别RHCP/LHCP，XPD固定30 dB，其余不变。
- 唯一变化：极化匹配。作为隔离检查，不纳入“纯标量增益”扫描结论。
- 对照：同一标量方向图的RHCP匹配状态。
- 检查：标量增益、独立Jones投影、有效接收增益和SNR。
- 通过判据：标量增益不变，有效增益按极化内积变化；不能将极化失配产生的损失归因于方向图主瓣宽度。后续姿态研究另立范围。

### PAT-20 线性预算与完整接收链交叉核验

- 条件：抽取已定义代表点：PAT-02；PAT-03共同−10 dB；PAT-04 BR=−20 dB；PAT-15方位0/90/180°。不另造新物理场景。
- 参数：保留真实ADC/DFE配置，另独立计算同尺度线性分量；不是关闭量化后冒充现有链路。
- 唯一差别：评价路径，实际接收IQ不变。
- 对照：解析结果、线性分量预算、真实合并/捕获跟踪。
- 检查：wᴴX与现有合并输出；均方功率与wᴴRw；联合非线性/量化残差；捕获成功率与C/N₀缺测。
- 通过判据：合并及功率恒等式沿用现有1e-8绝对误差/1e-10相对误差检查；解析SNR按A/B。完整链路偏离线性预算时报告残差，不改NF或信号强度“修好”结果。弱场景接收失败按C报告。
