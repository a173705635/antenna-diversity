# 正常启动后弱信号抗欺骗：下一批10轮

只研究可信启动后的单物理源；3/4天线主线，2天线比较；手机原尺寸、固定姿态、24星主配置。基线是上一批 single_source_receiver_spatial.py。只改精简版，不增加异常兜底，不放宽20m目标或30/50m失败口径。

每轮是一个研究问题的提出、实验、结论及下一步，不将单个种子/天线运行算一轮；允许否决假设与保持代码的验证轮，实际算法版本另计。

1. 同样可信启动及噪声增量，将8星暖启动35dB-Hz场景扩到24星，加入无攻击弱信号控制。
2. 按跟踪、增益、星数、码解一致性、载波和恢复条件逐层定位；若35dB-Hz已通过，进一步测30dB-Hz作为边界，不能将扩星冒称算法收益。
3. 在相同观测上检验码载波平滑时间是否限制码解一致性，保留同弧约束和导航门限。
4. 检验原始空间恢复确认是否被单源能量主导，建立投影后真实导向一致性的数值正/负例。
5. 将证据支持的空间确认改动接入完整RF；必须测试真实信号消失负例，不能只看输出增加。
6. 基于前面失败调整有证据的跟踪/平滑机制，测试误差、中断和启动；不预设改动成功。
7. 单源拖曳、撤除、近源簇回归，筛选候选并保留否决记录。
8. 两天线对照及另一噪声级，解释收益与空间维度/观测冗余的关系。
9. 冻结候选及运行依赖后测试新种子；保留未按时启动和失败记录。
10. 延长暖启动弱信号连续RF，检查末段性能；完整重演、输入与源码校验、方法和逐轮报告。

诊断可复用冻结跟踪，但前端修改必须重跑RF。保护输出仍指算法有依据地暂停，不引入文件/类型/异常兜底。记录所有机会的≤20m比例、≥30/50m发布、最大误差、最长缺失，以及攻击前实际发布。只几秒仿真不代表台架或商用能力。

## 根据第6轮失败调整后半程

第6轮在真实信号消失负例出现一次88.85m错误，第7轮改为优先修复陈旧质量观测进入导航的问题，原拟拖曳/撤除/近源回归不再声称已完成。第8轮处理初相位拟合下质量估计的自由度，并进行完整RF回归、30dB-Hz无攻击控制和两天线比较。第9轮在候选冻结后检验新种子的弱信号及真实消失；第10轮延长弱信号录波并审计。未运行的原计划工况明确留到后续，不能凭上一批结果直接覆盖本批改动。
