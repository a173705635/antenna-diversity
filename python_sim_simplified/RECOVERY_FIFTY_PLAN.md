# 信号恢复方向：50 轮研究计划

目标：在固定手机四角阵列内，从真假混合复数采样中估计抑制权重、提取码延迟、解算位置，检验持续攻击下恢复真实导航的条件。继承商业需求，但本研究不是硬件验收。

本次使用 writing-plans 的可验证任务划分，在用户指定精简目录内直接执行，不迁移或改动已有未提交研究。

## 数据与边界

- 不再向接收机直接注入位置误差；伪位置只能改变发射端码延迟和载波相位。
- 使用 GPS C/A、共同单源阵列响应、加性复高斯噪声，1 ms 周期的带限复基带快照。长时采用每秒一个相干积累等效快照；不是完整连续射频、PLL、导航电文解码或实时计算验收。
- 接收机仅使用混合采样、已知 PRN、辅助星历/粗时间、名义阵列及估计姿态；真实位置、真假分量和攻击开关只用于生成及评分。
- baseline 固定为单天线；另设正常无攻击配对。候选比较 MVDR、观测主特征向量投影、带卫星方向约束的投影；任何真方向上界只单列诊断。
- PVT 无解、错误捕获、正常误置零都计入完整分母。记录 20/30/50 m、P95、可用率、最长连续有效段、卫星数与几何、恢复后重新失效。
- 校准/开发种子与最终新种子分离；冻结候选后才生成最终数据。轮次指研究问题和对照，不把种子重复称为算法迭代。

## 执行任务

- [x] 实现 `signal_recovery.py`：共享 IQ 源、数据估计阵列权重、全码相位搜索与局部延迟跟踪、复用 `solve_position`；用无噪声延迟/位置、混合源消零、不可分辨和无真实信号测试验证。
- [x] 实现 `audit_recovery_fifty.py`：每轮冻结配置、配对输入、逐历元轨迹与汇总，保留源文件哈希。
- [x] 1–10 轮：单天线与空间方法、正常对照、功率和源方向初筛，先检验恢复链路本身。
- [x] 11–20 轮：根据初筛选择方法，考察 2/3/4 天线、8/12/16/24 卫星、部分与全星伪造、真实信号消失。
- [x] 21–30 轮：相位/幅度/位置标定、姿态误差、时间漂移、反射和 ADC 截幅；依据失败提出并比较改进。
- [x] 31–40 轮：冻结改进方法，考察低 C/N0、同方向退化、功率变化、慢拖偏和撤除；不以删除失败样本提高指标。
- [x] 41–50 轮：冻结全部参数，生成独立种子，开展长时与边界验证；不能因最终结果重新调参。
- [x] 输出 `RECOVERY_FIFTY_RESEARCH.md`、逐轮表、轨迹与比较图、可重现命令、限制和下一步；运行相关及全量测试。

自检重点：IQ 只在生成端使用真值；输出位置由码延迟求解；稀疏快照不冒充连续跟踪；商业可信输出未认证；源特征向量不等于已认证攻击方向；拒绝输出不等于恢复成功。

执行结果：50 轮研究、补充连续接收检查、80 条历史样本回放及 250 项全量测试完成。长期快照不是连续导航验收，商用目标未达成；失败与未覆盖项见研究报告。
