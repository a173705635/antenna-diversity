# 24星扩展与无攻击中断排查

沿用当前审计修正版，不改变定位、恢复或观测准入门限。仅在精简目录新增实验，不改写20轮冻结结果。

- 24颗同频GPS L1 C/A等效信号；前三颗近源时，额外16颗仍按随机天空分布。不是多星座实测结论。
- 原8颗PRN的方向、距离、多普勒、导航比特、噪声样本和通道误差保持不变，追加16颗。新生成器修正了按总星数重新等分多普勒导致前8星也变动的问题，并有配对回归测试。
- 三个已有种子114001/114013/114037，正常无攻击、一星重合、三星±0.5°近源三类；2秒连续RF，0.3秒攻击开始，三/四天线取同一四路录波子集。属于已知几何的受控扩展，不宣称独立留出。
- 每星真实C/N₀为45 dB-Hz，单欺骗源每PRN高10 dB、伪造100m东偏；24星时该源也伪造全部24个PRN，并非给接收机添加16颗没有被伪造的理想干净星。
- 不给接收机提供真假/近源真值标签。沿用实测锁定、C/N₀、投影保留增益等观测准入；检查剩余可用星数及PVT结果。
- 单独用无攻击114001作空间投影关闭消融，保留实际标定、捕获、跟踪和导航门限。该消融使用实验已知无攻击条件定位问题，不能直接部署成抗欺骗方案。
- 导航逐历元诊断记录须与原版输出一致，再分析直接拒绝和恢复等待各占多少。
