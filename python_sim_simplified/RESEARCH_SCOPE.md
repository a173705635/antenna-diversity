# 当前研究范围

2026-09-15 用户明确：研究不考虑冷启动场景。本文件约束后续研究与主验收；此前冻结报告按当时范围保留，不追改统计。

- 起始条件：无欺骗的初始化阶段，接收机通过实际观测完成正常捕获、跟踪、定位及所需初始化标定，随后引入单源欺骗攻击。初始化状态来自接收机估计，不使用生成器真值替代。
- 攻击源数量：仅考虑单个物理发射源产生欺骗信号。该源可以同时伪造多颗卫星/多个PRN，覆盖部分或全部真实卫星信号；这仍属于单源攻击。多处物理发射源的协同或分布式欺骗明确排除，不作为主验收、优化目标或交付阻塞项；历史多源反例仅保留记录。
- 单源限定不排除该源的传播反射、真实信号多径以及接收机通道偏差；这些不等同于多个欺骗发射源。当前仅按用户明确的源数量限制收窄范围。
- 排除：设备启动时欺骗已经存在，以及没有建立正常初始状态就要求抗欺骗定位的冷启动攻击。后续不将这些案例列为主目标、主验收分母或阻塞项。
- 继续覆盖：正常初始化后的低C/N₀、攻击接入与牵引、真实信号减弱或消失、运动、通道漂移、失锁和重捕获。攻击中的重捕获仍需判断来源，不能自动沿用攻击前的可信性。
- 验证时显式记录初始化完成时刻、攻击开始时刻及其间隔。不能仅凭仿真经过固定100ms，就宣称正常初始化已完成；初始化失败独立报告，不能静默删除失败种子美化成功率。
- 天线配置：三天线作为最低目标配置，四天线作为主研究配置；沿用手机固定安装尺寸。三、四天线均需在上述非冷启动范围内验证，最低目标不表示已经证实能够保底达标。
- 二天线保留为性能对照。性能差不要求必须修复，也不作为三、四天线交付的阻塞项；但必须报告定位误差、输出可用率、连续性及错误放行，并用可复现实验说明原因和适用边界。区分阵列几何与空间自由度、抑制真实信号的损失、同步及标定偏差和算法实现问题，不能把失败直接归因于天线数量。
- 配置对比优先使用同一四通道同步观测的二、三、四天线子集，保持卫星分布、攻击、初始化条件及处理方法可比；必要时通过消融实验定位性能差异。
- 攻击下持续定位和超出可信边界时保护输出的目标延续。攻击后定位误差、连续性及错误放行分别统计。

该范围调整不意味着旧冷启动失败已被解决，也不意味着已有含冷启动的汇总成绩可以直接代表新范围。下一次验证应预先定义符合本范围的场景，冻结后独立运行。
