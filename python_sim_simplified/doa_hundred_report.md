# 061–080：手机小阵列单发射源方向研究

这20轮完成了独立模型或估计器变化，并保存了各轮提案、实际源码快照、同输入结果和结论。它们研究的是条件方向可辨识性及误差，**没有证明米级导航，没有计算或改善PVT，不能据此判定≤20 m、≥30 m或≥50 m导航指标**。没有RF实测、IMU实测、真实手机天线方向图或实测幅相标定。

源码：`doa_hundred.py`；冻结验证：`doa_hundred_validate.py`；结果位于`results/research-hundred/iteration061`至`iteration080`。未修改其他仿真模块，没有将候选研究自动接入生产导航。

## 模型和可观测性

采用现有 `presets.mate70_phase_centers` 的 0.0759 × 0.1609 m 平面四角位置，L1波长为299792458/1575.42e6 m。复相位约定与`signal_recovery.steering`相同：

`a_m(u) = exp(+j k p_m·u)`，`u=(cos(el)cos(az), cos(el)sin(az), sin(el))`。

这与`spatial_direction`历史载波距离的负号及其方位角定义不同；测试直接对照现有IQ steering，未混用两套约定。所有xy误差都是单位方向向量水平分量误差，无量纲，不能写成度或米。

相对相位满足 `phi + 2πn = k B_xy q`。061在物理单位圆内枚举整数解；范围[-2,2]覆盖本手机L1矩形基线的相位分支，不是任意阵列通用上限。平面几何只能观测q=(ux,uy)，每个内部解均对应 `uz=±sqrt(1-|q|²)`。两天线仅给一个投影，球面与平面交集为圆。四角关系BR=TR+BL−TL，因此第四角增加冗余观测，不改变无噪声矩形相位格的代数约束。

单个未知源若允许任意通道相位g，则任意另一个方向v可用 `g'_m=g_m exp(j k p_m·(u-v))` 给出完全相同数据。这不是优化收敛问题。显式外部标定、标定误差界或姿态观测是额外信息，不可当成从同一未知源自动得到。
