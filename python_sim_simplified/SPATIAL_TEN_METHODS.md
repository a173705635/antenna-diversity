# 空间触发修复的模型与实验口径

每个20ms窗口按1ms相关，已捕获PRN的相关向量组成 Z∈C^(M×N)，N=PRN数×20。a_j为标称真实卫星导向（每个1ms列重复）；可信启动已估计通道相位和线性漂移。噪声和数据比特来自原连续RF，不用真值产生接收机相关量。

H0：z_j=a_j α_j+n_j。H1：z_j=a_j α_j+v β_j+n_j，所有PRN共享同一复空间向量v。α、β逐相关列自由变化，涵盖不同PRN相位/比特；v只标识空间响应，不直接等价于已校准的方位角。

H0最小二乘：α̂_j=(a_jᴴz_j)/(a_jᴴa_j)，E0=Σ||z_j−a_jα̂_j||²。

H1沿用原交替拟合（第3轮为2次，最终候选为6次），P=I−vvᴴ，α̂_j=(a_jᴴPz_j)/(a_jᴴPa_j+0.01M)，E1=Σ||P(z_j−a_jα̂_j)||²。0.01M是原有正则模型项；并非新增异常兜底。

相关噪声尺度 ν̂=mean(|x_m[n]|²)/2046，来自当前窗口全部原始采样。信号能量也进入分子，因此相对理想白噪声估计偏大；这是保守的实测尺度，但不是经过干扰消除的无偏噪声估计。不同PRN相关值有互相关，不能当完全独立统计样本。

研究分数 T=(E0−E1)/[ν̂(N+M−1)]。N个复β参数和M−1个复方向参数是新增参数数目的近似计数。T≥3启用原投影波束，否则采用原真实卫星波束a/M。该式是复杂度及噪声归一化证据，不冒称严格GLRT、BIC或已标定虚警概率。三/四天线时须实测其区分能力；两天线H1可饱和拟合、方向可辨识性更弱，不能由低残差保证源估计可靠。

原触发器用原始ZZᴴ特征值比；正常天空本来就可能各向异性。第2轮残差比例阈值虽然可区分强信号样本，却会把噪声当异常；第3轮改为上述噪声归一化残差减少量。

冻结和评价：原接收机复制为 results/spatial-ten/baseline.py；每个实际候选单独保存源码，前端改动后必须重跑同RF捕获跟踪。只导航重演不能证明新前端有效。结果分母包含无输出；初始化时间之外另查攻击前实际发布。正常场景的0.3s只是统一评分分界，不是攻击。数值测试、相关域实验、完整RF案例数及研究轮数分别统计。

评分沿用20ms可用时标，接入边界包含少量缓冲过渡；只在边界发布几个点不构成持续抗欺骗导航。6秒记录另检查最后100个10ms评分历元，避免只报告接入前后的短暂成功。

目前前提仍包括同步通道、可用星历和粗码周期辅助、准确标称姿态及阵列导向、固定机身姿态和开阔视线。单个物理源可以伪造全部PRN。不使用攻击时刻、真假标签、源方向、真实接收机位置参与候选算法。所有结果仅支持测试模型和测试时长，非实测或商用完整性声明。
