# 精密信号流（Precision Signal Flow）

这套图形语言把接收机视为一条从微弱空间波前到稳定估计量的“能量与信息通道”。宽阔的留白负责区分物理域、数字前端域和基带算法域，模块只保留决定理解的名称、数字与单位。所有间距、基线和连线都服从严格网格，使复杂系统在第一眼仍然能够顺序阅读；细节则在第二眼以小型注释逐层显现。

颜色不是装饰，而是信号语义。绿色始终代表目标 GNSS 信号及其保持约束，珊瑚色始终代表干扰及被压制方向，蓝色代表确定性的数字处理，紫色代表估计和闭环反馈。大面积背景保持克制，让少量颜色像示波器标记一样准确。每种颜色、线宽和圆角都经过一致校准，呈现出经过反复推敲的工程制图质感。

尺度体现处理层级：阶段容器稳定、安静，内部算子紧凑；主信号流使用连续实线，控制或估计反馈使用虚线。重复的采样率、位宽和维度被压缩为一条底部时间带，让信息密度高而不拥挤。构图追求非对称平衡——左侧物理场景留有空间感，右侧三分支与闭环具有更高密度，呼应信息从波形逐渐凝结为观测量的过程。

文字作为精确的视觉锚点，而不是解释性段落。标题、阶段编号、核心运算和少量实测结果共同建立阅读节奏；公式只在不可替代时出现。最终图应像资深接收机工程师和信息设计师共同打磨的制品，每一条连线和每一个数值都经得起核对，体现深厚专业判断与细致手工校准。

整体执行强调可编辑与可维护。几何元素保持独立、分组清晰，避免依赖不可重建的位图效果；视觉精度来自对齐、层级和一致性，而非堆叠装饰。成品应在缩小后仍能读出五大阶段，在放大后又能检查频率规划、数据尺寸与分支结果，达到可用于技术报告的精密完成度。
