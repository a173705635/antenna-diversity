# 冻结门限下的多径存在性边界

## 设计

沿用 `threshold.json` 中冻结的 6.614366289709286 dB 门限，不进行重新校准。
保持原 12 个相关搜索点、4 ms 相干累加、6 ms 记录、连续信号源、RF 热噪声和量化。
所有外加干扰关闭。仍是已知 LOS 方向、准确校准、理想四天线、至多单反射径模型。

每个点 100 次，使用 60000～60099 新种子，与校准/前次评估集合不重叠。
不同点使用共同随机种子，便于配对比较；不能把不同点当作相互独立样本合并统计。
每个点的 95% 精确区间单独计算，不是整个扫描的同时置信带。

| 扫描 | 取值 | 固定条件 |
|---|---|---|
| 功率 | -30、-24、-18、-12、-6、0 dB | 0.5 chip，110°/15° |
| 超额时延 | 0、0.05、0.1、0.25、0.5、1、2、3 chip | -6 dB，110°/15° |
| 角间隔 | 0、2、5、10、20、40、60° | -6 dB、0.5 chip；LOS 30°/60°，反射 30°/(60°−间隔) |
| 无多径对照 | 100 条 | 同一噪声/初始相位、延迟、多普勒分布 |

总计 22×100=2200 条。上述是单因素切面，不是功率×时延×方向的联合性能地图。
零超额时延场景用于检查空间残余，不意味着已经证明两条路径的时间可辨识性。

## 复现

```powershell
python python_sim_simplified/audit_detection_boundaries.py
```

目录 `results/detection_boundaries/` 保存逐点 JSON、汇总 `summary.json` 和图 `boundaries.png`。
逐点文件存在时复用，门限文件 SHA-256 必须一致；脚本结束再次检查门限未改变。
若修改生成/检测代码或扫描定义，应使用新的结果目录，避免复用旧 checkpoint。
门限对应有限的固定接收机和噪声条件，不能直接用于实测或其他模型。

## 判读规则

阳性只表示当前空间残余统计量超过门限，不证明路径数量、DOA 或时延估计正确。
捕获失败单列，阳性率分母同时提供全部记录数与有效记录数，不能删掉失败记录再只报较好结果。
100 次样本只用于初步边界定位，100/100 也不代表真实检测率必然等于 100%。

## 实测结果

22 个点共 2200 条记录全部捕获成功、分数有效。由原始分数重算了全部阳性数/区间，
确认冻结门限文件散列未改变。新无多径对照为 0/100，双侧 95% 区间上界仍为 3.62%。

### 功率切面

| 反射相对功率 dB | 阳性次数 | 阳性率 |
|---|---:|---:|
| -30 | 1/100 | 1% |
| -24 | 6/100 | 6% |
| -18 | 37/100 | 37% |
| -12 | 100/100 | 100% |
| -6 | 100/100 | 100% |
| 0 | 100/100 | 100% |

本切面的过渡区位于 -18 与 -12 dB 之间；没有更密扫描，不能给出精确的 90% 检出功率阈值。
该范围只对应当前 LOS 功率、噪声、记录长度和几何，不是接收机的通用灵敏度。

### 角度切面

| 角间隔 | 阳性次数 | 投影后反射功率保留比例（理论阵列响应） |
|---|---:|---:|
| 0° | 0/100 | 0% |
| 2° | 0/100 | 0.263% |
| 5° | 6/100 | 1.582% |
| 10° | 39/100 | 5.851% |
| 20° | 97/100 | 19.110% |
| 40° | 100/100 | 45.078% |
| 60° | 100/100 | 54.521% |

投影功率保留比例为 `1 - |a_LOSᴴ a_echo|²/(||a_LOS||² ||a_echo||²)`，
仅在本轮准确阵列和普通正交投影模型下成立。2° 时强反射也被一并去掉了约 99.74% 的功率。
这是方法结构导致的近方向盲区，不能简单通过细化 DOA 搜索网格恢复被投影删除的信息。
角度切面与功率切面的“固定反射方向”不同，不能把两张曲线直接拼成联合门限。

### 时延切面

0、0.05、0.1、0.25、0.5、1、2、3 chip 八个点均为 100/100 阳性。
这只说明在当前 -6 dB、异方向几何下存在性统计量能发现空间残余。
检测器的搜索网格仍为 0.25 chip，因此结果绝不表示它已达到 0.05 chip 的参数分辨率。
同样不能外推到弱反射、同方向或更多路径。

## 方案意义与下一步

已确认两个主要限制：弱反射时残余信噪比不足，近 LOS 方向时反射被投影连带删除。
下一步应设计单通道/合并通道的时间结构检测作为互补候选，在保留 LOS 的数据上比较
“单路径模型”与“双路径模型”，并使用独立 H0 校准门限。不要仅降低现有空间门限。
新分支仍需区分存在性与参数可辨识性；同方向且零时延的两路相干信号可等价为单路径复幅度，
该极限在当前静态模型下无法唯一辨别，必须作为明确边界。
