# 跟踪载波相位基准审计

## 问题与方法

检查独立捕获/跟踪后，扣除两天线已知几何的相位差，究竟留下整数周差还是任意实数初始化偏差。未使用200～400 ms中位数，未拟合或减去任何参考常数，未修改生产跟踪代码或SDCP。

入口 `audit_phase_origin.py`。单PRN GPS L1、双天线、无多径/干扰/热噪声，已知几何相位距离差−32.865664 mm；RF33 MHz，DFE抽取5，跟踪6.6 MHz。共同载波初相分别0.35、2.4、−2.2 rad。多普勒1375.25 Hz，避免整毫秒起点差恰巧对应整数周。

每个输入比较四种条件：正常起点/零NCO初相；TL/TR分别在4/17 ms门限后开始跟踪；不同起点再将NCO初相设为1.7/−2.1 rad；最后增加TR已知0.4 rad通道旋转反例。捕获码相位和频率来自实际捕获，未提供真值捕获结果；真正跟踪起点是门限后的下一个主码对齐位置。NCO初相通过测试侧包装状态构造函数设置，生产默认仍为零。

在相同绝对时刻，用块开始的累积相位/频率构造观测，统计300～390 ms。计算：

```
cycles = (phi_TR - phi_TL)/(2*pi) - geometry_m/wavelength
fraction = cycles - round(cycles)
```

`round`在这里用于检验离最近整数还有多少，并不是已经验证的整周固定算法；没有减去数据均值。保存完整cycles、fraction和两路NCO历史，整数分支变化可复核。

## 分层与结果解释

- 理想基带：矩形码、精确复数载波，不经过RF/DFE量化。
- 线性DFE：实际双天线信号源和DDC/FIR，绕过RF与DFE输出量化。
- 标称量化：−128.5 dBm、原RF/DFE量化，但热噪声设零。
- 可见量化对照：仅将信号功率设为−90 dBm，保留RF限幅/ADC/DFE量化。它用于确保无噪声输入跨越量化级，不代表标称GNSS灵敏度性能。

0.4 rad通道旋转注入在DFE输出、跟踪输入处，是已知相位偏置控制，不是实际硬件温漂模型。预期小数距离偏差为 `lambda*0.4/(2*pi)=12.114471 mm`；另外保存扣除这个已知控制量后的误差。该已知控制量只用于本审计评分，不传给PLL或SDCP。

理想情况下PLL会收敛到输入相位（模2π），独立初始化不必留下任意实数偏差。实数偏差可能来自硬件、量化、模型失配或失锁，必须与整数分支区分。无噪声时旧C/N0估计会有除零警告，未将该C/N0输出作为验证指标。

## 对SDCP的含义

共36个完整变体、3个标称无噪声不可用条件。扣除已知几何后，不注入通道偏置的结果：理想基带小数周距离误差约1e-13 m；线性DFE最坏6.29e-9 m；−90 dBm量化对照最坏0.0295 mm。改变跟踪门限4→17 ms和NCO初相后，整数分支可由0/1周变为−17/−18/−19周，但小数周仍恢复到相同物理相位。这个结论否定了当前理想模型下“独立NCO初始化必然造成任意实数相位常数”的推断。

0.4 rad通道旋转留下约12.114 mm小数距离偏置；理想/线性DFE扣除此已知控制量后仍回到上述精度，量化对照仍约0.03 mm以内。真实通道偏置与整数分支必须分开处理，不能凭初始化方式把二者混为一谈。

归档见[data/2026-09-11-phase-origin](data/2026-09-11-phase-origin/)，38个文件哈希及36组分数周序列已复核。最终116项测试通过（107.29秒）；有一个既有无噪声C/N0除零警告，不影响本次相位判据。

本审计不能证明任意真实接收机都只有整数差，但可以检验当前仿真是否有必要用未知参考中位数消掉任意常数。若经几何/通道校准后只剩整数周，可研究以波长为周期的残差，避免直接吸收启动时多径；它仍有模周期歧义、通道偏差、共模多径和失锁边界。

本轮未验证L1导航数据符号翻转、半周模糊度、真实本振/硬件重启、多普勒与功率全范围、温漂或多星互相关，不将理想相位可恢复等同于实机整周已可可靠固定。原SDCP实现和先前结果保持不变。
