# 实验报告与结果

新增审查：[全分支精简版合规与问题检查](2026-09-14-branch-simplified-review.md)：4 本地＋9 远端分支，列出防御包装、异常吞噬、默认回退、重复判断及规则未入库等 8 类问题；当前与三个历史精简版回归通过。本轮仅审查，不改算法。

新增实现：[RF／IMU 数据与时间契约首版](2026-09-14-sensor-contract.md)：独立校验器与旧 RF 适配，19 项针对性测试；48 条旧记录、36 个布局批次保持原观测结果，缺失硬件/标定证据显式保留。尚非在线保护或 IMU 导航。

新增设计草案：[手机尺寸抗欺骗 B 首发与 C 升级](../superpowers/specs/2026-09-14-commercial-antispoofing-design.md)：基于需求访谈形成四天线＋IMU 架构、三态输出、旁路空间抑制与分阶段验收；待用户评审，非已实现或商用放行。

新增建模：[工程误差统一数学模型](2026-09-14-engineering-error-model.md)：逐项继承 49 项清单，补充 16 项系统约束，给出复数信号链、SD/DD 协方差、测向可观测性及标定验证方法；解析核验，非新增硬件实验。

新增研究：[原手机阵列方向候选与星间双差](2026-09-14-doa-double-difference.md)：已实现候选测向与参考星法，验证偏差抵消、同源方向消失及多解/混合失败；未获得可靠唯一方向。

新增实验：[1 米阵列间距对照](2026-09-14-spacing-1m.md)：三 PRN 部分同源模型检出率三天线 90.92%、四天线 98.22%；保留混合信号退步，含 48 路 RF 记录与重算验证。

新增调研：[GPSPATRON 算法公开程度](2026-09-14-gpspatron-algorithm-disclosure.md)：专利线索、公开原理与校准要求、本地实现差异及可复现论文；未新增实验。

最新：[GPSPATRON公开原理启发的2–4天线空间检测](2026-09-14-gpspatron-spatial-diversity.md)。三星簇识别改善部分同源检出，按相同虚警目标比较天线数与判据；包括完整数字RF链、因果输出门控、失败场景和可重建数据。非专有算法复刻，非真实多天线硬件验证。

本次归档入口：[抗欺骗与 SDCP 观测基础阶段归档](2026-09-13-research-checkpoint.md)，包含范围、主要结论、限制及提交前核验记录。

当前 SDCP 基础资料：[全链路偏差清单、影响因素与处理边界](2026-09-13-sdcp-error-inventory.md)。49 项系统审查，含参考数值、校准条件、不可解决项及本项目验证覆盖；资料整理，不是新增检测实验。

最新：[真实录波通用接收模块与码定位](2026-09-13-recorded-receiver.md)：40 秒公开 IQ 中 10 星解出星历，380 次离线码定位；水平 RMS 4.384 m、垂向均值 +39.268 m，均相对元数据。独立 C 星历对照通过，尚未完成偏移归因和真实 SDCP。

前序：[单天线真实 GNSS 录波验证](2026-09-13-real-single-antenna.md)。公开 HackRF 实测 IQ，10 星独立跟踪、导航字结构及 DFE 量化对照；保留录波连续性异常和原 PLL 失败证据，该轮不涉及真实定位/SDCP 精度。

最新：[外部GNSSSimulator.jl双天线信号源交叉验证](2026-09-13-external-gnss-source.md)。已实际运行、完成原生测试及现有接收链对照，保留源码快照、依赖锁文件与未取余SDCP结果。

最新SDCP：[天线与RF固定幅相偏差](2026-09-13-sdcp-hardware-bias.md)。完整双RF/DFE/跟踪六场景×两噪声对；未取余残差保留固定偏置，参数为人为设定，非硬件实测。

SDCP新增[相位弧与参考生命周期原型](2026-09-13-sdcp-arc-lifecycle.md)：质量恢复不自动延续旧参考；已有RF回放验证，默认流程未接入，外部重新准入证据尚需研究。

最新SDCP验证：[单路RF中断、环路恢复与重捕](2026-09-13-sdcp-tracking-gap.md)。质量恢复不保证旧相位弧连续；本批原环路约3周变化被取余隐藏，新环路整数起点不同。尚未实现自动相位弧认证。

当前优先工作：先审清SDCP观测基础，再推进识别。见[定义、误差、状态与使用条件](2026-09-13-sdcp-observation-contract.md)；本轮为源码与确定性对照审计，实际失锁重捕状态闭环仍待验证。

**当前新阶段：天线分集抗欺骗。** 已完成[双天线空间一致性首轮实现与验证](2026-09-12-antenna-spoofing-validation.md)：同源全星替代可见，部分欺骗漏检、真假混合有未知区间；不等于认证或导航恢复。多径阶段仍收口，极化分集暂停。

此前多径阶段已收口，后续不推进极化分集。完整范围、结论及未完成项见[阶段总结与交接](2026-09-12-multipath-stage-closeout.md)。
