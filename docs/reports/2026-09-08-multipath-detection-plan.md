# 单反射径检测方案与验证计划

## 研究目标

本窗口主线调整为检测，不以 LCMV、跟踪精度或抑制增益作为检测成功标准。
代码共用现有生成、RF/DFE 和天线模型，场景关闭所有外加干扰，保留接收机热噪声。
第一阶段区分“仅直达径”和“直达径 + 至多一条静态镜面反射径”，并估计可分辨反射径的超额时延与方向。
不宣称已解决任意路径数量、多星或 NLOS 检测。

## 已知条件与未知量

已知/假定：PRN、采样率、天线几何与复数响应、LOS 方向、通道相干校准；粗捕获得到码区间和多普勒。
LOS 方向目前来自配置，不是本方案估计结果。先验证假设准确的理想阵列，再引入已知范围的误差。
未知：是否有反射径、LOS 精确码时延、反射径时延和方向、各路径复数幅度。
初期假定反射径与 LOS 多普勒相同且短时间静态；差分多普勒另作模型失配实验。

一个简化的阵列基带模型为：

`x[n] = b0 a0 c(tn − τ0) + b1 a1 c(tn − τ1) + v[n]`

这里 c 包含明确的连续码片/接收带宽定义；b 为未知复数幅度，a 为阵列响应。
H0 是 b1=0；H1 是存在一条可分辨反射径。超额时延为 τ1−τ0。
捕获峰只是搜索起点，不能直接作为 τ0。

## 路线选择

| 路线 | 优点 | 主要边界 |
|---|---|---|
| 单通道相关曲线检测 | 不依赖反射 DOA，可检查同方向反射 | 短时延相关主瓣重叠，难与 LOS 参数误差区分 |
| LOS 空间投影后的残余检测 | 可去掉准确模型下的 LOS，便于检查短时延反射 | 同方向/近共线反射会一起消失，对校准误差敏感 |
| 时间与空间联合检测 | 利用多天线与码时延信息，参数可以互相校验 | 计算与门限校准更复杂，仍有不可辨识区域 |

第一版采用“空间投影生成候选 + 连续时延/方向拟合 + 独立门限验证”的联合路线。
保留同方向案例作为明确失败边界，未来增加单通道时间结构分支；不将漏检包装成不存在多径。

## 拟议流程

1. **输入有效性**：确认多通道长度、饱和情况、相干性和捕获状态。捕获失败单列为不可检测，不能计为 H0 判断正确。
2. **粗同步**：固定 EGC 获得初始码/频率搜索区间，采用连续本地码；不按真值挑选更有利的捕获分支。
3. **去除 LOS 空间分量**：在校准后的噪声度量下消除 LOS 响应。第一步使用独立等功率噪声假设；实测相关噪声需要估计并白化。
4. **候选搜索**：搜索相对粗捕获峰的正负偏移，覆盖基准偏移；短块处理并控制残余频差，避免直接长时间相干累加抵消。
5. **存在性统计量**：用归一化匹配能量的搜索最大值作为候选统计量；门限必须对整个搜索过程校准，不能用单个网格点的门限代替。
6. **连续参数拟合**：方向先粗后细，估计一条反射方向；条件允许时分离两个空间分量，分别估计 τ0、τ1，再求超额时延。
7. **可辨识与拟合检查**：检查空间近共线、搜索边界、方向多解、参数稳定性与残差。数值优化收敛不等于参数可靠。
8. **输出**：存在反射证据/未达到门限/不可辨识/输入无效；另列时延、方向、参考基准和可靠性标记。

“存在反射证据”应经过校准统计量判定；“没有达到门限”只表示未检出，不保证不存在反射。
当模型不满足，例如多条路径、LOS 失配或差分多普勒，需标记范围外或残差异常，不应强行给唯一方向。

## 门限与验证纪律

- 先声明目标虚警率，例如每条记录 1%，而非每个搜索点 1%。这只是设计目标，当前尚未达标验证。
- H0 校准种子与 H0/H1 评估种子严格分离。先冻结门限，再看评估集；不同噪声/搜索长度要重新验证。
- 初步建议不少于 500 条校准记录、1000 条独立 H0 评估记录；若要更严格的尾部概率，需要更多样本。
- H0 中改变 LOS 初始相位/码延迟、噪声、方向和允许的校准误差，避免只适应一个确定 LOS。
- H1 分开扫描反射功率、时延、相位、角间隔，不把全部情况混成一个平均检测率。
- 精度统计必须同时报告有效估计数、漏检数和拒绝数；不能只报告成功样本的误差均值。

## 第一阶段验收表

| 项目 | 定义 |
|---|---|
| 虚警率 | H0 中报告存在反射的记录数 / 全部 H0 记录数；另列捕获失败 |
| 候选检出率 | H1 中生成候选的记录数 / 全部 H1 记录数；不等于正确识别率 |
| 正确识别率 | H1 中正确关联且满足预先规定时延/角度容差的记录数 / 全部 H1 记录数 |
| 参数误差 | 数据选出的首候选与真值比较，列中位数/分位数及样本数 |
| 不可辨识率 | 因近共线、边界或多解拒绝输出的比例 |
| 适用边界 | 对同方向、短时延、弱反射、非网格方向、模型误差分别报告 |

第一阶段不应将“检出几个局部峰”解释为“有几条物理路径”。最多单反射模型确认后再设计多路径数检验。

全部 80 次 EGC 捕获成功。以下为原检测器候选统计，不是正确识别率。

| 反射 110°/15° | 20/20 | 13.07° | 0 | 0.01458 |
| 反射 113°/17° | 20/20 | 7.87° | 0.125 | 0.01551 |

同方向的唯一候选不能视为正确检出；现有空间投影无法保留同方向反射信息。
噪声下方向误差已经超过单纯网格步长，说明减小 5° 网格并不保证解决问题。
应先建立存在性门限和参数置信评估，再评价连续方向细化的收益。
原时延恰好位于 0.5 chip 网格时的零中位数受离散网格与试验真值选择影响，不代表普适零误差。
