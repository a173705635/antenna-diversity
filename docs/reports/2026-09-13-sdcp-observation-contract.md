# SDCP观测基础审计：定义、误差预算、状态和识别边界

2026-09-13。当前决定：先明确SDCP可用条件，再研究识别；不新增欺骗检测器或抑制策略。本轮审查源码与既有报告，增加确定性观测域反例，不生成新RF、不宣称新的检测概率。

## 1. 结论

当前SDCP是有条件的空间一致性观测，不是自带来源认证的测量。要先统一符号、声明补偿依据、建立相位弧有效性，再解释残差。现有模块能完成数值计算和部分质量门控，但不能独立确认重捕后相位分支、预测几何或硬件校准可信。

## 2. 从接收机相位到单差

采用本报告统一的距离符号：A为参考、B为第二天线，D_j=L_Bj−L_Aj；预测几何g_j=ρ_Bj−ρ_Aj，远场近似−b·u_j，b指向A到B。必须说明b与u处于同一坐标系。

源码 `positioning.carrier_range` 对本地产生信号的负距离相位约定，计算 L=−λφ_NCO/(2π)，并用保存的NCO频率将相位推进到所请求的共同历元。不能再次对累计相位unwrap，也不能先舍入为整周。该函数只重建观测，不认证锁定、半周或真伪。

| 实现/入口 | 实际定义及作用 | 不能误解为 |
|---|---|---|
| `modified_sdcp` | 输入φ_B−φ_A，计算M=λΔφ/(2π)，减调用方同符号几何，再减参考区间中位数 | M不自动等于距离符号D；它取决于输入相位约定 |
| `audit_sdcp_positioning` | 由carrier_range构造−D，再使用−g补偿 | 相反符号不是本身的错误，但不得只翻转观测或几何其中一项 |
| `audit_calibrated_sdcp` | 同样使用−D、−g，比较参考版与校准取余版 | 该报告的有符号残差不可直接与D制残差相加 |
| `calibrated_sdcp` | 按调用方统一符号计算wrap_λ(S−G−B)，范围[−λ/2,λ/2) | 取余不等于固定整周或解决半周 |
| `geometry_free_sdcp` | 距离符号的(B−A)L1−(B−A)L5 | 原始GF不是已校准多径或欺骗残差 |
| `sdcp_self_check.detect` | 对输入残差做窗口、阈值、质量与异常门控 | 不会验证输入符号、几何来源或相位弧真实性 |

`geometry_offset_m` 的方位约定是向量 `[cos(el)cos(az), cos(el)sin(az), sin(el)]`；其他定位场景使用ENU方位从北向东。转换时必须明确轴顺序，不能只传同一个角度数字。当前定位审计主要使用ECEF距离差，避免混用角度约定。

## 3. 正常模型与误差预算

以D符号表示：

\[
D_j=g_j+B_f+\lambda\Delta N_j+h_j+m_j+e_j.
\]

B_f表示可近似共同的频段内通道偏差；整数ΔN_j只对有效连续相位弧有意义；h_j收纳方向/PRN相关响应误差及未建模项，m_j为差分多径，e_j为跟踪噪声等。半周状态另行处理，不能强塞成整数N。存在欺骗混合时，观测可能已不服从单一真实波前模型，不能默认只加一个固定多径项即可描述。

| 误差来源 | 能否消除或补偿 | 需要的依据 |
|---|---|---|
| 同星公共传播/发射相位项 | 同历元同分量下单差可抵消相应公共部分 | 不能扩展成“所有误差抵消” |
| 基线投影 | 可预测补偿 | 可信方向、基线姿态及误差界 |
| 公共通道偏差 | 可外部标定或在声明的可信参考中处理 | 温度/频率/配置适用范围，不默认零 |
| 逐星天线响应、多径 | 不能都作为同一个公共常数消掉 | 方向图/安装标定或额外观测 |
| 整数模糊度 | 连续弧相对变化中可消去常数，取余只隐藏整数 | 不等于周跳检测与整数固定 |
| 半周不确定性 | 需外部有效性信息或适配算法 | λ周期取余不会消掉半周 |
| 时间对齐/NCO误差 | 可重建和校验，但仍需量化残差 | 同历元、时钟/频率和插值误差 |
| 跟踪噪声 | 可用窗口降低部分随机成分 | 历元相关性、有效样本数；均值偏差不会自动消失 |

误差预算先分确定性偏差界、随机项、状态失效。未知相关性时不能把所有项平方和开根号当可信总误差。参考去常数也不等于误差预算完成。

当前L1波长190.293673mm。75.9mm基线若只有单个方向向量或基线朝向旋转误差δ，保守投影变化界为2b sin(δ/2)：1°/3°/5°分别1.325/3.974/6.621mm。它是解析上界，不是实际每颗星误差或误报率。若多个误差同时存在，需重新组合预算。

5°通道相位对应2.643mm。按2000Hz相位变化率估算，1/10/100μs不对齐分别对应0.381/3.806/38.059mm；该量只展示时间错位的尺度，不是完整时钟误差预算。代码1μs门限是工程配置，不是经过所有设备条件认证的要求。

## 4. 参考段与校准取余分别适用于什么

**参考版**：`modified_sdcp` 默认使用200～400ms参考区间中位数。只有声明该区间可信、相位弧可延续时，后续残差才能解释为相对参考的变化。参考段已经有稳定8mm偏差时会被全部吸收。离线函数也会返回参考区间之前的残差，那些值使用了未来参考，不能称为实时因果检测；在线基准必须在参考收集完成后才启用。

**校准取余版**：不需要启动去均值，但需要外部偏差与半周有效性依据。保留的是模λ残差，超过范围会折返；无法独自识别整周变化。

因此不是简单选择“减常数正确/错误”：应按应用条件选择，并保留不可用状态。冷启动、新星、重捕不能自动继承某颗星旧参考；有可信星历也不等于有可信相位参考。

## 5. 本轮确定性验证

采用1.2秒、10ms间隔的人造米制观测，几何随时间变化，调用现有函数；无噪声，仅验证语义。

| 输入变化 | 参考版后期残差 | 校准取余版后期残差绝对值 |
|---|---:|---:|
| 正常 | 数值零 | 数值零 |
| 从开始就有8mm偏差 | 0mm | 8mm |
| 600ms后新增8mm | 8mm | 8mm |
| 600ms后增加一整周 | 190.294mm | 数值零 |
| 600ms后增加半周 | 95.147mm | 95.147mm |

相同8mm残差可由观测加8mm或预测几何少8mm产生，函数输入补偿结果完全一致。因此仅凭残差不能唯一归因为多径或欺骗；公共硬件变化也有类似混淆。

## 6. 状态门控审查

以20历元窗、10历元子块、3次确认、8颗观测运行现有自检，作为机制测试参数，不替换默认50历元窗。

| 状态事件 | 代码实际行为 | 解释 |
|---|---|---|
| 输入残差增加整周 | 周期统计继续输出无异常 | 包裹残差无法提供整周保护 |
| 输入出现半周跳变 | 持续隔离，需外部重新验证 | 只覆盖该类可见跳变，不是完整半周认证 |
| 600～640ms仅valid=false，随后valid=true且残差平滑 | 840ms重新输出无异常 | 只是窗口恢复，不证明重捕了真实信号或正确分支 |
| 上述间断后仍未获得相位弧可信依据，保持valid=false | 后续持续未知 | 调用方必须表达未重新验证状态 |

这不是模块违反其注释约定：函数已经要求valid包含锁定和半周有效性。缺口在于当前尚未有实际接收机状态来源保证这个约定。不能以等待一个窗口替代相位弧重新确认。

原始`carrier_range`还可能在全局success为真时产生数值，但不检查每一时刻是否跟踪真信号。两路锁定不同真假分量、单路周跳、PRN顺序错误、时间错配都必须由调用方先处理；仅数值有限不足以准入。

## 7. SDCP使用准入表

| 条件 | 可做什么 | 不足时 |
|---|---|---|
| 同频、同PRN、同历元，双路观测弧有效 | 构造定义明确的原始单差 | 不作可比单差，输出观测不足 |
| 再有可信方向/基线与误差界 | 检查几何一致性 | 原始单差只能诊断，不能按绝对几何残差认证 |
| 再有通道/天线补偿依据 | 解释剩余残差范围 | 标定未知不能默认为零 |
| 有可信正常参考且持续有效 | 检测相对基准的变化 | 不覆盖参考开始前的污染 |
| 模λ残差，整数弧已知有效 | 检查小数周一致性 | 不可当作周跳监测或整数固定 |
| 已发现异常 | 隔离/标记，结合其他证据识别原因 | 不能直接给出“这颗星是欺骗” |

新捕获、全/部分失锁、失定位、冷启动、有无先验的使用条件应回填到[完整场景范围](../validation/2026-09-13-anti-spoofing-scenario-scope.md)，而不是删除这些场景。
