# 双频 GF 条件三态判决

本轮增加 gf_quality_gate.py 和 audit_gf_gate.py。该判决模块是条件异常判决，不负责整数固定、偏置估计或多径原因识别；未替换默认定位入口。

## 输入与规则

输入 r 为已处理整数分支、已减外部标定估计的 GF 残差。输入 B 为该统计量的非多径残余误差界限，必须包含标定误差和噪声等项，不能只填硬件偏差。valid 必须包括同星同历元与有效观测；branch_verified 必须来自外部连续弧、半周和分支检查。布尔标志不接受 NaN 隐式转 True。

对门限 T，计算 L=max(0,abs(r)-B)、U=abs(r)+B：

- L>T：疑似超界异常。
- U<=T：未发现超界证据，不代表无多径。
- 其余：不确定。
- B 未知、非有限、负值，或观测/分支未确认：不确定。

这是确定性有界误差下的区间规则。若 B 只是经验分位数，输出的可靠程度也取决于该覆盖假设，不能自行宣称统计置信度或恒虚警。

## 回放结果与限制

## 工程结论

三态代码已落地，但当前真正缺少的是经过验证的界限来源与分支完整性输入，而不是更复杂的判决公式。短记录的标准差不能直接当成全状态硬界限；用同一条多径记录调门限也不能替代独立评估。

下一阶段保持这一接口，先建立独立 LOS 记录上的经验误差覆盖，再做保留种子和偏置压力验证。经验界限必须明确目标覆盖率；物理标定界限未知时继续输出不确定。不会把本轮演示门限写成默认生产参数。
