# C/A码与多普勒辅助空间分离：首轮搜索验证

本轮在前述相干盲区之后增加波形维度，完成160次独立噪声试验。结果表明存在可继续实现的候选，但尚未具备可信的自动启用判据，不能接入默认定位或宣称RF抗欺骗完成。

## 算法及信息边界

1. 使用已知真实方向构造空间投影，消除该方向的分量。
2. 在投影后的数据中搜索欺骗波形的码延迟和多普勒。
3. 在时间维度消除选中的波形，再利用已知目标方向合并，搜索真实波形。
4. 对两种选中波形作联合最小二乘，估计两路上的复响应；用估计的欺骗响应和已知真实响应形成LCMV权重。

参数搜索没有读取真假波形的真实延迟/频率；搜索空间固定为5个延迟×4个频率共20候选。真实方向假设准确，PRN1和有限搜索范围已知；这不是全范围捕获，也不是来源认证。给定正确波形的同记录对照单独标为oracle，不能混入数据搜索结果。

## 信号和过程

复用项目GPS C/A码生成器，4.092MHz、10ms、4采样/chip；采用周期带限插值保留非网格延迟。单PRN、恒定导航数据位、真实与欺骗等功率，各45dB-Hz，独立复白噪声功率按fs/(C/N0)归一化；种子9730，每场景20次。目标(10°,25°)、欺骗源(100°,10°)，75.9mm东西基线，理想校准通道。

这里没有33MHz RF、模拟滤波、量化、DFE或PLL；只验证信号码波形与空间估计机制，不能推广为当前实际跟踪链路的抑制量。

|---:|---:|---:|---:|
| 0 | 0 | 0 | 0.10 |
| 0.25 | 0 | 20 | 23.88 |
| 0.5 | 0 | 20 | 28.31 |
| 1 | 0 | 20 | 27.98 |
| 0 | 50 | 20 | 26.48 |
| 0 | 250 | 20 | 26.92 |
| 0.25 | 50 | 20 | 26.25 |
| 0.37 | 80 | 不在搜索网格 | 26.60 |

最后一行只是一个非网格例子；正确波形oracle对照为28.33dB。网格内搜索与oracle一致，是因为这些20次试验选中了正确字典项，不代表所有噪声/几何/初始条件都正确。

0.25chip约73.26m码距离差，这不是极小延迟攻击边界；50Hz差在10ms中积累半周相对相位。没有测试更小连续差异矩阵，不能宣称0.25chip或50Hz是最低分辨率。每类20次、一个固定方向对，不足以支持产品成功率。

## 必须保留的失败

同码同频时正确波形矩阵条件数约1.27e16，真值波形也无法联合求解。当前搜索器排除重复字典项后，会从噪声中强制挑出第二候选，全部20次仍能得到数学上可接受的空间零陷，但抑制约0dB。这再次说明“零陷被接受”“矩阵能解”都不能代表真假已经分开。

当前缺少单波形/双波形模型选择、独立留出验证、无欺骗误触发校准以及稳定性门控。尚未有可宣称安全的自动启用策略。本轮仅据真值评价来源抑制，没有把真值传给搜索；方向错误、幅相失配和多径对照仍需加入这一新候选。

## 自查修正

开发版使用floor采样，0.37chip被离散化成另一个延迟，不能作为真实非网格验证。最终v2改用周期带限插值，独立重跑全部160次。开发数据保留追溯，最终结论只引用v2；该插值仍是理想采样模型，非实测天线/RF响应。
