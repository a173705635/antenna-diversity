# 多径研究阶段总结与交接

截至 2026-09-12。本文件是本阶段统一结论入口，覆盖早期空间检测、接收链路、SDCP、双频 GF、简单选路和双极化模型。用户决定：后续多径方案暂不沿极化分集推进；本阶段收口，保留代码与证据，下一阶段研究范围另行确定。多径与外部干扰分别评价。

## 1. 整体结论

已建立可复现的仿真、观测诊断和定位对照框架，但尚未得到可直接商用、免标定、覆盖全部多径的检测方案。检测到差分异常不等于确定多径来源，未报警不等于观测干净，载波异常也不能直接映射为码定位权重。

| 研究环节 | 已有证据与结论 | 限制及阶段处理 |
|---|---|---|
| 早期空间存在性检测 | 冻结门限下有独立 LOS 与单反射评估；弱反射、近 LOS 方向退化 | 不能把已知真值方向的 LCMV 收益算作检测器收益；保留历史基线 |
| 双独立接收链路 | 双 RF、双 DFE、独立跟踪；零延迟、无多径 1 秒×10组相位差标准差 1.981～2.386 mm | 理想公共时钟条件；单点最大约 9.044 mm，不是硬件认证 |
| GPS 定位 | L1/L5 码定位、码载波浮点联合解及逐观测加权 | 使用仿真卫星状态和时间辅助；未实现自主导航电文解码、整周固定或实机定位验收 |
| 单频 SDCP | 强异方向多径可见；参考段减常数会掩盖启动静态污染；取余/标定版本明确保留外部偏置要求 | 弱、共模及几何/硬件偏差混淆不能由窗口平均消除 |
| SDCP 自检 | 三态判决、公共异常停判和相位跳变隔离；两组强/启动强 RF 评估区间检出 100%，弱/共模 0% | 区间比例不是独立事件检测概率；未证明比相同持续确认的固定门限普遍更优 |
| 双频双天线 GF | 原始米制组合消去共同几何；四路 RF、整数分支、启动反射、未知偏置反例与失效回退已验证 | 未知整数和硬件偏置仍在；不能唯一识别受污染天线/频率；只保留辅助诊断 |
| 简单天线选择 | 固定 A/B 与逐星 C/N0 选路完成码定位对照 | 最大 C/N0 不保证最小多径；不采用为通用解决方案 |
| 双极化 | 1000 个独立标定事件、7类各2000个评估事件的理想相关器模型 | 尚无 RF/跟踪/PVT 闭环；按用户决定暂停后续推进 |

## 2. 关键结果为什么改变了路线

SDCP 自检中，未上报基线方向误差 3°/5°导致本批误报 6.5%～11.5%/21.42%～31.25%。更大误差时低报警可能来自停判，必须同时看有效覆盖率。500 ms 与 1 s 窗本批强/弱/共模结果相同，强多径确认延迟约 0.54/1.00 秒，未发现继续加窗的收益。强多径浮点定位有改善，但不能推广到所有定位方式。

GF 启动 RF 对照中，目标星平均残差改变约 −12.032 mm，证明该反射未被启动去均值抹去；但未知硬件偏置可抵消或模拟它。该场景只在 B 天线 L1 添加反射，不是完整双频物理反射模型。

同一启动多径记录中，GF 成对码降权使三维 RMS 从 4.955 m 增至 5.301 m。只降受污染 B 的诊断对照为 4.402 m，只降干净 A 为 6.142 m：误伤干净观测是原因之一。这里“知道 B 受污染”使用了场景信息，不能拿来作为实际检测能力。未触发时仍有明显码误差，因此不能只调整门限解决映射问题。

C/N0 选路的启动多径短记录中，固定 A/B/选路的码定位 RMS 分别为 4.993/12.423/10.646 m。该基线说明增强后的信号可能更受污染，不证明选路在所有场景无效。

双极化模型中，标称 LOS 异常比例 0.90%，LHCP 反射 100%，RHCP 反射仅 2.20%；未上报 LHCP 通道增益增加 3 dB 时，LOS 异常比例升至 77.80%。这些结果支持极化差异的可观测性及标定敏感性，不支持通用多径检测或实际接收机性能声明。暂停是当前研究决策，不等于已证明该技术普遍不可行。
