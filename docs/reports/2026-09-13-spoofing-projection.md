# 已知目标方向投影：来源估计与相干盲区

本轮继续上一轮来源响应估计。结果支持一个有条件的候选：在真假波形不相关时，目标消除后的交叉相关可估计来源；相干时不能直接使用。没有新增RF跟踪或定位改善声明。

## 实现

双通道快拍为 x=a*u+b*v+n。a 是已知真实卫星响应，b 是未知欺骗源响应。构造单位向量 q，满足 qᴴa=0，得到参考 z=qᴴx。以 `mean(x*z*)−σ²q` 估计来源响应方向，再复用现有LCMV保护a、压制估计响应。

σ²使用已知独立白噪声功率，是乐观的校准假设。在 u、v 不相关时，交叉相关的信号项与 b 成比例；相关时还包含沿 a 的项。因此本方法比直接取协方差主特征向量多用了已知目标信息，但没有消除相干问题。

当前两根天线在消除一个方向后只剩一维空间。不能直接把投影后的向量当成原始来源方向；交叉相关需要额外的不相关性条件才有意义。

## 验证及结果

GPS L1、75.9mm东西基线，目标(10°,25°)、来源(100°,10°)，两信号等功率；随机种子9720，每个相关性条件300次独立试验、每次4000复高斯快拍，噪声功率0.0025。构造 v=ρ exp(i0.7)u+sqrt(1−ρ²)e，其中e与u独立。ρ是本模型复相关系数的模，不是欺骗功率比或检测概率。

| ρ | 来源抑制中位数/dB | 相对真实波形的重建MSE中位数 |
|---|---:|---:|
| 0 | 38.14 | 0.00188 |
| 0.25 | 12.05 | 0.0642 |
| 0.5 | 6.03 | 0.2505 |
| 0.9 | 0.92 | 0.8118 |
| 1 | 约0 | 1.0011 |

真实波形平均功率为1。完全相干时MSE接近1，说明目标独立响应约束成立，也不能保证混合输入中的真实波形得到恢复。信号相关性造成来源估计偏差，不能将输出功率变小解释为只压住了欺骗。

## 精确反例

保持同一已知a，原始来源(100°,10°)与真实信号完全相干，混合响应是 `a+exp(i0.7)b`。换成来源(250°,20°)，重新选择两个未知复幅度，仍能表示完全相同的混合响应；数值残差1.11e−16。

这表明：单PRN、两个通道、未知真实/欺骗复幅度、完全相干且仅依赖快拍空间数据时，真实方向已知仍不足以唯一恢复欺骗方向。它不是对更多天线、已知波形幅度、动态几何或码/多普勒信息的不可行证明。

## 研究决定

不把这个候选无条件接入默认跟踪。应继续利用实际相关器上的码延迟/多普勒差，检查是否存在可分离的独立信息；特别需要覆盖接近同码同频时的失效。如果这些量无法分开，输出不可分离状态，不能用真值方向填补。

下一步RF验证应同时保留理想来源上限与数据估计结果；本轮没有完成该步骤。增加RF记录本身不能解决上述观测等价问题。
