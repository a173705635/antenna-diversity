# GNSS 窄带阵列抗干扰知识库

这套文档面向希望从零建立阵列信号处理直觉，并最终能够设计、实现和评估 GNSS 窄带阵列抗干扰系统的读者。

推荐按编号顺序学习。每一章都尽量回答四类问题：

1. 公式从哪里来；
2. 公式中的量具有什么物理意义；
3. 算法成立需要哪些条件；
4. 理想模型进入工程系统后会在哪里失效。

## 四、贯穿全书的能力边界

学习过程中应反复检查以下约束，而不是只记住闭式公式：

- **窄带条件：** $B\tau_{\max}\ll 1$，否则固定导向矢量模型失效；
- **子空间条件：** 有效信号模式数必须小于有效阵元数；
- **协方差条件：** $K\ge N$ 只保证可能满秩，不保证估计可靠；
- **自由度条件：** 约束秩为 $r$ 时，只剩 $N-r$ 个自适应空间自由度；
- **模型条件：** 算法保护的是模型导向矢量，不会自动保护真实但失配的目标；
- **前端条件：** 数字算法无法恢复因饱和、不同步或动态范围不足而丢失的信息；
- **评估条件：** 零陷深度不能替代输出 SINR、目标增益、WNG 和稳健性测试。
