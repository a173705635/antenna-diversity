# 精简研究仿真代码重构设计

## 目标

将 `python_sim_simplified` 从“教学副本”调整为个人研究使用的精简仿真主代码。重构重点是职责清晰、参数易修改、物理量来源唯一和结果可追溯，不引入完整版中的重型校验、批处理或报告框架。

## 保持不变

- RF、DFE、天线响应、通道延迟、分集合并、捕获和跟踪公式不变。
- 默认参数、随机种子和随机数生成方式不变。
- `run_end_to_end()` 的结果字典字段、控制台指标和七张输出图不变。
- 当前有效输入下的数值结果保持一致；浮点比较使用合理容差。
- Blind Null 判决和捕获成功后才进入跟踪的流程不变。

## 配置归属

同一物理量只保留一个默认来源：

- RF 采样率、接收中频、载波频率和码率由 `SignalConfig` 提供。
- 参考阻抗移到 `SimulationConfig.reference_impedance_ohm`，目标信号电压和 RF 噪声共同使用。
- `DFEConfig` 不再重复保存输入采样率；DDC NCO 默认使用信号中频。
- `DFEConfig.nco_frequency_hz` 允许显式覆盖 DDC 频率，以便研究频率失配。
- `AcquisitionConfig` 不再重复保存码率，捕获使用信号配置中的码率。

配置字段可以调整，调用点、测试和 README 同步更新；默认行为不得改变。

## 模块调整

### 配置和预设

- `config.py` 保存配置数据类和常量。
- 新增 `presets.py`，保存 `default_config()`、`parametric_config()`、`measured_config()` 和 Mate 70 默认几何。
- README 更名为“精简研究仿真版”，说明参数入口、已建模范围和未建模范围。

### 天线模型

- `AntennaModel` 不再保存整个 `SimulationConfig`。
- `build_antenna_model()` 只接收 `PhoneConfig` 和载波频率。
- `AntennaModel` 只保存活动天线、真实/估计位置、真实/估计天线状态、通道响应和测量方向图。
- 新增 `measured_pattern.py`，承接 CSV 加载、网格数据和插值；`antenna.py` 保留坐标变换、方向图、遮挡、耦合和有效流形计算。

### 阶段接口

- 新增 `models.py`，使用 `TypedDict` 描述现有结果字典。
- 运行时仍返回原有字典，不把研究脚本强制改成复杂对象。
- 为核心数组在类型和文档中注明形状、单位以及 true/assumed 含义。

### 大函数拆分

- `gnss.generate_scenario()` 拆分为目标波形、目标阵列响应、单个干扰源和结果整理等私有函数；公共签名和返回值不变。
- `tracking.track()` 拆分为初始化、单历元相关、环路更新和结果整理；环路公式与更新顺序不变。
- `pipeline.run_end_to_end()` 拆出单个合并分支的处理函数，使主函数只展示 RF→DFE→合并→捕获→跟踪的数据流。

RF、DFE、通道延迟、合并和捕获模块保持现有文件边界，只补充必要类型与接口说明，不为消除少量重复而增加工具层。

## 测试与验收

- 先记录当前确定性基线中的关键数组形状和四个合并分支指标。
- 重构后现有 28 项测试全部通过。
- 增加配置单一来源测试，覆盖采样率、中频、码率和参考阻抗的传播。
- 增加默认仿真的数值回归测试，比较关键标量和数组，使用明确容差。
- 确认程序仍生成相同名称的七张独立图片。

## 本轮不做

- 不改变任何算法和默认实验场景。
- 不恢复完整版的全量异常保护、schema、文件审计、批处理和报告系统。
- 不引入深层包结构、插件系统或配置框架。
- 不同步重构 `python_sim` 完整版。
