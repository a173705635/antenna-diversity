# Python 精简版宽带干扰设计

## 1. 目标与范围

在 `python_sim_simplified` 中增加可配置的带限复高斯噪声干扰，并让它完整经过天线、通道真时延、RF、ADC、DFE、天线合并、捕获和跟踪链路。现有 CW 干扰能力保留，默认仿真同时启用一个 CW 干扰和一个宽带干扰。

本次不实现扫频、脉冲、调制压制、多径或时变到达方向，也不把窄带 MVDR 改造成分频段宽带 MVDR。当前工作用于研究宽带干扰进入现有单权值空间处理链后的表现和局限。

## 2. 方案选择

采用独立的 `WidebandInterferer` 数据类，而不是给 `CWInterferer` 增加模式字段，也不使用多音叠加近似宽带噪声。这样 CW 与宽带干扰各自只暴露有效参数，并为后续增加扫频或脉冲干扰保留清晰扩展边界。

## 3. 配置接口

宽带干扰配置提供以下字段：

```python
WidebandInterferer(
    direction=Direction(80.0, 10.0),
    power_dbm=-90.0,
    center_offset_hz=0.0,
    bandwidth_hz=2.0e6,
    random_seed=1001,
    filter_taps=129,
    start_ms=0.0,
    stop_ms=None,
    enable=True,
)
```

`power_dbm` 表示干扰开启期间、整个配置带宽内的总输入功率，而不是功率谱密度。`center_offset_hz` 相对 GNSS L1 中心频率定义，在生成的等效复 IF 中搬移到 `if_hz + center_offset_hz`。

`SimulationConfig.interferers` 接受 `CWInterferer | WidebandInterferer`。默认配置包含原有 CW 和上述宽带干扰，两者同时启用。宽带干扰使用独立随机种子，不改变 RF 热噪声的随机序列。

## 4. 信号生成与数据流

宽带波形按以下顺序生成：

1. 生成单位功率复高斯白噪声；
2. 使用奇数阶线性相位 FIR 将其限制到配置带宽，并丢弃滤波启动瞬态；
3. 将稳态波形归一化为单位均方幅度，再根据总功率和参考阻抗换算电压；
4. 搬移到等效 IF 加中心频偏；
5. 应用起止时间门控；
6. 应用配置方向的天线复响应；
7. 使用现有 `apply_channel_delays` 对每个通道的整段宽带序列施加真时延；
8. 与 GNSS 信号及 CW 干扰叠加后进入现有 RF 到 TRK 链路。

FIR 的半带宽必须小于奈奎斯特频率，搬移后的整个频带必须位于 RF 复采样的可表示区间内。滤波器长度必须为不小于 3 的奇数。随机种子、带宽、功率和时间门控非法时应尽早报告明确错误。

## 5. 空域模型与指标解释

天线方向响应继续使用 L1 载频处的现有窄带阵列模型；2 MHz 相对 1575.42 MHz 的分数带宽很小，因此本次不增加随频率变化的方向图。通道真时延作用于完整宽带序列，所以由通道时延引起的带内相位斜率会自然保留。

现有 MVDR 仍对整个 DFE 带宽使用一组固定复权值。它不是频率分仓 MVDR，因此较大的通道群时延或频率相关阵列流形可能让带宽边缘的零陷变浅。该限制必须写入 README，不能把中心频点结果解释成整个带宽的抑制度。

`interferer_steering_effective` 对宽带干扰记录中心频率处的等效导向矢量。因此 `worst_interferer_gain` 对宽带干扰只是中心频率诊断。宽带抗干扰效果以合并频谱、捕获指标、跟踪状态和 C/N0 为主要证据。

## 6. 绘图

现有 CW 干扰继续用红色竖线标记。宽带干扰在 RF、DFE 和合并频谱中用半透明红色频带标记，并标出中心频率。空间响应图继续用干扰方向标记，但标题或图例区分 CW 与宽带干扰。

默认保存图数量和文件职责保持不变，不新增重复总览图。

## 7. 测试与验收

按测试驱动方式覆盖以下行为：

- 同一随机种子生成完全相同的宽带干扰，不同种子生成不同波形；
- 单天线理想场景下，开启区间的平均功率与配置总功率在数值容差内一致；
- 主要频谱能量落在配置中心频率和带宽内；
- 起止时间之外的宽带干扰分量为零；
- CW 与宽带干扰可以同时生成，truth 中的分量和中心频率导向信息顺序一致；
- 整条 RF、DFE、MVDR、Blind Null、捕获和跟踪链可以运行；
- 绘图能识别并标记宽带频带；
- 现有非相关测试继续通过。

验收时运行 `python_sim_simplified` 全部测试，并执行一次缩短时长的端到端宽带干扰仿真。对宽带波形检查功率和带内能量比例，对最终分支报告捕获指标及 C/N0，不以单一频点零陷作为通过条件。

## 8. 兼容性与代码边界

改动限制在 `python_sim_simplified` 及本设计文档。保留用户当前未提交的 `run_end_to_end.py` 通道时延配置，不覆盖或回退 `.idea` 等未跟踪内容。除适配新的干扰联合类型外，不重构天线、RF、DFE、捕获或跟踪模块。
