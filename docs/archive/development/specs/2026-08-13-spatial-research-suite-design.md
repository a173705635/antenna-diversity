# 可复现天线组合与 MVDR 鲁棒性研究套件设计

**日期：** 2026-08-13

**状态：** 已完成对话设计确认，等待书面规格复核

**实现范围：** 仅 Python 仿真；MATLAB 代码不在本轮同步范围内

## 1. 背景

现有 Python 工程已经实现 GPS L1 C/A 的等效复数 IF 到接收机链路，包括 RF/ADC、DFE、SINGLE/EGC/MVDR、捕获、跟踪和 C/N₀；同时已经提供四角点手机阵列、三维阵列流形、0～3 个静态 CW 干扰、解析空间指标、参数扫描和顺序 Monte Carlo。

本轮不重写这些底层模型，而是在它们之上增加一套可配置、可恢复、可复现的研究编排与自动报告能力。研究同时回答两个问题：

1. 理想模型下，不同角点数量和组合的相对性能如何；
2. 非理想模型下，MVDR 对导向、阵元位置、通道校准和对角加载的敏感性如何。

“11 种组合”专指四个角点 `TL/TR/BL/BR` 中任选 2～4 个得到的 6 + 4 + 1 个子阵，并不是 11 种合并算法。合并算法仍为 SINGLE、EGC 和 MVDR。

## 2. 研究定位与模型边界

### 2.1 研究定位

本研究是**比较性研究**。它比较给定理想化模型下的相对优势、退化趋势和失效边界，不宣称真实 HUAWEI Mate 70 的产品性能，也不定义缺少实测依据的产品验收门限。

### 2.2 已建模内容

- Mate 70 外形尺寸对应的四个理想角点相位中心；
- 任意不重复的 2～4 角点子阵；
- 三维远场窄带各向同性阵元流形；
- 实际与假设目标导向、实际与估计通道响应；
- 0～3 个具有方向、功率、频偏、初相和时间门的静态 CW 干扰；
- SINGLE、EGC、带对角加载的 MVDR；
- 解析输出 SINR、目标/干扰方向增益、白噪声增益等空间指标；
- RF/ADC、DFE、捕获、跟踪和 C/N₀ 的完整样本链路。

### 2.3 未建模内容

- 真实 Mate 70 天线位置、方向图、极化、互耦和人体握持效应；
- 多径、NLOS、动态到达方向和宽带/调制干扰；
- 多颗卫星、导航电文、定位解算和 PVT；
- 实时自适应权值更新与硬件实现限制。

报告必须同时列出已建模与未建模内容，防止将比较性结果解释为产品级结论。

## 3. 用户工作流

新增统一命令行入口 `python_sim/run_spatial_research.py`，支持预设、JSON 配置和命令行覆盖。

```powershell
cd F:\antenna_diversity\python_sim

# 标准预设，研究全部组合
python run_spatial_research.py --preset standard --combinations all

# 快速研究指定组合和模式
python run_spatial_research.py `
  --preset quick `
  --combinations TL+BR,TL+TR+BR `
  --modes egc,mvdr

# 从可编辑 JSON 加载完整研究定义
python run_spatial_research.py --config studies/my_study.json

# 配置一致时恢复中断的运行
python run_spatial_research.py --config studies/my_study.json --resume
```

组合输入支持：

- 单个组合，如 `TL+BR`；
- 逗号分隔的指定列表，如 `TL+BR,TR+BL,TL+TR+BR`；
- `all`，表示全部 11 种稳定顺序组合。

配置优先级从高到低固定为：

```text
命令行覆盖 > JSON 配置 > quick/standard/extended 预设 > default_config()
```

用户可以在 JSON 中显式修改载波频率、IF、采样率、DFE、目标和干扰、天线组合、模式、误差范围、样本数、随机种子和输出目录。改变 `carrier_hz` 只会改变使用该频率的阵列流形和相关射频参数，不会自动把 GPS L1 C/A 变成另一种 GNSS 信号；PRN、码率、采样率等相关字段必须由用户一并明确配置，并通过已有链路校验。

## 5. 算法与组合口径

### 5.1 SINGLE

SINGLE 只使用激活列表中的第一根天线。理想基线将 TL、TR、BL、BR 四个物理角点分别作为单天线基准；报告使用 `SINGLE(TL)`、`SINGLE(BR)` 等明确标签。

如果用户对一个多天线组合同时请求 SINGLE，例如 `("TL", "BR")`，完整链路沿用当前行为并标记为 `SINGLE(TL)`。报告不得把它描述成两天线合并。

在当前各向同性、无互耦、无机身遮挡的理想模型中，四个 SINGLE 基线可能完全相同。报告应把这种退化解释为模型对单阵元方向差异尚未建模，而不是隐藏重复结果。

### 5.2 EGC 和 MVDR

EGC 和 MVDR 可以对全部 11 种子阵或用户指定的任意合法子集运行。默认解析研究模式为 EGC 和 MVDR；完整链路默认同时展示 SINGLE、EGC 和 MVDR，用户可以缩减模式集合。

鲁棒性研究的中心对象是 MVDR，同时保留 EGC 作为不依赖样本协方差最优抑制的参考基线。若用户显式排除 MVDR，则跳过 MVDR 专属误差结论，并在报告中说明。

## 6. 分层漏斗式实验

### 6.1 A：理想基线

在真实与假设目标方向一致、真实与估计相位中心一致、通道校准残差为零时：

- 对 SINGLE 的四个物理角点建立基线；
- 先为每个请求组合和模式计算一个无干扰噪声参考点，再对请求的 EGC/MVDR 子阵运行单干扰方向扫描；
- 在默认干扰方向上运行干扰功率扫描；
- 记录输出 SINR、目标方向增益、各干扰方向增益、最差干扰增益、白噪声增益、权值范数、协方差秩、条件数和对角加载；
- 为每个组合计算全方向和可分辨方向区域的最差值、第 10 百分位、中位数和其他摘要统计。

主要排名使用参考干扰功率下、可分辨区域内的输出 SINR 第 10 百分位。干扰功率扫描用于展示抗干扰裕量和性能拐点，不与方向样本混成一个任意加权的总分。

该阶段回答阵元数量、孔径和几何组合如何影响理想性能。

### 6.2 B：MVDR 单因素鲁棒性

每次只改变一种误差，其余变量恢复理想值：

- 假设目标方位角误差；
- 假设目标仰角误差；
- 单角点和多角点三维相位中心误差；
- 相对通道幅度校准残差；
- 相对通道相位校准残差；
- 对角加载因子。

目标方位和仰角分别进行一维扫描，另一角度保持真实值。位置误差按“活动角点 × `x/y/z` 轴”逐项扫描：一次只移动一个假设相位中心的一条坐标轴。幅度和相位校准同样按活动角点逐项扫描：真实通道响应保持理想值，一次只对一个角点的估计响应施加指定残差。表格保存被扰动角点和坐标轴，因此既能查看具体曲线，也能按同一误差幅度汇总各角点中的最差结果。

“校准残差”定义为估计通道响应相对于真实通道响应的误差。单因素扫描应固定真实通道，改变估计值；组合 Monte Carlo 保存真实值、估计值及两者差值。公共幅度比例和公共相位旋转不作为阵间校准误差，因此随机相对残差在活动通道间去除公共分量后再应用。

输出包括 MVDR 与 EGC 的绝对指标，以及 `MVDR - EGC` 的输出 SINR 差。该阶段回答哪种误差最敏感，以及 MVDR 优势在哪个误差范围消失。

### 6.3 C：综合误差与多干扰

综合误差设置轻度、中度和重度三个**人为压力等级**，不表示真实 Mate 70 误差：

| 等级 | 目标方位/仰角误差标准差 | 每角点每轴位置误差标准差 | 相对幅度校准残差标准差 | 相对相位校准残差标准差 |
|---|---:|---:|---:|---:|
| 轻度 | 1° | 1 mm | 0.25 dB | 3° |
| 中度 | 3° | 3 mm | 0.75 dB | 10° |
| 重度 | 8° | 10 mm | 2 dB | 30° |

每个样本使用从研究主种子派生的确定性子种子：

- 方位和仰角误差独立零均值高斯抽样；方位角归一化到 `[0, 360)`，超出合法仰角范围的样本按固定顺序重采样；
- 每个活动角点的 `x/y/z` 位置误差独立零均值高斯抽样；
- 每通道幅度和相位残差独立零均值高斯抽样，并去除活动通道公共均值；
- 每个样本保存实际抽样值、子种子和最终解析指标。

多干扰至少包括三个可编辑的确定性模板：

1. `two_jammer_separated`：两个角度明显分开的干扰；
2. `two_jammer_close`：两个方向接近的干扰；
3. `three_jammer_stress`：三个同时存在的干扰。

三个默认模板以真实目标方向 `(30°, 60°)` 为基准，具体为：

- `two_jammer_separated`：`(120°, 10°, -90 dBm, +250 kHz, 0.8 rad)` 与 `(250°, 25°, -90 dBm, -180 kHz, 1.1 rad)`；
- `two_jammer_close`：`(120°, 10°, -90 dBm, +250 kHz, 0.8 rad)` 与 `(128°, 12°, -90 dBm, -180 kHz, 1.1 rad)`；
- `three_jammer_stress`：`(120°, 10°, -90 dBm, +250 kHz, 0.8 rad)`、`(250°, 25°, -90 dBm, -180 kHz, 1.1 rad)` 与 `(315°, 40°, -90 dBm, +420 kHz, -0.4 rad)`。

方向、功率、频偏和初相随预设写入 `resolved_config.json`，用户可以完整覆盖；若用户改变目标方向，模板不会暗中旋转，报告显示最终绝对方向。报告需说明：`M` 根天线在维持一个目标约束时通常最多提供约 `M-1` 个独立空间抑制自由度；实际能力仍受流形相关性、孔径、误差、加载和有限样本影响。

### 6.4 D：完整链路验证

完整样本链路只运行代表性场景和用户手动指定场景。每个自动选择都保存选择原因：

- `best`：主排名最高；
- `typical`：主排名居中，偶数时采用排序后较低的中央索引，保证唯一；
- `worst`：主排名最低；
- `knee`：在 best 组合的单因素误差扫描中，MVDR 相对 EGC 的输出 SINR 优势最早小于或等于 0 dB 的点；
- 三个多干扰模板：全部使用理想主排名的 best 组合；
- extended 额外加入轻度、中度和重度综合误差代表样本：分别在 best 组合、MVDR 模式下选择输出 SINR 最接近该等级样本中位数的 realization，并以 `sample_index` 作为并列决胜；
- 用户手动指定的场景始终保留，不被自动筛选覆盖。

自动角色以 `case_id` 去重；同一个场景若同时承担 best、typical 或 worst 等多个角色，只运行一次，并保存全部选择原因。因此“自动完整链路场景数”是上限，不保证在组合很少或曲线不具备 knee 时达到该数量。缺少 EGC 或 MVDR 时无法定义二者优势的 knee，该角色被明确记为 `not_selected`，其他场景仍可完成。

best、typical 和 worst 先按主排名选择组合，再在该组合 `ranking_mode` 的可分辨方向网格中，选择输出 SINR 最接近其第 10 百分位值的网格点作为完整链路干扰方向；并列时按输入仰角顺序、再按输入方位角顺序选择。功率、频偏和初相使用解析基线的参考单干扰配置。这样完整链路验证对应排名所代表的低分位工作点，而不是任意默认方向。

为了跨单位选择唯一 knee，每条单因素曲线都先按离理想点的绝对距离除以该曲线最大距离，得到 `[0, 1]` 的归一化严重度；加载因子使用 `abs(log10(factor/default_factor))` 后再归一化。每条曲线的正负两侧分别从零误差向外检查。若存在优势首次小于或等于 0 dB 的点，选择归一化严重度最小者；并列时按 `direction_azimuth`、`direction_elevation`、`position`、`amplitude`、`phase`、`loading`，再按角点和坐标轴稳定排序。若所有曲线都没有交叉，选择相邻采样点之间“优势下降量 / 归一化严重度增量”最大的较高严重度点。任一候选曲线不足两个不同严重度点时忽略；所有曲线都不可用时 knee 记为 `not_selected`。

完整链路输出捕获率、捕获峰值指标、跟踪率、最终 C/N₀、C/N₀ 时间曲线摘要和最终多普勒误差。解析模型对同一配置计算的结果写成 `analytic_output_sinr_db`；当前完整链路没有校准后的信号/干扰/噪声功率分解，因此不得把解析 SINR 命名成 sampled 或 measured SINR，也不得用 `None` 分布冒充完整链路 SINR 统计。

## 7. 方向区域、排名和并列处理

干扰与目标方向重合时，保持目标无失真约束的线性合并器不能可靠空间区分两者。因此每个方向扫描保存两个统计区域：

- `all_directions`：完整方向网格；
- `resolvable_region`：干扰方向与真实目标方向的三维夹角至少为 `exclusion_angle_deg`，默认 15°。

夹角由两个三维单位方向向量的点积计算，不直接用方位角差。网格边界 `separation == exclusion_angle_deg` 属于可分辨区域。

研究配置包含 `ranking_mode`，默认 `mvdr`，且必须属于本次解析模式集合。主排名只在该模式内比较组合，避免把算法变化和几何变化混在同一个次序中。主排名键依次为：

1. 可分辨区域输出 SINR 第 10 百分位，降序；
2. 可分辨区域输出 SINR 中位数，降序；
3. 白噪声增益，降序；
4. 最大物理基线，降序；
5. 组合名称按稳定角点顺序形成的字符串，升序。

这样即使数值完全并列，输出顺序仍确定。报告同时显示全方向最差值，不能通过排除区隐藏不可分辨场景。

## 8. 运行预设

| 项目 | `quick` | `standard` | `extended` |
|---|---:|---:|---:|
| 干扰方位角 | `0:30:330` | `0:10:350` | `0:5:355` |
| 干扰仰角 | `0:15:90` | `0:10:90` | `0:5:90` |
| 干扰功率范围/点数 | -110～-80 dBm / 4 | -110～-70 dBm / 9 | -115～-65 dBm / 21 |
| 每个单因素误差点数（线性 / 加载） | 5 / 5 | 13 / 9 | 25 / 21 |
| 每等级解析综合误差样本 | 50 | 500 | 5000 |
| 自动完整链路场景 | 4 | 7 | 10 |
| 每场景完整链路种子 | 3 | 40 | 200 |

默认单因素范围为：目标方位/仰角偏差 ±12°、位置偏差 ±12 mm、相对幅度残差 ±3 dB、相对相位残差 ±30°、对角加载 `1e-5`～`1`。quick 对每个线性范围取 5 个等间隔点、加载取 5 个对数等间隔点；standard 分别取 13 和 9 个点；extended 分别取 25 和 21 个点。所有范围都包含零误差；用户可以在 JSON 中覆盖完整值数组。

`quick` 自动完整链路角色为 best、typical、worst、knee；`standard` 再加入三个多干扰模板；`extended` 再加入轻度、中度和重度综合误差代表样本。角色按上一节规则去重或标记不可选。手动场景在这些角色之外追加，因此报告必须区分自动角色数、去重后的实际场景数和手动场景数。

运行时间只是目标等级：quick 预计数分钟、standard 预计约 30～60 分钟、extended 可以运行数小时；实际时间取决于硬件、组合数量、模式和用户覆盖值，不作为程序超时承诺。

```text
│  ├─ full_chain_validation.csv
│  └─ full_chain_cn0.csv
├─ figures/
│  └─ *.png
└─ checkpoints/
   └─ <stage>.json
```

- CSV 使用 UTF-8 长表，一行对应一个组合、模式、场景和采样点，便于 pandas、Excel 和 MATLAB 读取；
- JSON 使用严格 JSON，禁止 `NaN` 和 `Infinity`，不可用数据写 `null` 并附原因字段；
- 默认不保存完整 RF、ADC、DFE 和相关器数组；
- C/N₀ 曲线在 `full_chain_cn0.csv` 中按场景、模式、种子和 epoch 保存时间轴与有限标量值；不可用原因保存在 `full_chain_validation.csv` 的分支汇总行；
- 每条结果能追溯到组合、模式、场景、参数、随机种子和选择原因。

### 9.4 Manifest 与配置哈希

`manifest.json` 至少保存：

- schema 版本、研究名称和状态；
- 项目 Git SHA、Python 和依赖版本；
- UTC 开始/完成时间；
- 规范化科学配置的 SHA-256；
- 各阶段状态、记录数和错误摘要；
- 最终报告和表格路径。

配置哈希覆盖所有会影响科学结果和筛选规则的解析后字段，不覆盖研究名称、预设名称、输出目录、显示开关和 `resume` 标志；预设展开后的实际轴、样本数和场景仍参与哈希。已有目录默认拒绝覆盖。只有配置哈希和 schema 版本完全一致时 `--resume` 才可复用检查点。

## 10. 检查点、失败语义和恢复

- 阶段按 baseline、single-factor、combined-error、multi-jammer、selection、full-chain、report 顺序执行；
- 每阶段先写同目录临时文件，完成校验后通过原子替换发布；
- 捕获失败和跟踪失败是有效布尔研究结果，不是程序异常；
- 非法组合、重复角点、未知模式、未知 JSON 字段、非有限值、不一致的载波/IF/采样配置和非法方向在运行前拒绝；
- 配置一致时，`--resume` 跳过已完成且校验通过的阶段，重新运行缺失、失败或损坏阶段；
- 配置不一致或 schema 不兼容时拒绝恢复，并保留旧目录；
- 运行异常时 manifest 标记 `failed`，保存阶段和简短错误摘要；已完成数据保留；
- 只有所有必需阶段完成后才生成带 `completed` 状态的最终报告，不能把部分结果描述成完整研究。

## 11. 图表与自动报告

报告遵循从全景到原因再到接收机验证的叙事顺序：

1. 研究目的、配置摘要、模型边界和主结论卡；
2. SINGLE 四角点与 EGC/MVDR 子阵组合排名；
3. 干扰方位角 × 仰角输出 SINR/干扰增益热力图，叠加目标方向和 15°排除区；
4. 干扰功率曲线和性能拐点；
5. 导向、位置、幅相校准和对角加载退化曲线；
6. 轻度/中度/重度组合误差分布；
7. 两干扰和三干扰压力场景比较；
8. 完整链路捕获率、跟踪率、捕获指标、最终 C/N₀和多普勒误差；
9. 推荐组合、优势消失条件、异常场景、已建模和未建模项；
10. 复现命令、Git SHA、配置哈希和原始表格链接。

图表固定单位、色标和排序；同类热力图共享色限，避免视觉尺度误导。报告结论必须由保存的表格和筛选规则生成，不能手写挑选有利场景。
