# Single-antenna GPS SPP implementation plan

**Goal:** Run assisted GPS L1 code positioning from one RF/DFE stream containing eight PRNs.
**Architecture:** Reuse existing signal, RF, DFE and receiver functions. Add `positioning.py` for observation conversion and least squares and `run_gps_spp.py` for the executable controlled experiment.
**Tech stack:** Existing NumPy, SciPy, matplotlib and pytest; no new dependency.
**Spec:** User approved the ponytail review, superseding the dual-antenna scope of `docs/reports/2026-09-11-gps-spp-design.md`. Single antenna only; no multipath, interference, SDCP or navigation message decoder.

- [x] Write `tests/test_positioning.py`: recover known position/clock, reject deficient geometry, recover code ranges across a period boundary, reject invalid tracking input.
- [x] Implement `solve_position(satellite_positions_m, pseudoranges_m)` using `np.linalg.lstsq`; require >=4 finite observations, rank 4 and convergence. Start at Earth centre without truth initialization.
- [x] Record pre-update code phase/rate in `tracking.py`; reject empty/nonfinite input and unusable correlations before division. Update typed result and existing key-set check.
- [x] Implement `code_pseudorange(history, times_s, fs_hz, coherent_s, coarse_range_m)` using the containing NCO block, nominal code clock, modulo 1 ms and nearest coarse-aided period. Never use truth code errors. Coarse aid must be within half a code period; this is not navigation decoding.
- [x] Add runner: eight PRN components summed before one RF/DFE pass, eight independent acquire/track calls, common 10 ms observation epochs, one position/clock solution per epoch. Use controlled receive-frame satellite positions and radial velocities, with consistent code delay and Doppler. Explicitly label these as synthetic satellite states, not propagated broadcast ephemerides.
- [x] Run focused checks, a short RF smoke experiment, then three 1 s independent RF seeds. Save raw observations, aid/state metadata, positions, ENU/3D errors, usable satellite counts, source hashes and figure. Report failures rather than filling missing positions with truth.
- [x] Run the existing simplified tests, review changes and document results and reproduction commands. Do not push without request.

Verification commands: `python -m pytest python_sim_simplified/tests/test_positioning.py -q`; `python python_sim_simplified/run_gps_spp.py --duration-ms 300 --seeds 3000 --output python_sim_simplified/results/gps_spp_smoke`; `python python_sim_simplified/run_gps_spp.py`; `python -m pytest python_sim_simplified/tests -q`.
