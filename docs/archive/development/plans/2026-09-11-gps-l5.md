# GPS L5 Q5 implementation plan

Approved in conversation: single antenna, separate L1 and L5 frequency chains;
L1 RF 33 MHz / 5, L5 RF 33 MHz / 1. No multipath or external interference.
Reuse the existing synthetic reception-frame constellation and assisted timing.
No CNAV decoding, integer fixing or ionosphere-free accuracy claim in this stage.

- [x] Implement IS-GPS-705J Q5 primary code and NH20, verify published vectors.
- [x] Parameterize primary code length in source, acquisition, tracking and observations; preserve L1 defaults.
- [x] Estimate NH alignment from received prompt correlations; reject ambiguous synchronization. Track with NH wiped off, without simulation phase truth.
- [x] Run shared-time L1/L5 single-frequency and combined code/carrier float positioning, separate ambiguities per frequency and satellite.
- [x] Run regression and negative/control tests, archive configuration, results and limitations.

Validation: standard initial 13-chip vectors; all NH offsets and unknown carrier phase;
synthetic delayed/Doppler signals through RF/DFE; existing full L1 suite;
multi-PRN end-to-end comparisons. Combined observations share a receiver clock,
with zero inter-frequency hardware bias in this synthetic model. Same satellite
states and radial velocities imply frequency-scaled Doppler, not equal Hz.
