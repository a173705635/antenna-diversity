3. GNSS 为什么需要天线分集与空域抗干扰
GNSS 信号到达地面时功率极低，通常埋在热噪声以下，接收机依靠扩频码相关获得处理增益。单天线只能在时间、频率和码域区分信号；当强干扰进入前端并占据相同频带时，空间维度成为额外的可利用信息。
接收质量常用关系：SNR ≈ C/N₀ − 10·log₁₀(B_eq)
其中 C/N₀ 的单位是 dB-Hz，表示载波功率与单位带宽噪声谱密度之比；B_eq 是等效噪声带宽。C/N₀ 只有在相关峰稳定、跟踪有效时才有明确意义，不能给捕获失败分支强行赋值。

4. 阵列几何、传播时延与窄带模型
图 2  手机四角理想相位中心、目标方向和干扰方向
手机中心定义为坐标原点，+x 向右，+y 向顶端，+z 垂直屏幕向外。方位角从 +x 朝 +y 逆时针增加，仰角从手机平面向 +z 增加。
u(az,el) = [cos(el)cos(az), cos(el)sin(az), sin(el)]ᵀ
τₘ = pₘᵀu / c，    aₘ(u,f) = gₘ(u,f)·exp(−j2πfτₘ)
x[n] = aₛs[n] + Σₖ aⱼ,ₖ jₖ[n] + v[n]
导向矢量 a 把阵元位置、方向图、极化和通道响应压缩为一组复数系数。阵列算法真正利用的是各通道之间的相对幅度和相位，而不是绝对电压。
窄带条件：若最大阵元时延差为 Δτ_max，信号有效带宽为 B，则需要 B·Δτ_max ≪ 1。此时各阵元之间主要表现为固定复数相位差，而不是需要逐频点建模的不同波形延迟。
Mate 70 外形对角线约 177.8 mm，GPS L1 波长约 190.3 mm，因此最大几何孔径约 0.93λ、传播时延差上界约 0.59 ns。对当前数 MHz 等效带宽，B·Δτ_max 远小于 1，窄带阵列模型在几何时延层面是合理的；但这不代表机壳、人体和全波散射可以忽略。
空间可分辨性来自导向矢量差异；若两个来波方向产生几乎相同的阵列响应，算法无法可靠区分。
阵元数 M 限制空间自由度。保护 r 个独立约束后，最多剩 M−r 个自适应空间自由度。
手机四角不是规则半波长阵列，可能出现方向模糊、旁瓣和几何退化，需要扫描与 Monte Carlo，而不能只看一个方位切面。

6. RF 前端、热噪声、限幅与 ADC
RF 模块把天线端口功率转换为可采样复数电压，并显式考虑级联增益、噪声系数、热噪声、I/Q 限幅和量化。
P_noise,in = k·T·B，    k = 1.380649×10⁻²³ J/K
F_total = F₁ + (F₂−1)/G₁ + (F₃−1)/(G₁G₂) + …
Friis 公式说明第一级低噪声放大器的增益和噪声系数最关键：前级足够增益会压低后级噪声折算到输入端的贡献。噪声系数计算必须在线性域进行，最后才能转回 dB。
若 P = E{|x|²}/R，则电压尺度满足 V_rms = √(P·R)
软限幅使用 tanh 分别压缩 I、Q 分量，在接近满量程时平滑进入饱和；硬限幅则直接截断到 ±V_limit。前端一旦严重饱和，后续数字空域算法无法恢复已丢失的幅相信息。
x_lim = V_lim·tanh(Re{x}/V_lim) + jV_lim·tanh(Im{x}/V_lim)
ADC LSB = V_pp / 2ᵇ；理想均匀量化误差方差约为 Δ²/12（满足高分辨率假设时）
当前实现：默认复数 ADC 为 10-bit I/Q、1 Vpp；RF 级联总增益约 80 dB。模型包含热噪声和饱和，但尚未包含相位噪声、I/Q 失衡、时钟抖动、杂散和逐级非线性压缩。

8. 样本协方差、特征分解与对角加载
协方差矩阵保存跨通道的功率和相关关系，是 MVDR、Blind Null、子空间检测和 DOA 方法的共同基础。令 X∈ℂᴹˣᴺ，M 为通道数、N 为快拍数：
R̂ = XXᴴ/N；    R̂ = UΛUᴴ，Λ = diag(λ₁,…,λ_M)
Hermitian 协方差的特征向量给出正交空间模式，特征值给出各模式功率。单个强相关干扰通常产生一个明显的大特征值；独立同功率白噪声理想情况下使其余特征值接近。
有限快拍会导致特征值和特征向量波动；N≥M 只意味着可能满秩，不意味着估计已经可靠。
DFE 低通后相邻样本相关，因此样本数并不等于独立快拍数；有效快拍数通常更小。
条件数过大时直接求逆会放大数值误差和模型误差。
R_loaded = R̂ + δI，    δ = α·tr(R̂)/M
对角加载提高最小特征值，相当于牺牲部分极深零陷换取更稳定的求逆、更好的白噪声增益和更低的失配敏感性。当前 MVDR 默认 α=0.01。
工程判断：零陷越深并不一定越好。必须同时检查目标方向增益、输出 SINR、权值范数/白噪声增益、条件数、捕获率和跟踪率。
9. SINGLE、EGC 与 MVDR 的理论和区别
所有合并器最终都计算 y[n]=wᴴx[n]，区别在于权值 w 的形成方式。
SINGLE：w = e_r
EGC：w = a₀/(a₀ᴴa₀)
MVDR：w = R_loaded⁻¹a₀ / (a₀ᴴR_loaded⁻¹a₀)
EGC 只做目标相位对齐和等增益相加，不使用干扰协方差。若各通道噪声近似独立、目标相位正确，EGC 能提高相干目标幅度；但不会主动把权值放到干扰零空间。
MVDR 在满足 wᴴa₀=1 的条件下最小化 wᴴRw。它会利用协方差自动降低干扰方向输出，但强依赖 a₀。真实目标导向与假设导向失配时，算法可能把一部分目标当成需最小化的功率，出现目标自消除。
输出 SINR = Pₛ|wᴴaₛ|² / [ΣₖPⱼ,ₖ|wᴴaⱼ,ₖ|² + σ²wᴴw]
对 M 根天线、r 个独立保护约束，剩余自适应自由度约为 M−r。两天线、一个目标约束时通常只能稳定处理一个独立空间干扰模式；增加到 3 或 4 根天线可以增加自由度，但前提是阵列流形有效且通道相干。

Blind Nulling 的目标是解决“捕获前没有可靠卫星导向矢量”的问题。函数 combine_blind_null(x,cfg) 只接收 DFE 多通道样本和参考通道配置，不接收目标方向、干扰方向或任何场景 truth。
D = diag(R̂)，    C = D⁻¹ᐟ²R̂D⁻¹ᐟ²
S_dB = 10log₁₀[ λ_max / mean(其余 M−1 个特征值) ]

11. 为什么空域抗干扰对相位稳定性要求高
零陷来自多个通道的复数叠加。若两个通道在干扰方向上本应等幅反相相消，任一通道出现相位漂移，残差就会重新出现。固定通道相位偏置可以被同一数据块的样本协方差观察并吸收；真正危险的是权值估计后继续变化的相对相位。
两路等幅相消的残差幅度：|1−e^{jΔφ}| = 2|sin(Δφ/2)| ≈ |Δφ|（小误差）
差分频偏导致相位漂移：Δφ(t)=2π·Δf·t
以 40 ms 数据块为直觉示例，若希望相对相位漂移小于 10°，两通道差分频偏需小于约 0.69 Hz。这只是换算示例，不是当前仿真已经证明的硬件指标；真实允许误差还取决于干扰功率、天线数、更新周期、目标保护和期望零陷深度。
GPS L1 波长约 190.3 mm，1° 电相位约对应 0.53 mm 等效路径差。手机内部温漂、线缆/走线、电源、LO、采样时钟和射频器件变化都可能进入相位预算，因此实际多 RF 系统至少需要：
共享或严格同步的采样时钟和频率基准；
确定的数据帧/样点对齐，不能存在未建模的整数或分数采样延迟；
逐通道复增益校准，并知道校准残差随温度、频率和时间的变化；
权值更新窗口短于显著相位漂移时间，同时保持足够有效快拍；
检测、冻结、旁路和重新校准机制，避免失锁时继续使用失效权值。
12. GNSS 捕获：Doppler × 码相位二维搜索
捕获的任务是找到粗载波 Doppler 和 C/A 码相位。对每个候选 Doppler，先擦除载波，再通过 FFT 并行相关搜索全部码相位；多个 1 ms 相关功率做非相干累加。
R(f,τ) = Σₙ x[n]·c*[n−τ]·exp(−j2πfn/f_s)
P_nc(f,τ) = Σ_b |R_b(f,τ)|²
当前判决指标是主峰与排除主峰邻域后的第二峰之比。门限 2.5，码相位排除宽度 1 chip。该指标用于判断相关峰是否足够突出，不等价于输出 SINR 或 C/N₀。
图 4  代表性强 CW 用例的四分支捕获搜索图；SINGLE 失败，其余分支出现正确峰值
13. 闭环跟踪：DLL、FLL-assisted PLL 与 C/N₀
捕获成功后，每 1 ms 形成 Early、Prompt、Late 三组相关器。DLL 调整码速率/码相位，PLL 调整载波相位和频率；前 5 个历元使用 FLL 辅助，以提高初始频偏收敛能力。
e_DLL = (|E|−|L|)/(|E|+|L|+ε)
e_PLL = atan2(Im{P}, Re{P})
e_FLL = angle(PₖP*ₖ₋₁)/(2πT_coh)
Carrier NCO 的浮点和定点模式共享同一 DLL/PLL/FLL 误差和环路更新。固定模式将频率控制字和相位字量化；Code NCO、鉴相器、环路滤波器和相关累加器仍为浮点。
FCW = round[f_cmd/f_clk · 2ᴺ]，    f_actual = FCW·f_clk/2ᴺ
在 6.6 MHz NCO 时钟下，30-bit 频率 LSB 约 0.00615 Hz，43-bit 约 7.50×10⁻⁷ Hz。当前对比未观察到 Carrier NCO 位宽对主要结果有显著影响，因此该项已关闭为非主要问题。
Ĉ/N₀ = 10log₁₀{ |mean(P)|² / [(mean(|P|²)−|mean(P)|²)·T_coh] }
当前 C/N₀ 使用最近 10 个 Prompt 相关器窗口估计。窗口小于 2 个样本时返回 NaN；捕获失败分支不计算跟踪 C/N₀。

最大技术风险：仿真默认所有通道共享采样与相干处理。真实多 RF 是否能长期维持相位一致、如何校准、校准更新周期多长，目前尚无实测结论。
MVDR 风险：目标导向失配可能导致目标自消除。
Blind Null 风险：不使用目标导向，因此无法显式保证目标不落入干扰子空间。
统计风险：整段数据一次估计协方差，不能代表实时滑窗收敛和资源消耗。
传播风险：当前主要是静态 CW，结果不能直接推广到宽带、动态或相干多径干扰。
产品风险：合成天线参数只能做敏感性研究，不能替代真实测量。
