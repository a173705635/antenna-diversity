## 结构核验

29 项脚本化结构检查通过：18 条需求编号顺序/唯一性、G0–G5 六道关口、4 个历史证据链接、7 个源文件存在性、代码围栏和显示公式配对、无 TODO/TBD/FIXME 占位符，以及主要阈值/状态/证据约束存在性。该数量仅表示结构检查，不表示技术设计通过了 29 项实机试验。

解析换算核对：100 ms 独立非重叠窗每小时 36000 个，1% 单窗阳性率对应期望 360 个阳性窗口，不能直接换成事件次数。300 次独立同分布场次零失败时，单侧 95% 失败概率上界约 0.9936%，不是零风险。

## 语义审查

| 审查问题 | 结果与处理 |
|---|---|
| 是否把 P95 当作逐历元保护界？ | 已分开；NORMAL 的 U_H ≤20 m 是待评审保守规则，并非用户已批准的硬界 |
| 30 m 可信错误与 50 m 硬上限是否矛盾？ | 正常可信错误独立判失败；降级不得同样标可信，仍须有效边界且 ≤50 m |
| 长期无效能否冒充商用成功？ | 总可用率单报，最低可用率尚未批准，作为发布阻断项 |
| 10/30/60 s 是否被写成续航保证？ | 明确仅检查点；最低有效续航承诺仍需冻结 |
| 冷启动/历史回退是否有无条件可信来源？ | 没有，文档明确起点不可辨识则无效；不默认历史足够早就干净 |
| IMU 是否被视为独立认证？ | 没有；限定偏置、时标、姿态、运动可观性及污染风险 |
| 现有单窗恢复是否满足新要求？ | 不满足，明确需要新恢复准入，尚未修改代码 |
| C 是否依赖唯一测向？ | 不必，但子空间估计仍需证明；二倍相位不能直接提供完整 IQ 空间响应 |
| 抑制分支是否被误当作独立真值？ | 共享传感器与相关失效已列明，真值另行设计 |
| 相位/权重更新能否破坏导航观测？ | 需要新相位弧和偏差模型，已列为 C 准入条件 |
| 是否默认手机实体集成已可行？ | 没有，实际相位中心、天线安装、处理、电源和自干扰均需集成复验 |
| 发布是否还缺关键风险参数？ | 是；失败风险、暴露时间、总可用率、运行/攻击包络等阻止 G4 放行 |
