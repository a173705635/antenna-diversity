# Galileo E5 全带宽联合跟踪设计

## 1. 目标

在现有 MATLAB 工程中新增一条独立的 Galileo E5 单星跟踪验证链。该链路生成并跟踪完整 E5 AltBOC(15,10) 复数低中频信号，用于验证全带宽联合跟踪算法，不与天线分集、波束形成、原 GPS L1 C/A 接收链或现有 RF/DFE 模块耦合。

首版固定验证 Galileo SVID 1，并使用可配置接口表达 SVID，便于以后增加其他卫星码表。首版不实现卫星捕获、导航电文译码、伪距输出、定位或双天线处理。

## 2. 已确认的信号接口

- 输入数据类型：正交下变频后的复数 I/Q。
- 采样率：132 MHz。
- 模拟本振：1188 MHz。
- Galileo E5 中心频率：1191.795 MHz。
- 数字低中频：`1191.795 - 1188 = 3.795 MHz`。
- E5a 相对数字零频中心：`3.795 - 15.345 = -11.550 MHz`。
- E5b 相对数字零频中心：`3.795 + 15.345 = 19.140 MHz`。
- 接收机全带宽：以 E5 中心为基准的 51.150 MHz 参考带宽。
- 信号分量：E5a-I、E5a-Q、E5b-I、E5b-Q。
- 数据处理：仿真端产生确定且接收端已知的 E5a-I 和 E5b-I 导航符号；本地副本执行数据符号和次级码擦除，使四个分量均参与相干联合跟踪。

按 51.150 MHz 参考带宽计算，数字通带相对零频约为 `[-21.780, 29.370] MHz`，完整落在 132 Msps 复数采样的 Nyquist 区间内。后续 66 Msps 复数采样的 Nyquist 区间为 `[-33, 33] MHz`，同样能够容纳该通带；首版只验证 132 Msps，但所有算法不得把每码片采样点数写死。

信号参数、AltBOC 调制、主码及次级码定义以 [Galileo OS SIS ICD Issue 2.2](https://www.gsc-europa.eu/sites/default/files/sites/all/files/Galileo_OS_SIS_ICD_v2.2.pdf) 为准。

## 3. 方案选择

首版采用直接全带宽 AltBOC 匹配跟踪：信号源和接收机本地副本均按 ICD 的完整 AltBOC 8-PSK 状态映射生成复波形，Early、Prompt 和 Late 相关器直接处理整个 E5 频带。

该方案作为后续“双边带分离后联合跟踪”的基准。首版不在跟踪器内部预先把输入分成 E5a 和 E5b 两路，否则会把当前基准与后续对比方案混为一体。多相滤波器组和实时化优化也不属于首版范围。

## 4. 软件边界

新增代码使用独立的 `+galileo` MATLAB 包和独立入口，不修改以下现有算法的行为：

- `gnss.generate_scenario`
- `receiver.acquire`
- `receiver.track`
- `diversity.combine`
- `run_end_to_end`

建议文件职责如下：

```text
matlab_sim/
├── e5_default_config.m              % 独立 E5 参数和环路配置
├── run_e5_fullband_tracking.m       % 独立端到端验证入口
├── +galileo/
│   ├── e5_primary_code.m            % SVID 1 四分量主码
│   ├── e5_secondary_code.m          % SVID 1 四分量次级码
│   ├── altboc_replica.m              % 完整 AltBOC 波形/本地副本
│   ├── generate_e5_signal.m          % 132 Msps 复数低中频场景
│   └── track_e5_fullband.m           % 联合 DLL/FLL/PLL 跟踪
└── tests/
    ├── test_e5_codes.m
    ├── test_e5_altboc.m
    ├── test_e5_tracking.m

```

`run_e5_fullband_tracking` 只编排配置、信号生成、带偏差的初始状态、跟踪和结果显示。码生成、AltBOC 映射和环路算法不得写在入口函数内。

## 5. 信号生成

### 5.1 扩频码和符号

四个分量均使用 10.230 Mchip/s、10230 芯片的 1 ms 主码。主码由 ICD 指定的 14 级双 LFSR 和 SVID 1 初始状态生成。测试必须用 ICD 给出的前 24 个码片作为独立真值，避免仅用收发端相同实现做自洽验证。

次级码长度分别为：

- E5a-I：20；
- E5a-Q：100；
- E5b-I：4；
- E5b-Q：100。

E5a-I 导航符号率为 50 symbols/s，E5b-I 导航符号率为 250 symbols/s。场景使用固定随机种子生成确定的 `+1/-1` 导航符号，并将同一符号序列交给本地副本完成已知数据擦除。Q 分量不包含导航数据。

### 5.2 AltBOC 波形

`galileo.altboc_replica` 根据四个分量的码、次级码和数据电平，采用 ICD 的八个子载波子区间及 8-PSK 状态映射产生归一化完整 AltBOC 波形，包含主信号项和乘积项。采样通过连续码相位和子载波相位计算，不假设采样率是码率或子载波率的整数倍。

未加接收滤波和噪声时，波形平均功率归一化为 1，包络幅度应在数值精度内恒定。信号随后乘以中心低中频 `3.795 MHz`、载波 Doppler 和初始载波相位，并加入可重复复高斯白噪声。

码率和 15.345 MHz 子载波率按同一个归一化 Doppler 比例缩放，载波 Doppler 以 1191.795 MHz 为参考。这样四分量保持共同传播时延和统一时间尺度。

## 6. 联合跟踪器

### 6.1 输入和初始化

`galileo.track_e5_fullband(x, fsHz, cfg, init, knownData)` 接收一维复数 I/Q、采样率、跟踪配置、初始状态和已知导航符号。首版不实现捕获；验证入口从真实值构造带可配置偏差的初始 Doppler、码相位和载波相位。

无效采样率、空输入、缺少已知数据、非有限初值或不足一个完整相干积分周期的数据必须返回带明确标识符的错误。

### 6.2 相关器

每个 1 ms epoch 生成完整 AltBOC Early、Prompt 和 Late 本地副本。默认 Early/Late 总间隔为 0.1 chip。副本使用同一个公共码 NCO、公共子载波时间基准和公共载波 NCO；四分量数据及次级码状态与当前 epoch 对齐。

相关器直接对完整输入带宽积分，不先形成独立 E5a/E5b 基带流。Prompt 输出保留为复数，以供 FLL/PLL 和锁定检测使用。

### 6.3 鉴别器和环路

- DLL：归一化非相干 Early-minus-Late 功率鉴别器。
- FLL：相邻 Prompt 复相关相位差，只在初始配置 epoch 内辅助载波收敛。
- PLL：已知数据擦除后的 Prompt 四象限相位鉴别器。
- 码率：由名义码率、载波 Doppler 比例和 DLL 校正共同确定。
- 子载波：由同一码时间基准按固定 `15.345/10.230 = 1.5` 比例生成，不设置独立自由漂移的子载波 NCO。

AltBOC 自相关存在旁峰。跟踪器增加 `2/3 chip` 邻域的旁峰监视相关器；只有当相邻监视峰连续超过 Prompt 达到配置次数时，码相位才执行一次 `±2/3 chip` 校正。该逻辑用于恢复错误锁定，不能在正常热噪声波动下频繁跳变。

### 6.4 输出

跟踪结果至少包含：

- `success` 和 `status`；
- epoch 起始样本和时间；
- Early、Prompt、Late 复相关值；
- DLL、FLL、PLL 鉴别器序列；
- 载波 Doppler、载波相位、码率和码相位历史；
- Prompt 幅度、相位锁定指标和 C/N0 近似值；
- 旁峰监视值及发生的码相位跳转；
- 真实值与最终估计误差摘要。

## 7. 数值和资源约束

132 Msps 下每个 1 ms epoch 含 132000 个复样本。实现按 epoch 生成本地副本和更新环路，不长期保存四个分量的全采样率中间波形，避免不必要的内存放大。场景只保存最终复合输入和低速真值。

首版使用 base MATLAB 函数，不依赖 Navigation Toolbox、Communications Toolbox 或 Signal Processing Toolbox。所有随机量由配置的固定种子控制。

## 8. 验收标准

1. SVID 1 的四套主码长度均为 10230，取值仅为 `+1/-1`，前 24 码片与 ICD 独立真值一致。
2. 四套次级码长度和 SVID 1 分配符合 ICD。
3. 无噪声、未滤波的完整 AltBOC 波形包络误差小于 `1e-12`，平均功率为 1。
4. 132 Msps、LO 1188 MHz 配置下，频谱能量在 `-11.550 MHz` 和 `19.140 MHz` 两个理论边带周围均明显存在；用已知基带 AltBOC 副本擦除扩频调制后，公共低中频估计与 `3.795 MHz + Doppler` 的误差不超过一个 FFT bin。
5. 高信噪比、固定随机种子、初始 Doppler 偏差不超过 250 Hz、初始码相位偏差不超过 0.1 chip 时，至少完成 20 个跟踪 epoch；所有环路状态有限且 Prompt 非零。
6. 最后 10 个 epoch 的平均载波 Doppler 误差不超过 20 Hz，平均码相位误差不超过 0.03 chip，PLL 相位误差 RMS 不超过 0.25 rad。
7. 构造落入相邻相关峰的初始码相位时，旁峰保护能够回到主峰且不会持续跳变。
8. `run_e5_tests.m` 全部通过；现有 `tests/run_all_tests.m` 仍全部通过，证明新增独立链路没有改变原 GPS/天线分集行为。

## 9. 后续扩展边界

首版验证通过后，可在保持跟踪结果字段一致的前提下新增两项独立工作：

1. 将采样率切换为 66 Msps，重新验证接收滤波过渡带、频谱无混叠和环路性能。
2. 将同一完整 AltBOC 输入分离为 E5a/E5b 两路复基带，使用共享码/载波状态的双边带联合跟踪，并与本设计的直接全带宽结果比较计算量、跟踪门限和测距抖动。

天线分集或阵列处理不属于上述两项扩展的隐含内容；如需结合，应另行定义信号合并发生在宽带滤波前还是相关器后。
