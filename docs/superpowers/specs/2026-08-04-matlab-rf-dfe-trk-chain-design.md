# MATLAB 双天线 GNSS RF→DFE→TRK 链路设计

## 1. 目标

在 `F:\antenna_diversity\matlab_sim` 中建立一套可运行、可分层验证的 MATLAB R2023a 仿真基线，覆盖：

```text
GPS L1 C/A 与窄带干扰生成
→ 双天线空间接收
→ RF 前端与 ADC
→ DFE 下变频、滤波、抽取和量化
→ 单天线 / EGC / MVDR 合并
→ FFT 捕获
→ 闭环 DLL、FLL、PLL 跟踪
→ 性能比较与绘图
```

第一版只研究单颗 GPS L1 C/A 目标卫星、两阵元均匀线阵和一个窄带连续波干扰源。多星、多干扰、多径、导航电文解调和定位不属于第一版范围。

## 2. 建模层级

采用复数等效中频模型，不直接对 1575.42 MHz 的真实射频正弦载波进行过采样。空间相位仍按 L1 载波波长计算，因此保留天线间距、目标/干扰方向和通道幅相误差对分集性能的影响。

默认采样率为：

- RF/ADC：16.368 MHz；
- 复中频：4.092 MHz；
- DFE 抽取倍数：4；
- DFE 输出：4.092 MHz；
- C/A 码率：1.023 Mcps；
- DFE 输出每码片 4 个样本；
- 默认仿真时长：40 ms。

该层级可以表达热噪声、级联增益和噪声系数、ADC 限幅与量化、DFE 带宽、空间干扰抑制及捕获跟踪闭环，同时避免真实载频采样造成的不必要计算量。

## 3. 信号与坐标约定

阵列为沿 x 轴放置的双阵元 ULA，阵元位置为 $x_m$，角度 $\theta=0$ 表示阵列法线方向。导向矢量采用：

$$
a_m(\theta)=\exp\left(-j\frac{2\pi}{\lambda}x_m\sin\theta\right).
$$

阵列数据按“阵元 × 时间”组织：

$$
\mathbf X\in\mathbb C^{N_{\mathrm{ant}}\times N_{\mathrm{samp}}}.
$$

所有波束形成输出统一定义为：

$$
y[n]=\mathbf w^H\mathbf x[n].
$$

因此无失真约束为 $\mathbf w^H\mathbf a_s=1$。该约定必须贯穿 EGC、MVDR、测试和绘图，避免共轭方向不一致。

GPS 复中频信号为：

$$
s[n]=A_s c_{f_c(1+f_d/f_{L1})}[n-\tau_c]d[n]
\exp\left(j\left[2\pi(f_{\mathrm{IF}}+f_d)n/f_s+\phi_0\right]\right).
$$

其中码率按载波 Doppler 比例缩放为 $f_c(1+f_d/f_{L1})$。第一版导航数据 $d[n]$ 固定为 $+1$，以便把问题集中在 RF、DFE、分集合并、捕获和载波/码跟踪上。窄带干扰默认为位于 RF 通带内的复连续波，可独立配置功率、频偏、初相和 DOA。

复包络电压使用 $P=E\{|v|^2\}/R$ 标定，避免把实带通信号的峰值公式与复 IQ 的均方功率混用。

## 4. 模块架构

### 4.1 配置与入口

`run_end_to_end.m` 是唯一主入口，调用 `default_config.m` 生成配置结构。所有随机过程使用配置中的固定种子，默认运行具有可重复性。

配置按 `signal`、`array`、`rf`、`dfe`、`diversity`、`acquisition`、`tracking` 和 `plot` 分组。模块只读取自己负责的配置字段。

### 4.2 信号和阵列场景

信号模块负责：

- 生成经过校验的 GPS L1 C/A PRN 码；
- 生成码延迟、多普勒和中频载波；
- 生成单个窄带连续波干扰；
- 根据目标和干扰 DOA 施加不同的阵列导向矢量；
- 施加每个通道的固定幅度和相位误差；
- 返回无噪声阵列信号、各分量和真值结构。

目标和干扰必须分别经过各自导向矢量，不能在单通道相加之后再复制到各天线。

### 4.3 RF 前端与 ADC

每个天线通道独立通过相同结构的 RF 链。第一版使用级联等效模型：

- LNA、混频器/IF、VGA 的增益和噪声系数用于 Friis 公式；
- 按等效输入噪声功率 $kT_0BF$ 生成独立复高斯热噪声；
- 总增益把天线口复包络电压放大到 ADC 输入；
- 可选软限幅表达压缩趋势；
- ADC 执行满量程限幅和有符号均匀量化；
- 输出每通道饱和比例、总增益、级联 NF、输入/输出 RMS 和量化步长。

第一版不逐器件进行非线性记忆效应建模。RF 模型的用途是研究动态范围、噪声和量化如何影响后级，而不是替代晶体管级仿真。

### 4.4 DFE

每个 ADC 通道执行完全相同的处理：

1. NCO 复下变频，将 4.092 MHz 中频搬移到零频；
2. 自编窗函数 sinc 低通 FIR，不依赖 Signal Processing Toolbox；
3. 滤波后按 4 倍抽取到 4.092 MHz；
4. 可选 DFE 输出量化；
5. 返回滤波器系数、群时延、输入/输出采样率和输出尺度。

滤波器在抽取前抑制混叠。所有天线共享同一个 NCO 相位基准和滤波器，确保通道间相位关系不会被 DFE 人为破坏。

### 4.5 分集合并

DFE 输出后提供三种模式：

- `single`：只使用第一个天线；
- `egc`：按目标导向矢量相位对齐，并归一化为目标单位增益；
- `mvdr`：从 DFE 阵列快拍估计加载协方差，并满足目标方向单位增益约束。

MVDR 权值通过线性方程求解，不显式计算矩阵逆。对角加载采用 $\delta=\alpha\operatorname{tr}(\widehat{\mathbf R})/N$。每种模式返回权值、目标响应、干扰响应、权值范数和协方差条件数。

第一版使用仿真已知目标 DOA 构造保护导向矢量。这是用于验证 RF→TRK 链路和分集收益的受控基线，不代表真实接收机已经知道卫星姿态方向；后续可由星历、姿态或校准模块替换。

### 4.6 捕获

捕获模块使用 FFT 并行码相位搜索：

- 对每个 Doppler 频率格进行载波擦除；
- 每 1 ms 做循环相关；
- 默认对若干毫秒的相关功率进行非相干累加；
- 输出 PRN、Doppler、码相位、峰值、第二峰值和峰值比。

第二峰值必须在排除主峰附近至少一个码片后搜索，不能直接取排序后的第二个采样点。成功门限既检查峰值比，也检查与已知真值的 Doppler 和码相位误差。

### 4.7 闭环跟踪

跟踪从捕获结果初始化，每 1 ms 处理一个块，包含：

- 载波 NCO 和码 NCO；
- Early/Prompt/Late 相关器，默认间隔 0.5 chip；
- 归一化非相干 Early-Late DLL 鉴别器；
- Prompt `atan2(Q,I)` PLL 鉴别器；
- 初始阶段使用相邻 Prompt 的叉积/点积 FLL 辅助；
- 二阶 PI 形式的载波和码环更新；
- Prompt I/Q、载波频率、码率、鉴别器、锁定指标和宽带/窄带功率比 C/N0 近似量记录。

首版的目标是稳定闭环和可解释的误差收敛，不包含导航比特同步、数据解调和伪距输出。

### 4.8 结果与绘图

主入口返回或保存一个结果结构，包含配置、真值、RF 指标、DFE 指标、三种合并权值、捕获结果和跟踪时序。

默认绘图包括：

- RF 与 DFE 关键节点频谱；
- 三种合并方式的阵列方向响应；
- 捕获二维搜索图或最佳 Doppler 码相关曲线；
- DLL/PLL/FLL 鉴别器、估计 Doppler 和 Prompt 幅度；
- single、EGC、MVDR 的捕获峰值比和跟踪 RMS 指标对比。

绘图开关关闭时，测试可以无界面运行。

## 6. 输入检查和失败行为

代码应在以下情况给出带字段名的明确错误，而不是产生静默错误结果：

- PRN 不在 1～32；
- 采样率与抽取倍数不能形成配置的输出采样率；
- DFE 输出每码片采样数过低；
- ADC 位数、满量程、带宽或仿真时长非正；
- 目标/干扰导向矢量维度与阵元数不一致；
- 输入数据不足以完成配置的捕获或跟踪时长；
- 捕获指标低于门限时，不进入闭环跟踪，并在结果中返回未捕获状态。

## 7. 验收标准

固定随机种子下，测试必须验证：

1. C/A 码长度为 1023，取值为 $\pm1$，周期自相关主峰为 1023，非零循环移位属于 GPS C/A Gold 码的三值集合 $\{-65,-1,63\}$；
2. 半波长双阵元导向矢量的相位差与解析式一致；
3. DFE 将 4.092 MHz 中频搬移到近零频，输出采样率为 4.092 MHz，输出长度符合抽取关系；
4. EGC 和 MVDR 对目标方向的复响应误差小于 $10^{-10}$；
5. 在默认干扰场景下，MVDR 的干扰方向增益低于单天线；
6. 无干扰高信噪比测试中，捕获 Doppler 误差不超过一个搜索栅格，循环码相位误差不超过一个 DFE 样本；
7. 默认端到端场景中，至少 MVDR 分支完成捕获并进入跟踪；
8. 稳态跟踪区间内载波频率估计保持有限值，Prompt 相关幅度非零，DLL/PLL 误差不发散；
9. 关闭绘图后 `run_all_tests.m` 能以 MATLAB 批处理方式完成并在失败时返回错误。
