# 手机终端天线真实性模型设计

日期：2026-08-20
状态：设计已确认并完成自审
目标分支：`codex/antenna-realism`

## 1. 背景

现有 Python 仿真已经覆盖 Mate 70 外形约束下的理想 2–4 角点、三维窄带阵列流形、0–3 个静态 CW 干扰、RF/DFE、SINGLE/EGC/MVDR、捕获、跟踪、C/N₀，以及可恢复的七阶段研究流程。当前阵元响应仍固定为各向同性 `1+0j`，所以现有结果只能说明理想相位中心模型中的空间处理能力，不能代表真实手机天线。

本阶段补齐手机终端天线本体的建模接口和可运行的参数化模型，使同一套解析研究与完整样本链能够研究方向图、安装姿态、极化、遮挡、互耦及模型失配。没有测量数据时，输出继续明确标记为参数化研究结果。

## 2. 目标

1. 建立统一的窄带接收天线模型，供场景生成、解析协方差、方向扫描和报告共用。
2. 支持每个角点独立的三维安装姿态和复数双极化阵元响应。
3. 支持各向同性、参数化和表格测量三种方向图来源。
4. 支持手机/手握造成的可配置方向性衰减区域。
5. 支持按固定四角顺序定义、按任意 2–4 角点组合抽取的复数互耦矩阵。
6. 分离真实模型与接收机假设模型，以研究 MVDR 导向矢量失配。
7. 保持现有默认配置、旧 ULA 配置和已有数值基线兼容。
8. 在研究报告中展示单阵元响应、极化失配、互耦和最终阵列响应。

## 3. 非目标

本阶段不实现：

- 多径、NLOS、运动和动态 DOA；
- 宽带、扫频、脉冲或调制干扰；
- 多颗卫星、多 PRN、导航电文和 PVT；
- 在线 DOA、鲁棒导向矢量估计及滑窗实时 MVDR；
- 全波电磁求解、机壳散射求解或 SAR；
- 在没有实测输入时宣称 Mate 70 的真实天线性能；
- 互耦导致的外部噪声相关性。RF 链内部噪声仍按现有独立通道模型产生，互耦只变换到达天线端口的确定性信号和干扰电压。

## 4. 方案选择

### 方案 A：只增加标量方向增益

改动最小，但不能表示圆极化、线极化及极化失配，也难以无破坏地接入实测双极化方向图。

### 方案 B：直接建立完整电磁/网络模型

物理表达最完整，但需要真实结构、材料、S 参数和暗室数据。当前没有这些输入，容易产生看似精确但无法验证的结果。

### 方案 C：分层窄带接收模型（采用）

用复数 Jones 响应表达阵元，用显式姿态、遮挡和互耦逐层组合；默认仍可退化为当前各向同性模型。该方案能立即运行参数化研究，又为以后导入暗室方向图和 S 参数保留稳定接口。

## 5. 坐标、方向与极化约定

- 手机坐标继续使用现有定义：原点位于机身中心，`+x` 沿宽度、`+y` 沿长度、`+z` 指向屏幕法向。
- 外部 `Direction` 仍表示从阵列指向辐射源的方向，方位角绕 `+z`，仰角范围为 `[0°, 90°]`。
- 现有空间相位约定保持不变：

  \[
  p_m(\mathbf u)=\exp(-j k\,\mathbf r_m^T\mathbf u)
  \]

- 每个阵元用一个正交旋转矩阵描述局部坐标到手机坐标的变换。配置采用 yaw/pitch/roll（度），内部一次转换为矩阵并验证正交性和右手性。
- 入射电场在手机坐标的局部球面切向基中表示为复数 Jones 向量 `[E_az, E_el]`，并归一化为单位功率。
- 预设支持 `rhcp`、`lhcp`、`linear` 和显式 Jones 分量。圆极化手性以本项目的“从阵列朝向辐射源观察”的方向约定定义，并用同极化单位响应、正交极化零响应的测试固定符号，避免依赖文字歧义。
- 姿态变换通过三维复电场向量完成：先把手机球面基的 Jones 向量还原为三维电场，再旋转到阵元局部坐标，最后投影到局部球面基。这样 pitch/roll 不会被简化成只旋转方位角。

## 6. 数学模型

对方向 `u`、频率 `f` 和入射极化 `e`，第 `m` 个阵元在互耦前的开路等效电压定义为：

\[
x_m = b_m(\mathbf u)\;\mathbf h_m^H(\mathbf u_m,f)\mathbf e_m\;
      \exp(-j k\,\mathbf r_m^T\mathbf u)
\]

其中：

- `r_m` 为真实或假设相位中心；
- `u_m`、`e_m` 为变换到阵元局部坐标的方向和极化；
- `h_m=[h_az,h_el]` 为阵元复数双极化有效响应；
- `b_m` 为多个遮挡区域叠加后的复电压衰减，默认相位为零；
- 上标 `H` 表示共轭内积。

激活角点按 `active_antennas` 顺序组成向量 `x`。端口互耦和通道校准后的有效导向矢量为：

\[
\mathbf a_{effective}=\mathbf D_{channel}\,\mathbf C_{coupling}\,\mathbf x
\]

- `C_coupling` 是窄带复数端口传输矩阵；无互耦时为单位阵。
- `D_channel` 是现有逐通道幅相响应组成的对角阵。
- 互耦先作用于天线端口电压，逐接收通道误差后作用，顺序不可交换。

现有 `signal.power_dbm` 和 `interferer.power_dbm` 继续表示到达单位增益、单位极化匹配参考天线端口的功率。参数化或测量方向图的绝对增益会真实改变各通道电压及接收功率，而不是在生成后重新归一化。因此方向图峰值增益、遮挡损耗和极化损耗都会进入链路预算。

真实样本和解析协方差使用真实位置、姿态、方向图、遮挡、互耦和通道响应。MVDR 期望约束使用对应的估计模型。干扰协方差和生成的干扰样本始终使用真实模型。

## 7. 领域对象与接口

### 7.1 波极化

新增不可变 `WavePolarization`：

- `kind`: `rhcp | lhcp | linear | jones`；
- `tilt_deg`: 线极化倾角；
- 显式 Jones 模式使用四个实数保存两个复分量；
- `jones_vector()` 返回归一化 `complex128[2]`。

`SignalConfig` 新增 `true_polarization` 和 `assumed_polarization`，`CWInterferer` 新增实际极化字段。为了保持兼容，旧配置在各向同性模式下仍得到原来的单位阵元增益；新的真实性预设显式设置 GPS RHCP 和干扰极化。信号的真实/假设极化分离后，也能研究传播或校准造成的期望极化失配，而不需要伪装成阵元方向图误差。

### 7.2 阵元方向图

现有 `ElementPattern.complex_gain()` 和 `array_manifold()` 原样保留，继续服务旧标量调用。新增独立的 `PolarizedElementPattern.effective_height()` 协议，返回局部球面基中的复数双分量。`ScalarPatternAdapter` 可以把旧标量 pattern 接入新服务；旧 `IsotropicElementPattern` 在兼容模式下继续产生与极化无关的单位电压响应。这样不会让同一个方法在不同实现中返回标量或向量。

新增两种实现：

1. `ParametricElementPattern`
   - 峰值增益；
   - 前向余弦幂指数；
   - 后瓣/最低增益；
   - 名义接收极化；
   - 交叉极化鉴别度和交叉分量相位。
2. `TabulatedElementPattern`
   - 每个角点独立的规则方位/仰角网格；
   - 保存 `h_az`、`h_el` 的实部和虚部；
   - 方位角周期插值，仰角有界双线性插值；
   - 不做幅相直接插值，避免相位跨越造成跳变；
   - 超出已声明仰角覆盖范围时明确报错，不静默外推。

表格文件使用 CSV：

```text
element_name,frequency_hz,azimuth_deg,elevation_deg,
h_az_real,h_az_imag,h_el_real,h_el_imag
```

同一元素和频率必须构成无重复、完整的规则网格。局部方位角规范化为 `[0°, 360°)`，文件不得同时用 `0°` 和 `360°` 表示同一采样点；局部仰角允许 `[-90°, 90°]`。加载时计算 SHA-256，解析后的配置和报告记录文件摘要。首版不在频率轴上插值，只接受与配置载频在 `max(1 Hz, 1e-9 × f)` 内匹配的表格频率。

### 7.3 安装姿态

`AntennaStateConfig` 保存每角点 yaw/pitch/roll 映射；真实与假设 state 分别配置。默认全部为零，因此不会改变当前结果。角点集合必须严格为 `TL/TR/BL/BR`，相位中心仍由 `PhoneGeometryConfig` 的真实/假设坐标提供。

### 7.4 遮挡模型

新增 `AttenuationRegion`：

- 可选角点集合；
- 手机坐标中的中心方位/仰角；
- 球面角半径；
- 非负电压衰减 dB，运行时乘以 `10^(-attenuation_db/20)`；
- 可选边缘过渡宽度。

同一阵元命中的多个区域在 dB 域相加。零过渡宽度表示硬边界，正值使用确定性的余弦过渡。真实与估计遮挡区域分别配置，用于研究接收机是否知道握持状态。

### 7.5 互耦模型

使用固定四角命名的稀疏 `CouplingPath` 列表配置：

- `source`；
- `receiver`；
- `magnitude_db`；
- `phase_deg`。

运行时从单位阵开始填充非对角项，拒绝重复路径和自耦路径。真实和估计路径分别配置。按激活组合及其顺序抽取子矩阵。矩阵只要求有限和可构造，不把未经 S 参数验证的参数化矩阵宣称为被动网络。

### 7.6 统一服务

新增 `PhoneAntennaModel`，集中提供：

- `open_circuit_response(direction, polarization, frequency_hz, estimated)`；
- `coupling_matrix(active_antennas, estimated)`；
- `effective_manifold(..., estimated)`；
- `diagnostics(...)`。

所有下游模块只请求有效流形，不再各自实例化 `IsotropicElementPattern`。旧 ULA 仍走原有一维路径。

## 8. 配置与预设

新增结构化 `PhoneAntennaConfig`，由 `PhoneArrayConfig.antenna_model` 引用。它包含 `true_state` 和 `assumed_state` 两个 `AntennaStateConfig`；每个 state 都包含四角 pattern 映射、四角姿态、遮挡区域和耦合路径。真实与假设状态必须结构完整，但可以引用相同配置。

现有 `PhoneArrayConfig.pattern_model` 暂时保留为兼容字段：没有提供 `antenna_model` 时，`"isotropic"` 自动构造理想 `PhoneAntennaConfig`；同时提供两者且语义冲突时明确拒绝。后续版本才能正式弃用该字符串，当前阶段不删除它。

提供三个稳定预设：

1. `ideal_phone`：当前默认，零姿态、各向同性、无遮挡、单位互耦；数值必须与当前基线一致。
2. `parametric_phone`：有方向性的合成四角模式、可配置极化和弱互耦，用于算法敏感性研究；所有参数及“非实测”标签进入结果。
3. `measured_phone`：要求显式 CSV 路径和摘要，不提供伪造默认数据。

研究 JSON 可以覆盖预设中的姿态、方向图参数、遮挡区域、耦合路径、信号极化和每个干扰极化。解析后的科学配置哈希必须包含这些字段以及表格文件 SHA-256。

## 9. 现有链路接入

### 场景生成

- GPS 信号：生成 `desired_steering_true` 和 `desired_steering_assumed`。
- 每个启用干扰：生成真实有效流形。
- 保留现有 truth 键；新增开路响应、遮挡因子、互耦矩阵、极化匹配损耗等诊断键。
- 样本生成不重复施加通道幅相或互耦。

### 解析空间研究

- `evaluate_configuration_spatially`、方向扫描、功率扫描和多干扰研究统一调用 `PhoneAntennaModel`。
- 协方差由真实有效流形构造，MVDR 约束使用估计期望流形。
- `response_grid_db` 增加 `model_view=true|assumed`，默认展示真实有效阵列响应。
- SINGLE、EGC、MVDR 的定义不变。

### 完整样本链

RF、ADC、DFE、捕获、跟踪和 C/N₀ 接口不变；它们接收的 `(channels, samples)` 已包含新的天线空间响应。

### 研究编排

在现有七阶段中增加天线模型字段和诊断列，不增加新的阶段。代表场景仍由解析结果选择，完整链仍只运行已选场景。

## 10. 图和报告

增加以下证据：

- 四角单阵元真实与估计增益热图；
- GPS 与各干扰的逐阵元极化匹配损耗；
- 真实与估计互耦幅度/相位矩阵；
- 遮挡前后阵元增益对比；
- SINGLE/EGC/MVDR 最终有效阵列响应；
- 模型来源、参数化/测量标签和测量文件 SHA-256。

报告必须区分：

- `ideal`：旧各向同性理想模型；
- `parametric`：人为参数化模型；
- `measured`：由外部测量表驱动的模型。

只有 `measured` 且输入来源可追溯时，才允许使用“测量方向图驱动”措辞；仍不得自动称为 Mate 70 产品级验证。

## 11. 验证与错误处理

### 单元验证

- 零姿态、各向同性、单位互耦严格复现当前流形；
- 旋转前后局部方向和 Jones 基变换满足解析结果；
- 同极化单位响应、正交极化抑制及线极化倾角结果正确；
- 参数化方向图在波束中心、边缘和后瓣满足设定；
- 遮挡区域边界、过渡和多区域 dB 叠加正确；
- 互耦子矩阵严格保持激活角点顺序；
- 真实/估计模型差异只进入正确路径；
- CSV 周期插值、网格完整性、重复点、缺值、频率不匹配和摘要变化均有测试。

### 集成验证

- 旧默认配置的场景、解析指标、完整链和研究套件保持回归通过；
- 参数化模型下解析协方差与人工矩阵计算一致；
- 相同有效流形在解析路径和样本路径中一致；
- 2、3、4 天线任意组合均可运行；
- 0 和 3 个干扰、不同极化及遮挡组合均可运行；
- 所有 checkpoint、summary 和报告仍可用严格 JSON 序列化；
- 固定种子重复运行结果一致。

### 输入错误

所有用户配置错误统一抛出稳定 `ValueError`，包括非有限/复数标量、非法角点、非正交姿态、重复耦合路径、非法 Jones 向量、空或不规则表格、文件摘要不匹配及不支持的模型类型。不得把底层 `TypeError`、索引错误或 NumPy 广播错误泄漏给用户。

## 12. 兼容与迁移

- `default_config()` 和 `legacy_ula_config()` 的结果不变。
- 现有 `pattern_model="isotropic"` 自动映射到 `ideal_phone`。
- `array_manifold()` 保持公开并继续支持旧标量 pattern；新手机路径通过 `PhoneAntennaModel` 组合极化、姿态、遮挡和互耦。
- 现有 truth 和 metrics 键不删除，只新增键。
- 现有研究 JSON 在不写新字段时解析为理想模型。

## 13. 实施顺序

1. 坐标/极化、姿态和阵元方向图核心对象。
2. 遮挡、互耦和统一 `PhoneAntennaModel`。
3. 配置、预设及表格方向图加载与摘要。
4. 场景、解析扫描和完整链接入。
5. 研究配置、诊断指标、绘图和报告接入。
6. 全回归、参数化示例、文档和对外表述更新。

每一步使用测试先行并保持旧理想模型可运行。实现不改变 MATLAB 路径，本阶段继续以 Python 为唯一开发主线。

## 14. 设计自审结论

- 已把旧标量 `ElementPattern` 与新双极化协议分开，避免公开方法返回类型漂移。
- 已明确真实/假设位置、姿态、方向图、遮挡、互耦、通道和信号极化各自进入哪条路径。
- 已明确接收功率的单位增益参考，防止方向图在不同模块中被重复归一化。
- 已明确测量数据的坐标范围、频率匹配、插值方式和摘要要求。
- 已明确互耦不包含外部噪声相关性，这是本阶段保留的科学限制。
- 未发现需要扩大到传播、多星或 PVT 的依赖；设计可以独立实施。
