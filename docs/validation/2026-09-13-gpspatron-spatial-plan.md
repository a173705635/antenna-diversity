# GPSPATRON 公开原理启发的 2–4 天线空间检测：设计与实施计划

用户授权：在当前本地实现并完善方法、验证、结果和分析。工作树起点 4922a6e，开始时无未提交修改。

## 来源与范围

GPSPATRON 公开资料 https://gpspatron.com/coherent-gnss-spoofing-detection-multi-antenna/ （访问 2026-09-13）披露多天线载波相位关系用于空间一致性分析，未公开统计量、训练数据和产品门限。本地实现是公开原理启发的可审计研究版本，不能声称复刻 GP-Cloud 或达到其指标。

目标是检测并阻止可疑导航输出，不进行波束赋形、真假分离或恢复定位。保留现有 spoofing.py API 与默认仿真入口。使用原有手机四角坐标（75.9 × 160.9 mm），不是 GPSPATRON 的实际安装尺寸。共同频率参考、对齐时间和单频 GPS L1 是基础假设。

## 设计与备选

1. 扩展现有全星圆离散度至全部天线对：最小改动、可作为公平消融基线，预计部分欺骗仍弱。
2. 同源三星簇扫描：对全部 PRN 三元组计算跨天线对、跨历元平均离散度，取最小值；能利用更多空间约束，是本轮新增候选。枚举的多重比较必须在完整统计量上标定，不能把各基线当成独立事件。
3. 已知方向的 DOA/LCMV：需要可靠姿态、阵列流形及来源辨识，超出本轮检测目标，不采用。

输入为时间×天线×PRN 的载波距离与布尔有效性；检测器不接受真实位置、欺骗标签、攻击方向、逐星去均值常数或干净启动段。半周不敏感的复指数沿用旧判据，代价是空间折叠歧义。固定完整 100 ms 窗，缺数据/坏时间/不完整窗为 unknown；no_evidence 不等于真实信号认证。RF 观测通过既有 carrier_range 提取并传递质量掩码。

## 实施步骤与验证

- [x] 先写核心行为测试并确认失败：2–4 天线、全星兼容、部分同源、天线/PRN 排列、公共通道偏差、半周不变性、NaN/缺星/错序/不足窗。
- [x] 新建 spatial_spoofing.py：统计量、冻结门限、窗口判决、既有跟踪记录适配。
- [x] 新建 audit_spatial_diversity.py：独立 H0 标定与留出评估；同一四天线观测取子集形成配对对照。每种配置/判据目标窗口虚警 1%，默认 5000 标定事件、5000 评估事件。输出事件级统计量、Wilson 区间和配对提升区间。
- [x] 覆盖全星/部分/双源、真假混合功率、聚集天空、短孔径、空间特征逐星偏差、低信号、共反射和空间匹配反例；固定门限下报告分布外失效，不调整门限迎合 H1。
- [x] 新建 audit_spatial_diversity_rf.py：复用既有多星合成、独立 RF/DFE/捕获/跟踪/PVT；四通道取 2/3/4 子集，多个噪声种子，LOS、全替代、部分替代、真假混合。输出完整接收记录、配置、因果窗口及仅在窗口决策后生效的输出门控。
- [x] 快速模型/集成检查后运行正式试验，记录所有 unknown 和无收益场景。仿真 RF 无导航电文，明确区分静态接收与动态接管。
- [x] 运行相关和全套回归，核验归档哈希及图形；中文报告包含公式、假设、参数、命令、分母、置信区间、消融、负例、数据路径和限制；更新 README/PROJECT_STATUS/报告导航。

收益验收不要求算法一定有效：在同目标虚警率下测量 2→3→4 的检出变化，区分天线数收益与更换统计量收益。RF 相关时间窗不能冒充独立样本置信区间。被阻止的高误差输出不是更高定位精度；真实多通道录波未提供时不得宣称实测验证。
