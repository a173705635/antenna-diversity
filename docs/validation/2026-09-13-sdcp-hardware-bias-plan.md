# SDCP 天线与 RF 幅相偏差验证方案

目标：在无干扰、无多径、零人为延迟的双独立链路中，分别配置天线和 RF 固定幅相偏差，观察不取余的相位差。

设计：复用 antenna_response 和 process_rf。天线残余复增益作用于单元方向图响应、耦合之前；RF 残余复增益作用于等效输入信号及接收机噪声、限幅和 ADC 之前。RF 偏差代表固定噪声系数的等效输出增益/相位偏差，不代表任意 LNA 参数变化。新增参数默认零，历史 channel_* 参数保持原意义，实验将其清零，避免重复注入。

本轮为固定方向、固定频率、固定误差参数的机制试验。设置 TR 天线 −1 dB / +5°，TR RF +1 dB / +3°，TL 为零；这些数值是人为实验条件，不是实测或厂家指标。六个场景为零偏差、天线仅幅值、天线仅相位、RF 仅幅值、RF 仅相位、四项同时开启。每场景 1 秒、两组独立噪声对 9900/9901 和 9902/9903，同组各场景配对复用噪声。前 200 ms 单列为启动过程，后段统计不等价于锁定认证。

观测：保存两通道原始累计 NCO 相位与频率，用块内频率对齐同一物理时刻，不做 angle/unwrap/波长取余。距离符号 D = −λ(φ_TR−φ_TL)/(2π)，几何项直接由基线计算，报告 D−g 的均值、标准差、RMS、最大绝对值和相邻步变。保留任意整周/半周常数，不借助真值选分支；与同噪声零偏差记录作事后对照，真值只用于解释注入量。
