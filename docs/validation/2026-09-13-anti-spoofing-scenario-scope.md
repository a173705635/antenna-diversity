# GNSS天线分集抗欺骗：完整场景范围与应用边界

日期：2026-09-13。状态：场景定义，供后续选型和实验设计使用；不是验证结果或产品验收结论。

## 1. 目的与当前决定

先覆盖有无先验、冷启动、正常运行、失定位、失锁和恢复等状态，再依据可用信息选择算法与首阶段应用范围。不得先假定“攻击前正常、静止、姿态已知”而遗漏其他应用场景。

当前暂停扩展实验，优先明确检测任务。来源识别、可分离性判断、抑制及导航恢复作为后续独立能力讨论。天线分集是重点，但不预先排除可合法获得的独立辅助信息。

“完整范围”指本项目当前讨论的场景维度和覆盖方法，不意味着穷举现实中的全部攻击，也不意味着每种组合都物理可行或都能被当前算法解决。本文不冻结频段、天线数量、运动状态、攻击源数或先验组合；现有代码能力不等于目标范围。

## 2. 基本概念与任务层次

| 概念 | 本文含义 |
|---|---|
| 捕获成功 | 检测到与某个PRN假设相符的候选；不证明来源可信 |
| 跟踪锁定 | 环路能够跟踪某个成分或混合信号；不证明正在跟踪真实卫星 |
| 有定位解 | 能计算位置、速度或时间；可能来自受污染观测 |
| 失定位 | 无有效位置解；可能仍保有部分甚至全部跟踪观测，时间解也可能仍可用 |
| 失锁 | 某个信号跟踪连续性中断；不等于整机失定位 |
| 已知方向 | 必须说明坐标系、信息来源、不确定度和时效，不能只填写“已知” |
| 可信 | 在明确的信任来源和误差边界内可用于当前任务；不是算法无报警即自动可信 |
| 冷启动 | 本文按具体缺失的信息定义，不依赖设备厂商对冷／温／热启动名称的习惯 |

能力分层：

1. 检测：是否存在异常或欺骗迹象，能定位到哪些PRN／通道／频段？
2. 识别：能否区分真、假及其他异常来源？
3. 可分离性判断：有无足够观测安全地分离分量？
4. 抑制：是否压低可疑分量，同时保住真实信号？
5. 可信导航与恢复：如何使用、隔离和重新接纳观测，何时不能再输出可信解？

每项分别定义输入和验收指标。异常报警不等于欺骗归因，空间集中不等于恶意，抑制量大不等于定位恢复。

## 3. 整机工作状态

整机状态与逐星状态、先验状态交叉描述，不互相替代。

| 编号 | 状态 | 必须研究的问题 |
|---|---|---|
| R0 | 无可信时间、位置、有效星历和观测历史的启动 | 第一批候选如何检测？没有认证依据时能声明到什么程度？ |
| R1 | 有部分辅助信息，但尚未跟踪 | 辅助约束如何支持首次捕获验证？信息缺项或过期如何处理？ |
| R2 | 正常定位并稳定跟踪 | 如何识别运行中的接管，保留可信基准？ |
| R3 | 部分信号仍跟踪，但无法获得有效位置解 | 哪些检测不依赖当前位置？先验不确定度如何增长？ |
| R4 | 部分PRN失锁，其他仍连续跟踪 | 能否用保留的可信信息验证重捕？ |
| R5 | 全部失锁，但系统和本地时钟持续运行 | 保留了什么信息？重新捕获时哪些历史不能直接复用？ |
| R6 | 已输出错误位置／速度／时间，可能尚未告警 | 如何避免预测基准继续受污染？是否有独立信息可以纠正？ |
| R7 | 告警或隔离后进入恢复过程 | 如何重新验证、解除隔离并避免反复接纳假信号？ |
| R8 | 重启、断电恢复或状态持久化恢复 | 保存的信息是否可信、是否过期、是否来自之前的受骗状态？ |

R3需记录失定位原因：卫星数量不足、几何退化、观测质量不足、主动隔离，或解算故障等。位置、速度、时间的可用性分别记录，不用单个“定位有效”布尔量覆盖。

攻击可以在R0/R1启动前已经存在，也可在捕获过程中或后续状态切换时进入。重新启动不意味着信任被自动恢复。

## 4. 逐星、逐频段与逐通道状态

| 编号 | 状态 | 需要的处理边界 |
|---|---|---|
| S0 | 尚未捕获 | 首个候选可能是真、假、互相关或噪声误检 |
| S1 | 捕获候选，尚未充分验证 | 不把进入跟踪自动等同于允许参与可信定位 |
| S2 | 连续可信跟踪 | 使用适用的历史、预测和空间约束 |
| S3 | 跟踪有异常但尚未失锁 | 覆盖混合偏差、缓慢拖引、观测质量退化 |
| S4 | 失锁后重新捕获 | 原模糊度、半周状态和相位连续性可能失效 |
| S5 | 已隔离，正在重检 | 信号恢复或环路锁定本身不足以解除隔离 |

两个天线不一定跟踪同一分量：可能A跟踪真、B跟踪假，也可能不同频段分别受影响。必须包括通道不同步、单路失锁、两路选峰不同、半周状态不同的情况。未严格匹配的观测不能直接作相位单差。

## 5. 先验信息清单与信任管理

### 5.1 信息种类

| 编号 | 先验 | 可提供的约束 | 必须记录的限制 |
|---|---|---|---|
| P1 | 时间与本地时钟保持 | 可见性、时序、预测状态 | 初始误差、频率漂移、保持时长、更新来源 |
| P2 | 位置或区域范围 | 卫星方向、距离、可见性 | 精度、最后可信时刻、是否已被欺骗污染 |
| P3 | 星历／历书 | 卫星状态预测 | 类型、有效期、真实性来源；不能将历书精度当星历精度 |
| P4 | 速度、运动模型、运行范围 | 状态变化、多普勒合理性 | 模型误差，是否适合当前运动 |
| P5 | 天线基线几何与姿态 | 预期天线间空间响应 | 长度不等于朝向；坐标转换、姿态误差与变化率 |
| P6 | 天线方向图、互耦、通道幅相／时延标定 | 将方向映射到实际接收响应 | 频率、温度、安装和配置变化后的适用性 |
| P7 | 攻击前可信观测历史 | 相位、码、多普勒及质量连续性 | 可信依据、参考段长度、周跳／失锁后的失效范围 |
| P8 | 独立辅助传感器或服务 | 提供独立运动、时间、位置等约束 | 是否独立于被检测GNSS、通信中断和自身故障 |
| P9 | 可用的认证信息 | 在相应机制范围内增强信息真实性判断 | 覆盖的是电文还是测距信号、时效与重放限制；不默认项目已有该能力 |

### 5.2 每项信息都具有生命周期

至少区分：可信且有效、可信但误差已增长、来源未验证、疑似受污染、不可用。记录来源、时间戳、误差界／协方差（若可得）、更新规则和失效条件。

关键规则：

- 攻击前“正常”也要说明由何种依据确认；不能只因旧算法未报警就定义无攻击。
- 新接收的星历、位置和时间不能无条件覆盖可信预测基准。
- 不用可能受骗的位置计算方向，再以该方向符合观测为理由证明位置可信。
- 失锁后可以保有时间、位置和星历先验，但不得默认原相位模糊度及连续性仍有效。
- 允许基准更新时，应说明更新准入、冻结、超时和恢复规则，防止缓慢攻击被吸收。
- 外部辅助也可能错误或过期；必须有缺失和失效场景。

### 5.3 “方向已知”的分级

| 情况 | 还缺什么 |
|---|---|
| 只有星历 | 仍需时间、接收位置估计才能得到本地天空方向 |
| 已知天空方位／仰角 | 仍需天线姿态才能映射到天线坐标系 |
| 已知天线坐标系方向 | 仍需阵列几何及响应模型才能预测实际复响应 |
| 已知实际复响应及误差界 | 可以建立更直接约束，但必须考虑标定失效 |

仿真真值可以用于评估和理想上限，不得悄悄传入实际检测器补齐缺失先验。

## 6. 欺骗威胁维度

| 编号 | 维度 | 应覆盖的情况 |
|---|---|---|
| A1 | 出现时机 | 启动前已有、捕获期间、跟踪期间、失定位／失锁期间、恢复期间 |
| A2 | 受影响范围 | 单PRN、部分、多数或全部；单频／多频、单星座／多星座 |
| A3 | 来源结构 | 单源、多源；远场／近场；不同来源之间是否协调 |
| A4 | 入射途径 | 外部天线入射、转发／重放、天线或接收接口注入等不同模型 |
| A5 | 真信号是否存在 | 仍存在并叠加、被遮挡、被其他干扰压制而不可用 |
| A6 | 相对信号参数 | 码延迟、多普勒、相位、功率及随时间的变化，频间／PRN间一致性 |
| A7 | 过程 | 突发、逐渐增强、接管、缓慢拖引、间歇、撤离、再次进入 |
| A8 | 目标 | 错误位置、速度、时间，或破坏可信导航可用性 |
| A9 | 空间关系 | 明显可区分、近似响应、相同基线投影、阵列空间混淆 |
| A10 | 前端状态 | 线性工作、AGC变化、量化受限、饱和；不能用线性零陷解释饱和后的恢复 |

不能默认欺骗高于宽带噪底。对相关前和相关后处理分别说明信噪条件。真假同PRN、同码同频、相干或部分相干是需要保留的边界，而不是从实验中排除的失败项。

外部射频欺骗、转发、接口注入和上层辅助信息污染不能混成同一威胁。天线空间检测对绕过天线或复制空间响应的情况可能缺少区分信息，需独立标注适用性。

## 7. 环境与无攻击对照

至少纳入：LOS、多径、NLOS、遮挡、弱信号、正常卫星升落、几何退化、静止／运动、姿态变化、正常周跳与失锁重捕、通道漂移、对齐误差、硬件故障、先验过期及辅助信息中断。

分别设置：

1. 无欺骗的正常基线；
2. 无欺骗但具有上述异常因素的误报对照；
3. 欺骗与这些因素叠加的压力场景。

外部噪声干扰与欺骗分别建模；混合场景明确标注，不能把失锁、不可用或强干扰报警计成欺骗识别成功。

## 8. 代表性应用场景矩阵

下表是覆盖入口，不是完整笛卡尔积，也不预设当前方案适用。

| ID | 接收机与先验状态 | 攻击或对照 | 核心问题 |
|---|---|---|---|
| C01 | R0，无可信先验 | 启动前已有单源多PRN欺骗 | 能否检出空间异常？能否辨真伪？ |
| C02 | R0，无可信先验 | 仅一颗／部分假信号，其他真实 | 无历史时的部分欺骗盲区 |
| C03 | R1，有可信时间、位置、星历、姿态 | 首次捕获假信号 | 独立预测能否阻止错误接纳？ |
| C04 | R1，仅有过期或粗精度辅助 | 捕获期欺骗 | 不确定度扩大后的检测能力与误报 |
| C05 | R2/S2，有可信历史 | 单PRN突然进入 | 逐星检测、告警前观测偏差 |
| C06 | R2/S2，有可信历史 | 部分PRN逐渐增强并拖引 | 防止参考漂移，避免整组检测漏检 |
| C07 | R2/S2，有可信历史 | 多PRN同源接管 | 整组证据与逐星证据如何结合？ |
| C08 | R2，其他星可信，目标PRN为S0/S1 | 新星候选是假信号 | 没有该星相位历史时如何验证？ |
| C09 | R3，失位置解但仍跟踪 | 部分欺骗进入或持续 | 不依赖当前PVT的检测，误差界保持 |
| C10 | R4/S4，部分失锁 | 两路重捕到不同分量 | 单差可比性和重新接纳规则 |
| C11 | R5，全失锁但时钟持续 | 保持期后捕获到假信号 | 先验老化与全局重新验证 |
| C12 | R8，重启或断电恢复 | 攻击仍存在 | 持久化状态是否可信，恢复是否等同冷启动？ |
| C13 | R6，已经输出错误状态 | 攻击保持一致错误解 | 防止自洽预测循环，寻找独立依据 |
| C14 | R7，处于告警／隔离 | 欺骗撤离或间歇出现 | 恢复延迟、错误解除隔离、反复接纳 |
| C15 | 任意状态 | 真信号不可用，仅剩伪造／转发信号 | 区分检测与无法恢复真实导航 |
| C16 | 有／无方向先验 | 不同方向却同基线投影 | 单基线空间盲区 |
| C17 | 有方向先验 | 多源、近场或接口注入 | 空间模型失配及适用边界 |
| C18 | R2或R3 | 无欺骗，存在多径／遮挡／姿态变化 | 误报、拒绝正常观测、覆盖率 |
| C19 | R1/R2/R5 | 辅助信息过期、错误或受污染 | 先验失效是否被发现？是否错误自证？ |
| C20 | 多频／多星座接收 | 仅部分频段或星座受影响 | 交叉约束是否独立可信，能否保留可用解？ |
| C21 | 任意状态 | 欺骗叠加强干扰或前端饱和 | 先判观测不可用，不能误称识别成功 |

重要状态链需要连续验证，不能只抽取稳态：正常→攻击进入→混合→接管／失锁→重捕；无定位→保留部分观测→重新定位；告警→隔离→攻击消失→重新验证。攻击可能在任意阶段中断或重新出现。

## 9. 输出状态与处理原则

建议将观测状态、告警与导航状态分开设计，具体实现后续再定。

| 输出层 | 状态建议 | 禁止的等同关系 |
|---|---|---|
| 观测 | 待验证、通过当前检查、可疑／隔离、不可用 | 捕获／锁定≠可信；未报警≠真实 |
| 检测 | 无该类证据、发现异常、符合某类欺骗证据、证据不足 | 多径异常≠已确认欺骗；缺测≠检出 |
| 导航 | 正常使用、降级、可信解不可用、恢复待验证 | 有数值解≠可信定位；拒用后无解≠零误差 |

空间方向异常只能证明与假设不符。要输出欺骗类别或真假标签，必须说明还有哪些依据及误判边界。候选源不可分离时不强行形成零陷。解除隔离也应有规则，不能用刚恢复锁定直接替代。

## 10. 统一评价指标

| 类别 | 需要记录的量 |
|---|---|
| 检测 | 独立攻击事件检出／漏检、正常事件误报、逐星识别情况、错误接纳 |
| 时序 | 攻击出现、影响观测、接管、首次告警、持续确认、隔离、恢复等时间点 |
| 告警前风险 | 最大位置／速度／时间偏差，以及达到规定误差界前是否告警 |
| 可用性 | 有效观测覆盖、未知比例、正常观测被拒绝比例、可信导航可用性 |
| 捕获／重捕 | 假候选接纳、真候选拒绝、验证耗时与模糊度状态 |
| 恢复 | 恢复时间、错误解除隔离、重新受骗与告警反复 |
| 后续抑制 | 真信号损伤、假信号残留、噪声代价、跟踪/PVT收益，分别统计 |

所有比例声明分母：独立事件、记录、卫星、窗口或历元。连续窗口不能当独立攻击事件；未知不能算成功，未输出位置不能算零误差。分别报告误报与覆盖，防止靠全部拒绝获得低误报。

门限、时间窗、可信误差界、最小卫星数等数值在具体应用范围选定后冻结，不在本范围文档中虚构通用数值。开发调参与独立留出验证分开。

## 11. 具体实验的填写模板

每个实验至少填写以下内容：

| 字段 | 内容要求 |
|---|---|
| 实验ID与目的 | 对应C类场景，说明待证实的能力与预期反例 |
| 整机／逐星／逐通道状态 | 初态及全过程转换，位置/速度/时间可用性 |
| 先验 | P1～P9逐项填写来源、可信状态、精度、时效、更新和失效规则 |
| 接收条件 | 天线几何、方向图、姿态、时钟、标定、RF/DFE及观测接口 |
| 威胁 | A1～A10适用项，攻击时序与真实信号是否存在 |
| 环境与对照 | 相同条件无攻击记录，必要时加入单因素压力 |
| 算法允许输入 | 明确排除仅供仿真评价的真值，标记oracle分支 |
| 输出与门限 | 告警、隔离、未知、恢复规则及冻结参数 |
| 评价 | 指标、统计单位、种子/记录划分、置信区间适用性 |
| 证据 | 配置、代码版本、源数据、日志、结果及哈希路径 |

物理一致性检查：由同一传播与运动模型确定码、载波、多普勒和到达方向；跨天线、PRN及频段保持合理关系。若在观测域人工加偏置，必须标明模型层级，不能称为真实RF攻击。

## 12. 如何从全范围选择下一阶段

先给每个候选方案建立“所需信息→对应场景→能力边界”表，标为可研究、有条件、只能异常报警、证据不足或存在原理盲区。然后选代表性状态转换、已知失败点及无攻击对照，而非直接穷举所有组合。

每次缩小范围都保留：纳入项、排除项、排除原因、将来如何扩展，以及不能对外声称的能力。静止、单源、L1、正常跟踪起点等可以是后续选项，但目前没有因此删除冷启动、失定位或无先验场景。

当前尚待选择的应用约束包括：移动平台类型、频段/星座、天线数量和尺寸、姿态来源、时间保持能力、星历信任来源、允许的先验误差、检测/恢复时间和错误导航容限。它们留待应用选型，不阻止本全范围清单归档。
