按已批准路线执行，沿用 Ponytail 和 writing-plans 的最小改动原则：只增加外部生成及接入审计入口，保留现有接收链算法。Julia 官方便携环境及包缓存在被忽略的 results 中，第三方源码快照、许可、依赖版本和结果放入专题数据目录。不得把自行重写的 Python 波形标作外部源。
