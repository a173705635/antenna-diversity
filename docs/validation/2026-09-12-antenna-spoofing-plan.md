# 天线分集抗欺骗首轮设计与实施计划

> 后续范围讨论见[完整场景范围与应用边界](2026-09-13-anti-spoofing-scenario-scope.md)。本文保留首轮实验设计，不将其中的固定8PRN等限制推广为全部应用场景。

目标：依据公开原始研究选择适合现有双 RF/DFE/独立跟踪代码的防御方案，完成模型及 RF 闭环验证。沿用用户授权自主调研、选型、实施；极化分集暂停，外部噪声干扰不混入主试验。

## 选型与范围

选择双天线多 PRN 载波单差空间一致性路线。它有实船公开证据，也符合现有接口。首轮实现圆统计简化检测器，不宣称复现 Psiaki 2014 的完整双假设最大似然算法、D3 理论门限或 NovAtel 专利全部认证流程。

每个共同历元取 d_j=(L_Bj-L_Aj)/lambda，构造 z_j=exp(i*4*pi*d_j)，分散度 S=1-|mean_j z_j|。小 S 表示共同空间响应。4*pi 对整数及半周模糊度不敏感，代价是扩大方向投影混淆；无逐星启动去均值。共同通道相位旋转不改变 S，逐星偏差会改变它。单基线不提供唯一三维到达角。

接收机输入仅含同频、同 PRN 顺序、严格对齐的载波观测和有效性标志。固定8颗集合，缺任何一颗则该窗口未知，避免按可见星数改变已标定统计分布。10个连续10ms历元构成100ms观察块，跨缺测/时间断点不累计。低于冻结阈值为疑似共同来源，否则为未发现该类证据；两者都不是密码学认证。

模型阈值：独立5000组随机天空几何（仰角15～90度、均匀sin仰角）、随机基线姿态、75.9mm长度、每历元差分相位等效3mm独立高斯噪声；每组10历元×8PRN。取 LOS 分散度下1%分位。留出种子测试，明确这是条件模型门限，不是实机1%误报保证。

RF 复用 build_scene/run_record/carrier_range：L1 33MHz RF、DFE /5、6.6MHz独立捕获跟踪。保存每通道实际跟踪结果。全替代情形给各PRN一致的天线间传播距离差，同时用错误接收位置构造自洽伪距；这模拟已捕获同源伪造信号，不模拟动态接管过程。还包括部分替代、真假信号直接叠加和已有无欺骗多径记录。只在数字仿真内生成测试输入。

主要输出：独立模型事件误报/检出及Wilson区间；RF有效覆盖、非重叠窗口比例、原始定位误差、告警后拒用比例。RF少量记录不输出普适检测概率，不将拒用后的无解写成定位精度提升。

## 实施任务

- [x] 新建 spoofing.py 和 tests/test_spoofing.py：验证共同偏差/整数半周不变性、分散响应、坏输入与缺测窗口。
- [x] 新建 audit_spoofing_model.py：冻结门限，保存独立事件和短基线、集中天空、部分受骗、逐星偏差、多发射方向反例。
- [x] 新建 audit_spoofing_rf.py：复用现有链路，执行独立噪声、全替代及混合/部分反例，保存原始记录与哈希。
- [x] 写调研及结果报告，交叉核查统计，运行回归，更新导航。

商用限制：同历元载波输出、双RF时钟、实际方向图和温度/多径影响须另行验证；单个伪造PRN、分布式来源、正常信号集中投影、严重失锁是关键边界。没有原始真信号时不能恢复可信GPS位置。下一步抑制路线需另行证明源识别和空间可分离性，不能用真值方向零陷代替。
