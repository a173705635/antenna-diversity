# 手机阵列测向与星间差分验证

用户已同意继续实现测向，并要求加入星间差分。维持 75.9 × 160.9 mm、2–4 天线，不加入 IMU。

1. 独立模块实现星间双差统计、疑似同源 PRN 选择、已校准单差方向拟合。无校准信息时不输出绝对方向；两天线明确报告方向约束不足。保留半周/整周周期候选及平面镜像，不用仿真真值选择候选。
2. 先写可观测性与几何测试：同源双差消去方向；共同通道偏差可消；逐 PRN 偏差不可消；小基线已校准无噪声方向恢复；手机阵列倍相多解；双天线/缺测拒绝唯一测向。
3. 双差统计分别用独立 H0 校准，与原判据比较。重用先前随机种子，保留同源、部分、混合、聚集与硬件偏差反例；不把多个判据未经校准地 OR。
4. 对既有原尺寸 RF 跟踪记录离线测向，分别评估已知零通道偏差的理想假设及由独立 LOS 记录校准的条件。真方向只在估计器返回后用于评估；最佳误差只能作为候选集合覆盖，不能声称估计器已选中正确方向。
5. 保存原始输入引用、哈希、每窗候选、模型统计及报告；不改写已封存数据、不将原型拟合阈值称为认证置信度。
